## 단계와 결과 (11/10)

| 단계 | 방법 | 판정 | 가게 수 | 사람 |
|---|---|---|---:|---|
| 1 | 인허가 폐업 신고 | 폐업 (확정) | 68,457 | ✗ |
| 1 | 10/28 이후 영업 신고 | 영업중 (확정) | 84 | ✗ |
| 2 | 상가정보 같은 건물에 비슷한 상호 | 영업중 (추정) | 23,038 | ✗ |
| 3 | 카카오 규칙 | 영업중 (추정) | 2,244 | ✗ |
| 3 | 카카오 규칙 | 폐업 (추정) | 3,078 | ✗ |
| 4 | 위에서 애매한 것 | 조원이 판정 | 758 | ✓ |

3단계 규칙 (임시 값): 카카오 300m 안 후보 중 상호 유사도 0.8 이상 + 100m 이내면 영업중, 결과 없음 또는 유사도 0.5 미만이면 폐업, 그 사이 · 좌표 없음 · 구내식당 등 · 흔한 상호는 4단계. 표본 300곳에서 규칙과 Claude 에이전트 판정이 295곳(98%) 같았습니다.

**최종판정 = 조원 판정이 있으면 조원 판정, 없으면 자동 판정.** 4단계인데 아직 아무도 안 본 가게는 `미확인`.

## 자주 쓰는 명령 (이 폴더에서 실행)

조원 판정을 가져와 반영 (가장 자주):
```bash
python 00_스크립트/sync.py
```

기준을 바꿔 처음부터 다시:
```bash
python 00_스크립트/funnel.py
```
```bash
python 00_스크립트/build_archive.py
```
```bash
python 00_스크립트/export_web.py
```
```bash
python 00_스크립트/sync.py
```
그다음 `04_조원확인/공유페이지`에서 배포: `npx vercel@50.44.0 deploy --prod --yes`

- `01_원본데이터/`는 읽기만 합니다. 원래 파일 위치: 인허가 원본은 `Desktop\과제 1\6_대구전체_음식점_영업기간`, 나머지는 `08_버틴집_이전작업(api)`.
