# 실습2 프로젝트

## 개요
교촌에프앤비(치킨 프랜차이즈) 관련 자료를 바탕으로 기업·산업 분석과 고객 리뷰 분석을 수행하는 실습 폴더입니다.

## 폴더 구성
- `onepager_교촌에프앤비.pdf` — 교촌에프앤비 기업 원페이저
- `산업구조_밸류체인_분석.pdf` — 산업 구조 및 밸류체인 분석 자료
- `.claude/agents/review-tagger.md` — 고객 리뷰 태깅 서브에이전트
- `.claude/settings.json` — 프로젝트 권한 설정

## 작업 원칙
- 모든 답변과 산출물은 **한국어**로 작성합니다.
- 수치·사실은 반드시 폴더 내 자료에서 근거를 찾고, 출처(파일명·페이지)를 함께 표기합니다.
- 자료에 없는 내용은 추정임을 명시하고, 사실처럼 단정하지 않습니다.
- 원본 PDF는 수정하지 않습니다. 결과물은 `output/` 폴더에 저장합니다.

## VOC 태깅 품질 기준
VOC 파일(`archive/`)을 읽고 태깅할 때는 아래 기준을 모두 확인합니다.

### 검사 항목
| # | 검사 항목 | 통과 기준 | 채점관 점수 | 관계화면 표시 |
|---|---|---|---|---|
| 1 | voc_id 누락·중복 | 누락 0건, 중복 0건 | **범위 점수** | 채점 패널 |
| 2 | 원문 인용 근거 | 모든 행에 원문 그대로의 인용 구절이 있음 | **근거 점수** | 채점 패널 |
| 3 | 태그 허용 목록 | 모든 태그가 허용 7개(P1·P2·P3·H1·H2·해당없음·검토) 안에 있음 | **형식 점수** | 채점 패널 |
| 4 | 검토 태그 비율 | 전체의 **5% 이하**이며, 모든 검토 행에 이유(note)가 적혀 있음 | 형식 점수 | **검토 건수** 표시 |

### 최종 통과 조건
| 구분 | 조건 |
|---|---|
| 채점 세 묶음 | 범위 · 근거 · 형식 점수 **모두 80점 이상** |
| 관계화면 | **채점 패널**(세 점수)과 **검토 건수**가 반드시 표시됨 |
| 사용자 대조 | 사용자가 직접 대조한 10건 중 **9건 이상 동의** |
| 승인 | 최종 승인은 **사용자가 직접** 합니다. Claude는 스스로 승인하지 않습니다 |

## 리뷰 분석
- 분류는 `review-tagger`(묶음 N → `ax/demo/parts/part_N.csv`), 채점은 `review-grader`(→ `ax/demo/grades/grade_N.md`) 서브에이전트를 사용합니다.
- 태그 체계는 `painpoint/painpoint_def.md`의 허용 태그 7개(P1·P2·P3·H1·H2·해당없음·검토)를 따릅니다.
