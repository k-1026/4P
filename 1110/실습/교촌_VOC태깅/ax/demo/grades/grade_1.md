## 1. 채점 패널

범위: 100점
근거: 91점
형식: 100점
검토 건수: 3건

| 항목 | 점수 | 80점 통과 | 계산 근거 |
|---|---|---|---|
| 범위 | 100점 | 통과 | 정상 voc_id 100 / 원문 파일 100 x 100 = 100, 중복 0건이라 감점 0 |
| 근거 | 91점 | 통과 | 통과 행 91 / 100 x 100 = 91 (띄어쓰기 포함 15자 기준, 초과 9행) |
| 형식 | 100점 | 통과 | 헤더 25 + 태그 25 + note 25 + 검토 비율 25 |

형식 세부:
- 헤더 `voc_id,tag,evidence,note` 정확히 일치: 25점
- 허용 7개 태그 안의 행 100 / 100 x 25 = 25점
- note 규칙 준수 행 100 / 100 x 25 = 25점 (검토 3행 모두 이유 있음, 나머지 97행 note 비어 있음)
- 검토 비율 3% (5% 이하): 25점

## 2. 검토 건수

3건 / 전체 100건 (3.0%). 기준 5% 이하를 충족합니다.
