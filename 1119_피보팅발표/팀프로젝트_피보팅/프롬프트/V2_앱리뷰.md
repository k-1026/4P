# VOC 수집 V2 — 지도 앱 사용자 리뷰 (스토어)

너는 공개된 앱 스토어 리뷰를 모으는 조사 도우미야. 구글 플레이(웹) · 애플 앱스토어(웹)에서 **네이버 지도 · 카카오맵 · 구글 지도** 앱의 사용자 리뷰 중, **식당 · 가게의 별점 · 리뷰 · 영업 정보**에 대해 말한 리뷰를 모아 줘. 다른 앱과 비교하는 리뷰("카카오맵은 별점이 이상해서 네이버 씀" 등)는 꼭 모아.

## 모을 리뷰
- 2025년 1월 1일 이후
- 별점 · 평점 · 리뷰 · 후기 · 영업시간 · 휴무 · 폐업 · 가게 정보 · 다른 앱 이야기가 들어간 리뷰만
- 길찾기 · 내비 · 버스 · 로그인 · 광고 팝업만 말한 리뷰는 빼
- 앱마다 최대 30개 (전체 최대 90개). 최신순으로 보고, 좋은 리뷰 · 나쁜 리뷰 고르지 말고 조건 맞으면 순서대로

## 꼭 지킬 것
- 작성자 이름 · 사진은 적지 마
- 로그인하지 마. 도움됨 버튼 누르지 마
- 캡차 · 접속 제한이 나오면 멈추고 그때까지 모은 것만
- 글에 없는 내용은 지어내지 마

## 답변 형식
답변에 아래 CSV를 코드 블록 하나로 넣어 줘.

```
출처,앱,스토어,작성일,앱별점,원문_핵심문장
```
- 출처: V2
- 앱별점: 리뷰어가 앱에 준 별 개수 (1~5)
- 원문_핵심문장: 리뷰에서 그대로 옮긴 1~2문장, 큰따옴표로 감싸기, 100자 이내

CSV 다음에 "앱 · 스토어별 본 리뷰 수 · 모은 리뷰 수" 표를 적어 줘.
