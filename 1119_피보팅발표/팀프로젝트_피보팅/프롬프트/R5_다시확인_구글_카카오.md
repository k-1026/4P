# 다시 확인 R5 — 구글 지도에서 못 찾은 가게 + 카카오 후기 수 점검

너는 지도 앱 화면을 확인하는 조사 도우미야. 이전 조사에서 **구글 지도에서 못 찾았거나 다른 가게로 본 28곳**이 정말 없는지, 그리고 **카카오맵 후기 수가 적게 나온 10곳**이 맞는지 다시 확인해 줘.

## A. 구글 지도 다시 찾기 (28곳)
가게마다 아래 방법을 **모두** 써 보고, 하나라도 같은 가게가 나오면 "찾음"이야.
1. google.com/maps 에서 상호 그대로 검색
2. 상호 + 동/읍/면 이름 (예: "국민국밥 산격동")
3. 상호의 띄어쓰기를 바꾸거나 지점명을 빼고 검색 (예: "유아이유 범어")
4. 도로명주소로 검색한 뒤 **지도에서 그 건물 주변에 표시된 가게 이름**을 확인
5. 업태 + 동 이름으로 검색해 목록에 있는지 확인 (예: "범어동 카페")
- 같은 가게 판단: 주소(도로명 또는 지번)가 같거나 거의 같은 건물이면 같은 가게. 이름이 조금 달라도(띄어쓰기 · 지점명) 주소가 같으면 같은 가게로 보고 메모에 화면 이름을 적어
- 이름만 같고 주소가 다른 곳은 "다른 가게"
- 찾으면 별점 · 리뷰 수 · 영업 상태 문구를 화면 그대로 적어

## B. 카카오맵 후기 수 다시 보기 (10곳)
map.kakao.com 에서 찾아 가게 상세 화면의 **별점 · 후기 수 · 블로그 리뷰 수**를 다시 적어 줘. 후기 수가 어디에 표시되는지(예: "후기 3", "별점 4.0 (2)")도 메모에 화면 문구 그대로.

## 꼭 지킬 것
- 로그인하지 마. 리뷰 쓰기 · 저장 · 좋아요 누르지 마
- 가게 사이에 3초 이상 쉬어. 캡차 · 접속 제한이 나오면 그 사이트는 멈추고 나머지만 계속, 우회하지 마
- 보이지 않는 값을 추측하지 마. 리뷰 본문 · 작성자 정보는 적지 마

## 답변 형식
코드 블록 두 개로 CSV를 줘 (파일 저장 안 해도 됨).

A:
```
번호,상호,구글_찾음,찾은_방법,구글_화면상호,구글_별점,구글_리뷰,구글_영업표시,메모
```
- 구글_찾음: 찾음 / 다른 가게 / 없음 / 막힘
- 찾은_방법: 1~5 중 처음 찾은 방법 번호 (없음이면 빈칸)

B:
```
번호,상호,카카오_찾음,카카오_별점,카카오_후기,카카오_블로그,메모
```

마지막에 A의 찾음 · 다른 가게 · 없음 · 막힘 개수를 적어 줘.
