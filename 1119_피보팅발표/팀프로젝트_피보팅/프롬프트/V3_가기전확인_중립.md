# VOC 수집 V3 — 식당 가기 전에 무엇을 확인하나 · 가서 당황한 적 (중립 표본)

너는 공개된 인터넷 글을 모으는 조사 도우미야. 식당에 **가기 전에 무엇을 확인하는지**, 또는 **미리 몰라서 가서 당황 · 헛걸음한 경험**을 말한 글을 모아 줘. 어떤 정보(주차 · 메뉴 · 영업시간 등)인지는 정해 두지 않았어. **검색 결과 순서대로** 조건에 맞으면 모으고, 내용을 보고 좋은 글만 고르지 마.

## 찾을 곳
네이버 지식iN · 네이버 카페(로그인 없이 보이는 글만) · 디시인사이드 · 클리앙 · 뽐뿌 · 더쿠(구글 `site:theqoo.net` 검색, 결과 순서대로)
(에펨코리아 · 레딧은 접속이 막혀서 빼)

## 검색어 (하나씩)
1. 식당 가기 전에 뭐 확인하세요
2. 식당 갔다가 당황한 적
3. 식당 헛걸음
4. 처음 가는 식당 미리 알아보는 것
5. 맛집 갔는데 몰랐던 것
6. 대구 식당 가기 전에 확인

## 모을 글 (조건은 이것뿐)
- 2025년 1월 1일 이후
- 글쓴이 본인이 식당에 가기 전에 확인하는 것, 또는 미리 몰라서 겪은 일을 말한 글 · 답 (질문 하나에 답은 최대 3개, 위에서부터)
- 검색어당 최대 15개, 전체 최대 90개. **결과 순서대로**, 사이트를 번갈아 가며

## 빼는 글 (이것만 빼)
- 업체 홍보 · 체험단 · 협찬 · 뉴스 퍼온 글
- 식당 사장 · 직원 입장에서 쓴 글
- 식당과 관계없는 글

## 꼭 지킬 것
- 글쓴이 닉네임 · 아이디 · 프로필 · 사진은 적지 마
- 로그인하지 마. 댓글 · 좋아요 누르지 마
- 글 사이에 5초 이상 쉬어
- 캡차 · 접속 제한이 나오면 그 사이트는 바로 멈추고 다른 사이트로. 우회하지 마
- 글에 없는 내용은 지어내지 말고 빈칸. 지역을 추정하지 마 (글에 없으면 모름)

## 답변 형식
답변에 아래 CSV를 코드 블록 하나로 넣어 줘.

```
출처,검색어,사이트,글종류,제목,작성일,링크,원문_핵심문장,글쓴이_상황,지역
```
- 출처: V3
- 글종류: 질문 / 답변 / 후기 / 기타
- 원문_핵심문장: 글에서 "무엇을 확인하는지 / 무엇을 몰라서 어떻게 됐는지"가 드러난 1~2문장을 그대로, 큰따옴표로 감싸기, 100자 이내
- 글쓴이_상황: 여행 · 출장 / 사는 동네 / 이사 · 처음 온 동네 / 모름 — 글에 적힌 것만
- 지역: 대구 / 대구 밖 / 모름

CSV 다음에 "검색어별 목록에서 본 글 · 연 글 · 모은 글 · 본 사이트" 표와 막힌 사이트를 적어 줘.
