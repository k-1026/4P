# 폐업 표시 실측 P2 — 아래 가게가 지도 앱에 어떻게 표시되는지 (26~50번, 25곳)

너는 지도 앱 화면을 확인하는 조사 도우미야. 아래 대구 가게 25곳을 **네이버 지도 · 카카오맵 · 구글 지도**에서 각각 찾아, 지금 화면에 **영업 상태가 어떻게 표시되는지** 적어 줘. (이 가게들이 지금 영업하는지 아닌지는 알려 주지 않을게. 화면에 보이는 대로만 적어.)

## 찾는 법
- 상호 + 주소로 찾고 **주소가 같은 가게인지 꼭 확인**해. 이름만 같고 주소가 다르면 "다른 가게"
- 같은 주소에 **다른 이름의 가게**가 있으면 "없음"으로 적고 메모에 그 가게 이름을 적어
- 웹(map.naver.com · map.kakao.com · google.com/maps)에서 확인

## 앱마다 적을 것
1. 찾음: 찾음 / 없음 / 다른 가게 / 막힘
2. 영업표시: 화면에 보이는 영업 상태 문구를 그대로 (예: 영업 중, 영업 종료, 곧 영업 시작, 폐업, 영구 폐업, 임시 휴업, 정보 없음)
3. 폐업표시: 화면에 폐업 · 영구 폐업 · 없어진 장소라는 표시가 있으면 O, 없으면 X
4. 최근활동: 가장 최근 리뷰 날짜 또는 최근 소식 날짜 (보이는 대로, 없으면 빈칸)

## 꼭 지킬 것
- 로그인하지 마. 리뷰 쓰기 · 저장 · 좋아요 · 정보 수정 제안을 누르지 마
- 가게에 전화하지 마. 전화번호는 적지 마
- 가게 사이에 3초 이상 쉬어. 캡차 · 접속 제한이 나오면 그 사이트는 멈추고 나머지만 계속, 우회하지 마
- 보이지 않는 값을 추측하지 마. 리뷰 본문 · 작성자 정보는 적지 마

## 답변 형식
아래 CSV를 코드 블록 하나로 (파일 저장 안 해도 됨). 한 가게당 한 줄, 값에 쉼표가 있으면 큰따옴표로.

```
번호,상호,네이버_찾음,네이버_영업표시,네이버_폐업표시,네이버_최근활동,카카오_찾음,카카오_영업표시,카카오_폐업표시,카카오_최근활동,구글_찾음,구글_영업표시,구글_폐업표시,구글_최근활동,메모
```
- _찾음 칸은 "찾음 / 없음 / 다른 가게 / 막힘" 네 낱말 중 하나만 (O · X로 쓰지 마)

CSV 다음에 사이트별 찾음 · 없음 · 다른 가게 · 막힘 개수를 적어 줘.
