# 휴무 정답 확인 H1 — 앱끼리 휴무가 달랐던 대구 식당 17곳

너는 지도 앱 정보를 확인하는 조사 도우미야. 아래 대구 식당 17곳은 2026-11-19에 네이버 지도 · 카카오맵 · 구글 지도의 **휴무(쉬는 요일)**가 서로 달랐던 가게야. 이번에는 **가게가 직접 적은 휴무 정보**를 찾아서, 어느 앱이 가게 공지와 맞는지 확인해 줘. (우리가 정답을 아는 게 아니야. 보이는 것만 적어 줘.)

## 가게가 직접 적은 휴무를 찾는 곳 (보이는 것만)
1. 네이버 지도 장소 화면의 **소식 · 알림**(사장님이 쓴 글), 그리고 장소 정보의 영업시간 아래 "사장님이 직접 등록" 같은 표시가 있는지
2. 카카오맵 장소 화면의 **사장님 공지 · 소식**
3. 가게 **공식 인스타그램 · 블로그 · 홈페이지**가 앱에 링크돼 있으면 그 프로필 소개나 고정 글 (로그인 창이 뜨면 거기서 멈추고 "로그인 필요"로 적어)
4. 앱에 올라온 **가게 사진 중 영업시간 · 휴무 안내판**이 찍힌 사진 (사진 날짜가 보이면 같이)

## 가게마다 적을 것
- 지금_네이버휴무 · 지금_카카오휴무 · 지금_구글휴무: 오늘 화면에 보이는 휴무 (없으면 "표시 없음", 가게를 못 찾으면 "못 찾음")
- 가게공지_휴무: 가게가 직접 적은 휴무 문구 (100자 이내 인용). 못 찾으면 "못 찾음"
- 가게공지_출처: 1~4 중 어디 + 글 · 사진 날짜 (보이는 대로)
- 맞는_앱: 가게 공지와 휴무가 같은 앱 (예: "네이버", "네이버·카카오", "없음"). 가게 공지를 못 찾으면 빈칸
- 메모: 임시휴무 · 휴무일 변경 공지 · 폐업 표시 등 눈에 띄는 것

## 꼭 지킬 것
- 로그인하지 마. 리뷰 쓰기 · 저장 · 좋아요 · 정보 수정 제안을 누르지 마
- 가게에 전화하지 마. **전화번호는 적지 마.** 작성자 정보 · 리뷰 본문은 적지 마
- 가게 사이에 3초 이상 쉬어. 캡차 · 접속 제한이 나오면 그 사이트는 멈추고 나머지만 계속, 우회하지 마
- 보이지 않는 값을 추측하지 마

## 답변 형식
아래 CSV를 코드 블록 하나로. 한 가게당 한 줄, 값에 쉼표가 있으면 큰따옴표로.

```
번호,상호,지금_네이버휴무,지금_카카오휴무,지금_구글휴무,가게공지_휴무,가게공지_출처,맞는_앱,메모
```

CSV 다음에 "가게 공지를 찾은 가게 수"와 "맞는_앱"별 개수를 적어 줘.
