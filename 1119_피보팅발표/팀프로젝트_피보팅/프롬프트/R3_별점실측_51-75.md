# 별점 실측 R3 — 같은 가게의 네이버 · 카카오 · 구글 별점 · 리뷰 태그 비교 (51~75번, 25곳)

너는 지도 앱 화면을 확인하는 조사 도우미야. 아래 대구 식당 25곳을 **네이버 지도 · 카카오맵 · 구글 지도**에서 각각 찾아서, 화면에 보이는 별점 · 리뷰 수 · 리뷰 태그를 적어 줘.

## 찾는 법
- 상호 + 주소로 찾고, **주소가 같은 가게인지 꼭 확인**해. 다른 가게면 "다른 가게"로 적고 넘어가
- 못 찾으면 "없음", 폐업 표시가 있으면 영업표시 칸에 그대로 적어
- 웹(map.naver.com · map.kakao.com · google.com/maps)에서 확인

## 적을 것 (화면에 보이는 그대로, 없으면 빈칸)
- 네이버: 별점(보이면) · 방문자 리뷰 수 · 블로그 리뷰 수 · 키워드 리뷰 상위 3개와 숫자(예: 음식이 맛있어요 120) · 영업 상태 문구(영업 중 / 휴무 / 폐업 등)
- 카카오맵: 별점 · 후기 수 · 블로그 리뷰 수 · 태그 상위 3개(있으면) · 영업 상태 문구
- 구글 지도: 별점 · 리뷰 수 · 리뷰 주제 칩 상위 3개(있으면) · 영업 상태 문구 (영구 폐업 · 임시 휴업 등)

## 꼭 지킬 것
- 로그인하지 마. 리뷰 쓰기 · 저장 · 좋아요 누르지 마
- 가게 사이에 3초 이상 쉬어. 캡차 · 접속 제한이 나오면 그 사이트는 멈추고 나머지만 계속, 우회하지 마
- 보이지 않는 값을 추측하지 마
- 리뷰 본문 · 작성자 정보는 적지 마

- _찾음: 찾음 / 다른 가게 / 없음 / 막힘
