## C. 한국리서치 「외식 행태와 맛집 선택 기준」 — 전국 만 18세 이상 1,000명 웹조사, 2025-01-03~06
원문: https://hrcopinion.co.kr/archives/32338 (확인일 2026-11-19, 브라우저로 직접 읽음) · 표본오차 ±3.1%p(95%) · 비례할당, 마스터샘플
등급: ⑤ 행동 방식 질문에서 B, ① 규모 질문에서는 민간 조사(C) — 전국 값이라 대구 값이 아님

| 항목 | 값 |
|---|---|
| 음식점 고를 때 참고하는 정보 (1~3순위) | 주변 사람 추천 52% · 과거 경험 · 기억 45% · **지도 앱 22%** · SNS 17% · 블로그 17% · 식당 예약 · 리뷰 앱 17% · 맛집 추천 앱 16% · 배달앱 15% |
| 지도 앱 참고 — 연령별 | 18~29세 46% · 30대 32% |
| 블로그 참고 — 30대 | 37% (SNS 28%) |
| 영향을 받는 정보 | 서비스 · 위생 평가 89% · 가격대 87% · 음식 설명 · 평가 78% · **별점 72%** · 리뷰 수 64% · 예약 · 웨이팅 현황 63% · 음식 사진 62% · 인증 이력 50% |
| 별점에 영향 — 2 · 30대 | 80% 이상 |
| 반드시 고려하는 요인 | 맛 64% · 위생 · 청결 46% · 가격 36% · 식재료 33% · 친절 31% · **주차 편리성 28%** · **접근성(교통 · 소요시간) 27%** · 쾌적함 24% |
| 주차 편리성 — 연령별 | 40대 이상은 3명 중 1명, 30대 23%, 18~29세 11% |
| 미리 찾아보고 계획 / 그때그때 | 38% / 59% |
| 줄이 길면 다른 곳으로 | 65% (기다림 31%) |
| 마음에 든 맛집 재방문 / 새 맛집 | 87% / 11% |

읽는 법
- 별점은 72%가 영향을 받는 정보 → "별점 비교가 중요하다"는 생각을 지지 (2 · 30대는 80% 이상)
- 예약 · 웨이팅 현황에 63%가 영향, 줄이 길면 65%가 다른 곳으로 감 → 가게 리뷰의 웨이팅 불만(L6)과 같은 방향
- 주차 편리성을 반드시 고려하는 사람 28%, 40대 이상은 3명 중 1명 → 실태조사(주차 불편 40대 25.0%)와 같은 방향
- 참고 정보가 한 가지가 아님: 주변 추천 · 지도 앱 · SNS · 블로그 · 리뷰 앱이 비슷한 크기로 나뉨 → 여러 곳을 같이 본다는 VOC(M1)와 같은 방향
