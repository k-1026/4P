# 출처 등급 기준 (2026-11-19 사용자 제공 — L.L.M Academy Day 02 「리서치 루프 실행법」 26쪽)

| 등급 | 종류 | 대구 예시 | 쓰임 |
|---|---|---|---|
| **A** | 공식 통계 · 법정 계획 · 공공데이터 원본 | KOSIS · 한국부동산원 임대동향조사 · 2040 대구 도시기본계획 | 숫자와 공식 사실의 출처 |
| **B** | 공공기관 · 연구원 보고서, 공식 백과 | 대구정책연구원 보고서 · 디지털대구문화대전 · 한국관광 데이터랩 | 해석과 배경 설명의 근거 |
| **C** | 언론 보도 | 매일신문 · 경북매일 · 대구MBC | A · B를 찾는 단서, 최신 동향 확인 |
| **D** | 블로그 · SNS · 커뮤니티 · 리뷰 | 네이버 블로그 · 인스타그램 · 지도 앱 리뷰 | 분위기 · 체감 · 트렌드용. **숫자 근거로 사용 금지** |

## 규칙
- **숫자는 A 또는 B 등급에서만.** C 등급 기사의 숫자는 인용한 기관을 찾아가 원본 확인
- 교차검증: 독립 출처 2곳 이상 (같은 보도자료를 받아 쓴 기사 5개 = 출처 1개)
- 기록 형식: 주장 한 줄 + 출처 링크 + 출처 등급 + 기준 시점 + 확인일

## 리서치 루프 다섯 단계
1. 질문 정의 — 답의 종류가 하나인 질문으로 쪼개기 (숫자 / 역사 / 방문객 등)
2. 검색 · 수집 — 넓게 훑고 좁게, 1차 출처부터 (숫자는 만든 기관, 계획은 세운 기관). 기사 · 블로그는 단서로만
3. 출처 등급 확인 — 위 표로 판정
4. 교차검증 — 독립 출처 2곳 이상
5. 저장 · 기록 — 기준 시점까지

## 중요: 등급은 "찾는 정보의 종류"에 따라 달라진다 (2026-11-19 사용자 설명)

위 표는 숫자 · 공식 사실을 찾을 때의 등급이다. **찾는 정보가 바뀌면 A가 되는 출처도 바뀐다.**
- 예: 입지 문제(주차장 · 거리)는 공공데이터로 찾으니 공공데이터가 A
- 예: 가성비처럼 사람이 느끼는 것은 VOC가 중요하니 VOC가 A

→ 질문을 "답의 종류가 하나"가 되게 쪼갠 뒤, 질문 종류마다 등급표를 따로 둔다 (2026-11-19 사용자 확정)

| 질문 종류 | 예 | A | B | C · D |
|---|---|---|---|---|
| ① 규모 · 비율 (몇 %가 그런가) | 주차가 불편했던 방문객 비율 | 공식 통계 · 원시자료 (실태조사, KREI) | 공공기관 · 연구원 보고서, 데이터랩 | 민간 조사(C), VOC 건수(D, 숫자 금지) |
| ② 사실 · 상태 (실제로 어떤가) | 주차장 위치, 역까지 거리, 영업 여부 | 공공데이터 원본 (인허가, 공영주차장 현황, 역 좌표) | 지도 앱 화면을 직접 본 실측 | 리뷰에 적힌 말(D) |
| ③ 앱에 무엇이 있나 | 앱별 별점 · 리뷰 수 · 주차 정보 유무 | 앱 화면을 직접 잰 실측 (무작위 표본) | 앱 회사 공식 안내 | 기사 · 블로그 |
| ④ 체감 · 이유 · 표현 (왜, 어떻게 느끼나) | 가성비, 리뷰 불신, 헛걸음 경험 | VOC · 리뷰 (고르지 않고 모은 것) | 설문 주관식, 찾을 것을 정하고 모은 VOC | 기사에 실린 사례 |
| ⑤ 행동 방식 (어떻게 하나) | 식당을 어디서 찾고 무엇을 확인하나 | 공식 조사 문항 (실태조사 정보 경로 등) | 민간 조사, 고르지 않고 모은 VOC | 팀 설문(편의표본) |
| ⑥ 규칙 · 제도 | 다른 앱 정보를 가져다 써도 되나 | 법령 · 약관 원문 | 기관 해설 | 기사 |
