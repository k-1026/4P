# 페인포인트 가설 정의서 (초안) — 여러 지도 앱 별점 · 리뷰 모아 보기 (2026-11-19)

> 피드백: "여러 사이트 정보를 한곳에 모으는(통합) 쪽으로 가면 좋겠다"
> 서비스 범위: **대구 식당**. 고객은 정하지 않고 **VOC에서 찾는다** (사용자 결정 11-19)
> 과정: ① VOC 모으기 → ② 분류 에이전트 → ③ 채점 에이전트 + 사람 10건 대조 → ④ 페르소나 → ⑤ 레드팀 3개
> 이 문서는 ②에서 분류 에이전트가 쓰는 **태그 기준**이다. 팀이 확정하기 전까지 초안.

## 확인하려는 가설

> 11-19 추가 가설(사용자): "앱마다 가진 정보가 달라서(예: 주차 안내는 네이버에만), **모자란 정보를 합쳐서 보완해 보여 주면** 좋겠다." → M9와 정보 격차 실측(R6)으로 확인

"식당을 고를 때 **네이버 · 카카오 · 구글을 번갈아 보는 번거로움**이 있고, 사람들은 그 수고를 줄이고 싶어 한다."

반대 가설도 같이 모은다: "한 앱이면 충분해서 비교하지 않는다."


## 방향 (11-19 오후 사용자 결정)

- 세 가지 모두 **후보**이고, 합치는 것도 긍정적: ① 별점 비교(중요하게 봄) ② 모자란 정보 보완 ③ 입지 정보(주차 등) — **③은 ②에 포함**
- 입지 만족 · 불만은 **식당 고르는 손님**에게 보여 줄 정보
- 고객은 계속 **VOC에서 찾는다** (대구 사는 사람 · 외지 방문객 둘 다 봄)
- **확실한 근거 위에서 진행**: 근거마다 급(정확도)을 따져, 급이 높은 자료를 우선
- 정보를 먼저 다 준비한 뒤 진행. 애매한 것은 추정하지 않고 사용자에게 질문

> **2026-11-19 저녁: 태그 기준은 `분류기준_18태그.md`로 바뀜** (M10 · I1 추가, 글 안의 이야기마다 한 줄, 정보성격 · 결과 · 미리찾아봤나 칸 추가). 아래 13태그 표는 이전 기준으로 남겨 둠.

## 태그 (허용 13개) — 11-19 사용자 결정으로 M6 · H2, 이어서 M7 · M8, 이어서 M9 추가

> **"곳"(정보 출처)의 범위 (11-19 V1b 사람 대조 결정):** 지도 앱 · 리뷰 사이트뿐 아니라 **SNS · 블로그 · 커뮤니티 · 단톡방(여행방 등) · 지인(친구 · 가족)**도 모두 출처로 센다. M1 · M3 · H1 · H2에 똑같이 적용.

| 태그 | 이름 | 이런 글이면 | 예시 문장 (가상, 판정 연습용) |
|---|---|---|---|
| **M1** | 여러 곳을 번갈아 봄 | 두 곳 이상(위 출처 범위)에서 확인한다고 직접 씀, 또는 여러 정보가 모인 곳(여행방 등)에서 찾아 모아 둠 | "네이버 보고 카카오도 보고 구글까지 봐요" |
| **M2** | 앱마다 평가가 달라 헷갈림 | 앱 사이 별점 · 평가 차이 때문에 판단이 어렵다고 씀 | "카카오는 3점대인데 네이버는 4.7이라 뭘 믿어야 할지" |
| **M3** | 한 곳만으론 못 믿어 교차 확인 | 한 곳을 못 믿어 다른 곳에서 확인함, 또는 "검증된(여러 곳에서 확인된) 것만 믿는다" | "네이버는 리뷰 이벤트가 많아서 구글 별점으로 거름" |
| **M4** | 리뷰가 많아 읽기 귀찮음 · 고르기 어려움 | 리뷰를 다 읽기 힘들다, 후기가 많아도 고르기 어렵다, 핵심만 보고 싶다 | "리뷰 수백 개 언제 다 읽어요" |
| **M5** | 앱마다 가게 정보가 다름 | 영업시간 · 휴무 · 폐업 표시가 앱마다 달라 헛걸음 · 혼란 | "카카오엔 영업 중인데 네이버엔 폐업으로 나와요" |
| **M6** | 한 앱 표시가 실제와 다름 (헛걸음) | 다른 앱 언급 없이, 앱의 영업 중 · 영업시간 · 폐업 · 업종 등 가게 표시가 실제와 달랐다 (11-19 사람 대조로 업종 포함) | "영업중이라 해서 갔는데 문 닫았어요" |
| **M7** | 리뷰 · 별점을 못 믿음 | 리뷰 · 별점을 믿지 못한다고 말하지만 다른 곳에서 확인한다는 말은 없음 | "네이버 후기는 진짜 믿지마" |
| **M8** | 별점으로 1차 거름 | 한 곳의 별점을 첫 거름망(예: 4.0 이상)으로 쓰고 그다음 더 고민 · 비교함 | "구글 4.0 이상이면 가볼까 고민해요" |
| **M9** | 필요한 정보가 앱에 없음 · 부족함 | 주차 · 메뉴 · 가격 · 혼밥 · 예약 · 휴무 등 **알고 싶은 가게 정보가 없거나 부족해서** 따로 찾아봤다 · 물어봤다 · 가서 당황했다. (표시가 틀린 것은 M6, 앱끼리 다른 것은 M5) | "주차 되는지 어디에도 안 나와서 전화해 봤어요" |
| **H1** | 한 곳으로 충분 (반대 근거) | 한 곳만 본다, 비교할 필요 없다 — 다른 곳과 비교한 말은 없음 | "그냥 네이버만 봐요" |
| **H2** | 비교 끝에 한 곳으로 갈아탐 | 두 곳 이상을 비교해 본 뒤 믿는 한 곳만 쓴다 | "네이버는 이벤트 리뷰라 못 믿고 카카오맵만 봐요" |
| **해당없음** | 관련 없음 | 위 어디에도 해당하지 않음 | |
| **검토** | 애매함 | 여러 원인이 섞임 · 전해 들은 말 · 판단 어려움 (note에 이유) | |

## 판정 규칙

- 원문 그대로 인용(15자 이내)이 모든 행에 있어야 한다. 요약 · 의역 금지
- 한 글에 여러 태그가 해당하면 **가장 강하게 말한 것 하나**, 둘이 비슷하면 `검토`
- 글에 없는 상황 · 지역은 지어내지 않고 `모름`
- `검토`는 전체의 5% 이하
