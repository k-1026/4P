| 결론 | **불편이 있다는 근거는 있지만**, 그 불편을 겪는 사람이 **얼마나 되는지**, 정보를 주면 **풀리는지**, **우리 서비스를 쓰려는지**는 데이터가 없다 |
|---|---|

| 항목 | 상태 |
|---|---|
| 식당 영업 · 휴무가 틀려 헛걸음한 사람의 비율 | 데이터 없음 |
| 주차 정보를 미리 찾는 사람 · 주차 때문에 식당을 바꾼 사람의 비율 | 데이터 없음 |
| 정보를 주면 불편이 줄어드는지 | 데이터 없음 |
| 새 서비스를 쓰려는지 | 데이터 없음 |
| 대구에 사는 사람의 식당 정보 불편 | 데이터 없음 (2026 대구사회조사는 12월 공표) |
| 행동 값의 대구 방문객 기준 수치 | 데이터 없음 (조사 대부분이 전국 값) |
