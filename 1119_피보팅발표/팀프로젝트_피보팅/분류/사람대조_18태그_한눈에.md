| 라. 한 곳이면 된다 | **H1** 한 곳으로 충분 | 한 곳만 본다 (영상 하나, AI 검색 하나 포함) |
| | **H2** 비교 끝에 한 곳으로 갈아탐 | 다른 곳과 견주어 믿는 한 곳을 쓴다 |
| 라-2. 고르는 방식 | **S1** 사람에게 추천을 구함 | 사람에게 식당을 추천해 달라고 함. 그 글에 딸린 조건 조각도 S1 |
| | **S2** 고르는 기준 · 요령 | 무엇을 보고 고르는지 (최근 리뷰, 리뷰 수, 주문 수, 업력) |
| 마. 정보를 주는 글 | **I1** 정보 공유 | 알게 된 가게 정보를 남에게 알려 줌 |
| 바. 그 밖 | **해당없음** | 이유 칸: 앱 기능 / 맛 · 서비스 평가 / 식당 아님 / 내용 없음 / 기타 |
| | **검토** | 원문이 잘려 뜻을 알 수 없음 |
