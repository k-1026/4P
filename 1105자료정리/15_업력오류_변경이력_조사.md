# 업력 오류와 변경 이력 조사

> 대표자 이름은 개인정보이므로 조회와 파일에서 내용을 출력하거나 저장하지 않고, 형태와 날짜만 다뤘습니다.
> 상위 30곳 조회는 **문서 작성 시점에 진행 중**입니다. 아래 수치는 13곳의 중간 결과입니다.

## 문제

인허가를 이어받으면 인허가일이 그대로 남습니다. 그래서 인허가상 40년 된 가게가 실제로는 최근에 생긴 가게일 수 있습니다.

## 행안부 이력 API (`/history`)

2026년 1월 이후 시점의 기록만 제공합니다. 같은 관리번호를 시점별로 비교했습니다.

| 인허가일 | 2026년 1월 상호 | 현재 상호 | 변경 시기 |
|---|---|---|---|
| 1971-03-07 | 핸즈 경대병원점 | 컴포즈커피 대구경북대병원점 | 1~5월 사이 |
| 1978-06-07 | 돌담 (한식) | 카페 무던 (기타) | 1~5월 사이 |
| 1978-04-22 | 자야 (소주방) | 르폴뒤 | 9월 이후 |
| 1975-08-13 | 성주 (기타) | 서문닭강정 | 9월 이후 |

`동흥반점`, `진시흥국수방`은 세 시점 모두 상호가 같았습니다. 다만 소유자 변경 여부는 이 API에 없습니다.

## 식약처 변경 정보 API (I2861, 공공데이터포털 15145167)

주인 변경 시점을 잡을 수 있는 자료입니다. 팀 문서(`02_일반음식점_인허가데이터_수집과_업력분석.md`)에 조사되어 있던 내용을 다시 확인했습니다.

| 항목 | 내용 |
|---|---|
| 주소 | `apis.data.go.kr/1471000/FoodRstrtLcnsChgInfo01/getFoodRstrtLcnsChgInfo01` |
| 조회 조건 | 업소명, 인허가번호 |
| 결과 | 업소명, 업종, 인허가번호, 주소(구까지), 변경일자, 변경 전후 내용, 변경 사유 |
| 비용·승인 | 무료, 개발 계정 자동 승인, 10,000건 |
| 샘플의 변경 구분 | `소유자 또는 대표자`, `영업소 명칭 또는 상호` |

**제약**
- 공공데이터포털 버전에는 샘플에 있는 변경 구분 칸이 없어 내용 형태로 유형을 추정합니다.
- 인허가번호와 행안부 관리번호를 바로 연결할 수 없어 상호와 구로 찾습니다.
- 상호로만 찾으므로 그 이전 상호로 된 기록은 빠질 수 있습니다.

## 상위 30곳 중간 결과 (13곳)

| 항목 | 결과 |
|---|---|
| 중구에서 변경 기록이 있는 곳 | 13곳 중 13곳 |
| 대표자 변경 추정이 있는 곳 | 7곳 |
| 상호 변경 추정이 있는 곳 | 12곳 |
| 가장 이른 변경 기록 | 1972-10-26 |
| 인허가번호 | 13곳 모두 중구에서 1종류 |

**읽히는 내용**
- 2026년 이전, 심지어 **1970~1990년대 변경까지** 기록이 있습니다.
- 앞서 "2026년 이전 변경은 찾을 수 없다"고 한 판단은 **틀렸습니다**.
- 다만 유형은 추정입니다. `기타`가 많고, 상호 추정에는 실제 변경이 아닌 기록이 섞였을 수 있어 내용 검증이 필요합니다.

스크립트: `step5_change_history.py`, 결과: `시험_변경이력_상위군.csv`

## 남은 문제

- **대물림:** 부모에서 자녀로 넘어간 가게도 대표자 변경으로 나옵니다. 성 비교는 개인정보 문제와 오판 위험이 있어 권하지 않습니다.
- **형식적 변경:** 법인 대표 변경처럼 운영이 그대로인 경우를 구분하지 못합니다.
- **대구 전체 적용:** 가게당 호출이 필요하고 서버가 느립니다(약 1~2분에 1곳 수준). 영업 중 가게 전체는 시간이 많이 걸리므로 상위권부터 적용하는 방법을 검토해야 합니다.

## 그 밖의 점검 방법

| 방법 | 내용 | 한계 |
|---|---|---|
| 업태·메뉴 불일치 | 옛 업태와 현재 메뉴가 안 맞으면 표시. 예: 경양식 41년인데 팟타이 | 의심 표시일 뿐, 메뉴가 그대로면 못 잡음 |
| 상위권 사람 확인 | 공식 명단, 기사, 블로그 | 수작업 |
| 업력 등급 | `업력 확인됨`, `인허가 기준`, `업력 확인 필요` | 제안 단계 |

## 수성구 기록 문제

수성구는 영업 중 가게의 인허가가 1990년대 이전 12건, 2000년대 1,342건입니다. 2000년쯤 일괄 재등록됐을 가능성이 있습니다(추정). 수성구 카드에는 기록 제한을 함께 표시해야 합니다.
