# 데이터 분석 방법론 검토

> 논문은 검색 결과의 요약 수준으로 봤고 전문을 읽지는 않았습니다.

## 결론

**[AI 판단]** 우리 데이터에는 **지연 진입을 넣은 카플란-마이어**가 가장 맞습니다. 복잡한 모델보다 데이터 조건에 맞는 보정이 먼저입니다.

## 좌측 절단 문제

중구 데이터의 가장 이른 폐업 기록은 **1999년**입니다.

| 폐업 연도 | 건수 |
|---|---|
| 1995~1999 | 2 |
| 2000~2004 | 1,111 |
| 2005~2009 | 1,261 |
| 2010~2014 | 962 |
| 2015~2019 | 1,061 |
| 2020~2024 | 1,559 |
| 2025~ | 757 |

1980년대에 개업해 1995년에 폐업한 가게는 데이터에 없는 것으로 보입니다. 살아남은 가게만 남으면 오래된 시기의 생존율이 부풀려집니다.

- **영향:** `08_버팀지수_계산비교.md`의 KM 중위값은 실제보다 길게 나왔을 가능성이 큽니다.
- **근거 수준:** 왜 기록이 없는지 공식 설명은 확인하지 못했습니다. 데이터 모양을 보고 추정한 것입니다.
- **보정:** 오래된 가게는 개업일이 아니라 관측이 시작된 시점부터 위험 집단에 넣습니다 (지연 진입).

## 방법별 판단

| 방법 | 내용 | 판단 | 쓰는 곳 |
|---|---|---|---|
| 지연 진입 + 카플란-마이어 | 영업 중과 관측 시작 전 개업을 함께 처리 | **필수** | 버팀지수 기준값 |
| 깔때기 그림 / 경험적 베이즈 | 작은 그룹의 수치 조정, 불확실성 표시 | **채택** | 상권 생존 지도 |
| 콕스 비례위험 | 면적, 업태, 개업 시기의 영향 분석 | **나중에** | 정책 리포트, 지수 검증 |
| 연도별 폐업 위험 (이산시간) | 연도별 폐업 확률 | **후보** | 코로나 시기 등 연도 효과 |
| 공간 프레일티 | 지역 효과를 모델에 포함 | **보류** | 현재 규모에 비해 복잡함 |
| 와이블 등 분포 가정 | 생존곡선 모양을 가정 | **불필요** | 순위 산출에 필요 없음 |

## 판단 근거

- **카플란-마이어:** 음식점 생존 연구에서 널리 쓰이고, 곡선 모양을 가정하지 않습니다.
- **깔때기 그림·경험적 베이즈:** 작은 집단은 우연만으로 순위의 위나 아래에 오기 쉽습니다. 가게 수가 적은 골목의 폐업률을 칠할 때 필요합니다.
- **콕스:** 이태원 연구에서 단순 비교로 위험이 높던 상권이, 다른 조건을 통제하자 약 29.9% 낮게 나왔습니다. 단순 비교로 결론을 내리면 위험합니다.
- **공간 프레일티:** 서울 상권 연구 발표처럼 쓰인 예가 있지만 구현과 설명 부담이 크고, 상권 경계가 없는 지금은 이득이 불확실합니다.

## 방법론으로 해결되지 않는 것

- **지위승계:** 어떤 모델로도 바로잡히지 않습니다. 이력 데이터나 브랜드 대조가 필요합니다.
- **맛과 수요:** 생존 기간만으로는 증명되지 않습니다.
- **프랜차이즈:** 애선스 연구에서 체인 여부가 폐업과 관련이 있었습니다. 분리할 근거가 되지만 미국 사례입니다.
- **근거 범위:** 인허가 자료로 지수를 만들어 소비자용 순위에 쓴 사례는 이번 검색에서 찾지 못했습니다. 버팀지수 자체는 우리가 검증해야 합니다.

## 기능별 추천 계산

| 기능 | 계산 |
|---|---|
| 버틴집 순서 | KM 배수 |
| 가게 이야기 카드 | 개업 연도, 업력, KM 중위 대비 배수, 생존확률 |
| 상권 생존 지도 | 상권별 생존 중위값, 3년 생존율, 연간 폐업률. 깔때기 또는 경험적 베이즈 적용 |
| 떠오르는 집 | 같은 개업 연도·업태의 생존율과 비교. 개업 후 1년 생존율이 80~90%대라 구별력이 약함 |

작은 그룹은 일정 수(시험에서는 30곳) 미만이면 상위 그룹을 기준으로 씁니다. 숫자는 분포를 본 뒤 정해야 합니다.
