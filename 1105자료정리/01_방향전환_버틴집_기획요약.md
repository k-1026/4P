# 방향 전환: 버틴집 기획 요약

> 근거 문서: `버틴집 서비스 기획서_찬영` (2026-10-30)

## 방향 전환

- **[사용자]** 2026-11-05: 찬영 님 기획서의 아이디어로 방향을 바꿨습니다.
- 이전 방향은 여행객이 상황을 입력하면 조건에 맞는 음식점을 찾아 주는 지도였습니다. 영업시간과 메뉴 등 "빈 정보 채우기"가 핵심이었습니다.
- 새 방향의 핵심은 개업·폐업일자로 **오래 버틴 가게**를 찾는 것입니다.
- **[사용자]** 서비스 이름은 바꿀 예정입니다. 새 이름은 아직 정하지 않았습니다.

## 기획 핵심

| 항목 | 내용 |
|---|---|
| 캐치프레이즈 | 동네가 먹여 살린 가게 |
| 대상 지역 | 대구 (검증 후 전국 확장) |
| 핵심 가설 | 동종 업종 평균보다 오래 영업한 가게는 수요가 검증된 가게다 |
| 핵심 데이터 | 일반·휴게음식점 인허가 데이터 (개업·폐업일자) |
| 노출 원칙 | 순서는 버팀지수로만 정하고, 유료 광고 자리는 두지 않음 |

## 지표

```
버팀지수 = 해당 가게의 영업 기간 ÷ 동일 상권·동종 업종의 평균 영업 기간
```

1보다 크면 주변 평균보다 오래 살아남은 가게입니다.

`검증됨` 표시는 버팀지수, 상권 대비 생존, 시민 반응 데이터가 모두 겹치는 가게에만 붙입니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 버틴집 지도 | 버팀지수 상위 가게 표시, `검증됨` 배지 |
| 상권 생존 지도 | 상권별 평균 영업 기간과 폐업률을 색으로 표현 |
| 떠오르는 집 | 업력 3년 미만이지만 주변 대비 생존 속도가 빠른 가게 |
| 가게 이야기 카드 | 개업 연도, 업종 평균 대비 버틴 기간 요약 |
