# 근거 자료: 공공 산식과 논문

> **확인 수준**을 함께 적었습니다. "검색 요약"은 원문을 읽지 않았다는 뜻입니다.

## 공공 산식

| 지표 | 사용 기관 | 산식 | 확인 |
|---|---|---|---|
| n년 생존율 | 서울시 상권분석서비스 | (t−n)년 신생기업 중 t년까지 생존한 수 ÷ (t−n)년 신생기업 수 × 100 | 페이지 확인 |
| 평균영업기간 | 서울시 상권분석서비스 | (폐업신고일 − 개업신고일)의 평균. 최근 10년, 최근 30년 기준 | 페이지 확인 |
| 개·폐업률 | 서울시 상권분석서비스 | 당기 개·폐업 신고 점포 수 ÷ 전체 점포 수 × 100 | 페이지 확인 |
| 상권변화지표 | 서울시 (팀 조사) | 행정동 평균 영업기간을 서울시 생존·폐업 평균과 비교해 4등급 | **페이지에서 찾지 못함** |
| 평균 존속연수 | 국세청 생활업종 통계 | 산식 없음. 한식전문점 6년 5개월 (2018~2022년) | 기사 확인 |
| 백년가게 업력 | 중소벤처기업부 | 업력 30년 이상 중 종합 평가 | 2020년 기사 확인. 현재 기준 재확인 필요 |

국세청 값은 산식이 없어 우리 값과 직접 비교하면 안 됩니다.

## 우리 지표와의 관계

| 항목 | 말할 수 있는 수준 |
|---|---|
| 생존배수의 분모 | 서울시 평균영업기간과 같은 계산, 단위는 구·업태 |
| 생존배수의 배수 계산 | 공공 산식을 바탕으로 **우리가 만든 지표** |
| 상권 생존 지도 | 공공 생존율, 폐업률 응용 |

## 1번: 데이터 품질 근거

| 주장 | 근거 | 확인 |
|---|---|---|
| 잘못 이어진 기록이 개업·폐업을 왜곡 | BLS 2016: 과대 집계는 지표를 부정확하게 함. 상호·전화·승계 관계로 연결, 큰 미연결 건 사람 검토 | 원문 확인 |
| 연속성은 공식 기준으로 판단 | Eurostat-OECD 매뉴얼: 지배 주체, 활동, 위치. 소유권 변경만으로는 폐업 아님(26쪽), 활동과 위치 모두 변경 시 폐업 후 개업(29쪽) | 원문 일부 확인 |
| 소유권 변경은 분석에서 따로 처리 | Luo & Stark: 소유권 변경 시 관측 종료. 폐업으로 세지 않음. 체인 제외 | 원문 확인 |
| 체인은 분리 | Parsa 외 2011: 체인 실패율이 독립 음식점보다 낮음 | 검색 요약 |
| 오래전 폐업이 빠지면 실패율이 낮아 보임 | Yang & Aldrich 2012 | 검색 요약 |

## 2번: 생존 비교 근거

| 주장 | 근거 | 확인 |
|---|---|---|
| 음식점 수명은 생존분석으로 측정 | Luo & Stark: 미국 서부 독립 음식점 약 8만 1천 곳, 중위 수명 약 4.5년 | 원문 확인 |
| 한국 인허가 자료 활용 | 서울 치킨집 폐업 예측: 인허가 개·폐업 신고일, 분류 모델 | 초록 확인 |
| 상권 비교는 조건을 함께 봐야 함 | 이태원 음식점 연구: 단순 비교와 통제 후 결과가 반대 | 검색 요약 |
| 효율적인 기업이 살아남음 | Jovanovic 1982: 경제학 이론. 맛의 증명 아님 | 초록 수준 |
| 평가가 낮은 음식점이 더 많이 폐업 | Luca & Luca: Yelp 후원 연구 | 보도 수준 |

## 찾지 못한 것

- 생존배수 공식을 제안하거나 검증한 논문
- "오래 버틴 가게 = 동네 수요가 검증된 가게"를 직접 검증한 연구
- 인허가 지위승계 왜곡을 다룬 학술 논문 (기사만 찾음)

검색 범위가 작으니 없다고 단정할 수 없습니다. RISS, KCI에서 `음식점 생존분석`, `지위승계 폐업`을 더 찾아볼 수 있습니다.

## 발표에서 쓸 수 있는 말

- **가능:** "공식 통계 기준과 선행 연구에 따라 기록의 연속성을 점검하고, 소유권 변경을 별도로 처리했습니다."
- **가능:** "생존분석은 음식점 연구의 표준적인 방법이고, 생존배수는 이를 쉽게 설명하기 위해 만든 지표입니다."
- **불가능:** "오래 버틴 가게는 맛집으로 검증됐습니다."
