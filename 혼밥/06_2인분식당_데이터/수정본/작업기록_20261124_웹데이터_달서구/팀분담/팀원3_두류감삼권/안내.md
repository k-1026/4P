# 혼밥 달서구 식당 지도 수집 — 팀원3_두류감삼권

우리 웹페이지에 넣을 **달서구 식당이 1인분을 파는지, 혼자 가도 되는지**의 근거를 모으는 일입니다.
Aside가 네이버 지도·카카오맵을 열어 메뉴, 메뉴판 사진, 사장님 답글, 방문자 리뷰를 읽고 CSV로 적어 줍니다. 판정은 나중에 한곳에서 합니다. **여기서는 모으기만** 하면 됩니다.

| 맡은 범위 | |
|---|---|
| 행정동 | 두류1.2동, 두류3동, 감삼동, 성당동, 죽전동, 본리동 |
| 가게 수 | 1,349곳 (`대상목록.csv`) |
| 묶음 | 54개 (`prompt_000.txt` ~ , 한 묶음 25곳) |

## 1. 준비 (처음 한 번)

1. **Aside 앱**을 설치하고 로그인합니다. 브라우저가 Aside와 연결되어 있어야 합니다.
2. PowerShell에서 `aside --version`이 나오는지 확인합니다. 안 나와도 `수집.ps1`이 기본 설치 위치를 찾아 줍니다.
3. 이 폴더를 통째로 바탕화면 같은 곳에 둡니다. **prompt 파일은 고치지 마세요.**

## 2. 수집 (방법 A: 자동, 추천)

이 폴더에서 PowerShell을 열고:

```powershell
powershell -ExecutionPolicy Bypass -File .\수집.ps1
```

- 묶음을 3개씩 동시에 돌립니다. 한 묶음에 15~25분쯤 걸립니다.
- 컴퓨터와 브라우저를 켜 두세요. 절전 모드가 되면 멈춥니다.
- 중간에 끊기거나 창을 닫았으면 **같은 명령을 다시 실행**하세요. 끝난 묶음은 건너뜁니다.
- 네이버가 막는 것 같으면(결과가 계속 비거나 오류) 동시 개수를 줄입니다: `... -File .\수집.ps1 -Par 2`
- Mac이면 터미널에서 `PAR=3 bash run_all.sh`.

## 2'. 수집 (방법 B: 손으로, 자동이 안 될 때)

1. `prompt_000.txt`를 열어 **전체를 복사**해 Aside 채팅에 붙여넣고 실행합니다.
2. 끝나면 Aside가 준 **CSV 답 전체를 복사**해서 `out_000.csv`라는 이름으로 이 폴더에 저장합니다(메모장 → 다른 이름으로 저장 → 인코딩 UTF-8).
3. `prompt_001.txt` → `out_001.csv` … 번호를 꼭 맞춰 주세요.

## 3. 마무리

모든 묶음이 끝나면:

```powershell
powershell -ExecutionPolicy Bypass -File .\마무리.ps1
```

두 파일이 생깁니다.

| 파일 | 내용 |
|---|---|
| `결과_팀원3_두류감삼권.csv` | 모은 결과 전체 (엑셀로 열림) |
| `결과_팀원3_두류감삼권.md` | 맡은 범위(포함한 것), 결과 요약, 빠진 가게 목록, 메모 칸 |

`결과_….md` 맨 아래 **메모** 칸에 수집하면서 있었던 일(막힘, 이상한 점)을 적고, **두 파일을 보내 주세요.** 가능하면 `out_*.csv` 파일들도 압축해서 같이 보내 주세요(문제 생기면 다시 합치는 데 씀).

## 지킬 것

- 리뷰 작성자 이름·닉네임·사진은 모으지 않습니다(지시문에 이미 들어 있음). 결과를 고치거나 덧붙이지 마세요.
- 결과 파일에는 리뷰 문장 일부가 들어 있으니 **팀 안에서만** 주고받습니다.
- 막히면 혼자 고치지 말고 바로 알려 주세요.
