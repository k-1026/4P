# 작업: 대구 전역 '미상' 가게 손확인 (담당 구·군만)

## 배경
대구에서 "혼자 1인분만 시킬 수 없는 식당"을 데이터로 찾는 조사다. 1차 판정(지도 수집)에서 최소주문이 '미상'으로 남은 가게를,
지도 수집 원문 + 새 블로그 수집 원문을 **직접 읽고** 분류한다. 너는 판정 규칙을 적용만 한다. 규칙을 바꾸거나 새로 만들지 않는다.

## 읽을 파일 (모두 읽기 전용, 절대 경로)
기준 폴더 B = `C:\Users\Green\Desktop\팀프로젝트 - 혼밥`
1. 판정 규칙: `B\2인분식당_데이터체크_및_수집안내.md` 3장 전체 (특히 '판정 적용 기준')
2. 지난번 손확인 예시: `B\매칭도구\작업기록_20261121\manual64.py` (분류 이름과 예)
3. 대상 목록: `B\매칭도구\작업기록_20261124_미상블로그\블로그수집\대상목록.csv` — 이 중 **담당 접두어**로 시작하는 수집ID만.
4. 1차 판정: `B\원본자료\2인분식당_수집양식_대구전역표본_판정_Aside_20261123.csv` (수집ID로 찾음)
5. 지도 수집 원문: `B\원본자료\2인분식당_신호원문_대구전역_Aside_20261123.csv` (수집ID로 찾음)
6. 블로그 수집 원문: `B\매칭도구\작업기록_20261124_미상블로그\블로그수집\blog_out_*.csv` (파일 앞에 설명 글이 있을 수 있음. `"수집ID"` 머리줄부터가 CSV)

## 분류 (손확인_분류, 하나만)
- `블로그_조건2건이상` — 서로 다른 글(블로그·리뷰, 지도 원문 포함) 2건 이상이 **같은 가게**의 2인분 이상 조건(N인분부터, 첫 주문 N인분, 2인 이상 주문 등)을 말함 → 제안_최소주문 = 2인분이상_추정
- `크기메뉴_최소2인` — **대표 메뉴**의 가장 작은 크기가 2인 이상(小 2인 등) → 2인분이상_추정, 인분 = 가장 작은 크기 인원. 대표 메뉴 = 1차 판정 파일의 `대표메뉴` 칸이나 상호에 나오는 메뉴. 대표가 아닌 메뉴(곁들임, 다른 요리)만 2인 크기면 해당하지 않는다 → 미상 유지, 메모에 적음. 대표 메뉴 중 하나라도 1인·1.5인 크기가 있으면 해당하지 않는다.
- `가게규칙_1인1메뉴` — 메뉴판 '1인 1메뉴' → 1인분가능_확정
- `메뉴표기_조건` — 메뉴판 사진·메뉴 표기·사장님 답글에 2인분 이상 조건이 직접 있음 → 2인분이상_확정
- `메뉴표기_1인분` — '1인 세트', '혼밥 메뉴', '나홀로', '1인분 주문 가능'처럼 혼자 주문을 직접 말하는 매장 표기 → 1인분가능_확정
- `조건_1건만` — 2인분 조건을 말하는 글이 1건뿐 → 미상 유지
- `1인분_가격단위만` — '삼겹 1인분 150g'처럼 값·양 단위로만 적힌 1인분 → 미상 유지
- `식사단품_1인분` — 덮밥·장어 1인 등 식사 단품이 1인분으로 적힘 → 미상 유지(메모)
- `배달메뉴만` — 인분 표기가 배달앱 메뉴에만 있음 → 미상 유지
- `1인입장_단서1건` — 혼자 입장 관련 글 1건뿐 → 미상 유지
- `가게_못찾음` — 같은 가게인지 확정 못 함(상호·주소·지점 다름, 폐업 등)
- `정보없음` — 해당 문장 없음

- **범위(제안_범위):** '가게 전체'는 '첫 주문 N인분', '기본 주문 N인분', '최소주문은 N인분', '고기류 최초 주문 N인분'처럼 **가게 전체(또는 고기류 전체)에 거는 조건**일 때만 쓴다. 특정 메뉴 이름에 붙은 조건('닭갈비(2인분부터)', '버섯 칼국수 (2인 이상)')은 그 메뉴가 대표 메뉴여도 '일부 메뉴'다(수집안내 3장 조건_적용범위 예).
- **상호에 나오는 메뉴**(예: '…해장국', '…국밥', '…칼국수')도 대표 메뉴다. 그 메뉴가 1인 식사면 다른 메뉴가 2인 크기여도 크기메뉴_최소2인이 아니다.

1인입장(혼자 들어갈 수 있는지)은 최소주문과 **따로** 본다. 규칙 3장대로: 사장님 답글·매장 메뉴가 있으면 그것으로, 없으면 서로 다른 글 2건 이상일 때만 불가/가능. 시간대를 말하는 거절 2건 이상이면 '불가' + 시간대제한.

## 반드시 지킬 것
- 원문에 **보이는 것만** 쓴다. 모델 지식·추측으로 채우지 않는다. 근거가 없으면 미상.
- 'N인분 이상 주문 시 서비스·무료'는 혜택 조건이라 최소주문 근거가 아니다. 포장·배달·추가 주문('추가는 2인분부터')·리뷰 속 먹은 양('2인분 먹었어요')도 아니다.
- 협찬 표시 글은 근거로 쓰되 메모에 '협찬' 표시.
- 블로그 작성자 이름·닉네임은 쓰지 않는다.
- 같은 글을 두 번 세지 않는다. **블로그는 같은 URL = 1건.** **지도 방문자 리뷰(네이버·카카오)는 모든 리뷰가 같은 목록 URL을 쓰므로, 작성일이나 문장이 다르면 서로 다른 리뷰로 센다**(1차 판정 도구 judge_signals.py와 같은 방식). 같은 리뷰가 두 번 수집된 것(작성일·문장이 같음)만 1건으로 친다.
- 남이 쓴 말을 옮긴 문장(예: '리뷰를 보니 혼자가면 안받아 준다고')은 직접 겪은 근거가 아니므로 세지 않고 메모에만 적는다.
- 위의 읽을 파일은 **하나도 고치지 않는다.** 출력 파일 하나만 새로 만든다.

## 출력
`매칭도구/작업기록_20261124_미상블로그/손확인/손확인_<담당이름>.csv` (현재 작업 폴더 기준, UTF-8 BOM, 모든 칸 따옴표)
담당 대상의 **모든 수집ID를 한 줄씩**(빠짐없이). 칸:
`수집ID,상호,상권_업종소분류,손확인_분류,제안_최소주문,제안_인분,제안_범위,제안_1인입장,제안_시간대제한,근거건수_조건,근거1_원문,근거1_출처,근거1_URL,근거1_작성일,근거2_원문,근거2_출처,근거2_URL,근거2_작성일,메모`
- 제안_최소주문: 2인분이상_확정 / 2인분이상_추정 / 1인분가능_확정 / 미상
- 제안_범위: 가게 전체 / 일부 메뉴 / (빈칸). '첫 주문 N인분'·'기본 N인분부터'는 가게 전체.
- 제안_1인입장: 불가 / 가능 / 미상
- 근거 원문은 파일에 있는 문장을 **그대로** 옮긴다(100자 안쪽). 바꿔 쓰지 않는다.

손으로 하든 스크립트를 쓰든 괜찮다. 스크립트를 쓰면 `매칭도구/작업기록_20261124_미상블로그/손확인/` 안에 두고(파이썬 표준 라이브러리만, `python -I`로 실행), 마지막에 **모든 '미상이 아닌' 제안은 원문을 직접 읽고 확인**한다.

## 확인 (실행하고 결과를 보고)
1. 출력 행 수 = 대상목록.csv에서 담당 접두어 수집ID 수 (같아야 함), 수집ID 중복 없음.
2. 손확인_분류별 개수, 제안_최소주문별 개수.
3. 미상이 아닌 제안마다 근거 원문이 입력 파일에 실제로 있는지 문자열로 대조한 결과(없으면 그 수집ID 목록).
