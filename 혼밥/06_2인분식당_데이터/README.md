# 06 2인분 식당 데이터 (11-21 ~ 11-24)

"혼자 가면 1인분을 시킬 수 없는 식당"을 찾아, 식당마다 **1인분 가능 / 2인분 이상 / 모름**을 판정한다.
공공 식당 목록에 지도·메뉴판·사장님 답글·블로그에서 모은 근거를 붙여 판정하고, 그 결과를 챗봇(`../07_챗봇`)에 넣었다.

## 결과

대구 1차 데이터 **4,487곳** (가게 한 곳당 한 줄, 11-24)

| 1인분 판정 | 곳 수 | 뜻 |
|---|---|---|
| 1인분 확인 | 39 | 메뉴판·사장님 답글에 1인분·1인 메뉴가 적혀 있음 |
| 1인분 추정 | 3,294 | "혼밥" 검색에 나왔고 2인분 이상 자료에 없음 |
| 일부 메뉴 2인분 | 770 | 일부 메뉴만 2인분 이상 |
| 2인분 이상 | 329 | 가게 전체에 2인분(또는 3인분) 이상 조건 |
| 1인분 확인 안 됨 | 55 | 혼자 입장 정보만 있음 |

달서구는 팀원 4명이 행정동을 나눠 네이버 지도·카카오맵을 직접 수집하고 있다.

| 순서 | 프로그램 | 하는 일 |
|---|---|---|
| 1 | `build_frame_daegu.py` | 상권정보에서 대구 전역 2인분 후보 업종 · 비교 업종 목록 만들기 |
| 1 | `build_web_dalseo.py` | 달서구 웹데이터 첫 판(v0) 만들기 |
| 1 | `prefill_daegu.py` | 대구 전역 표본의 수집 양식 미리 채우기 |
| 2 | `make_web_pilot.py` | 지도 수집 지시문 만들기 |
| 2 | `split_team_collect.py` | 달서구 수집을 4명이 행정동별로 나누고 팀원 몫 꾸러미 만들기 |
| 3 | `merge_team_collect.py` | 팀원 수집 결과를 한 폴더로 합치기 |
| 3 | `store_match.py` | 가게 목록 두 개를 상호 · 주소로 맞추기 |
| 4 | `judge_signals.py` | 모은 근거(메뉴 표기 · 사장님 답글 · 리뷰)로 판정 칸 채우기 |
| 4 | `judge_web_pilot.py` | 지도 수집 결과를 웹에 보여 줄 값으로 판정 |
| 4 | `compare_judgments.py` | 두 출처의 판정을 가게마다 대조해 하나로 합치기 |
| 5 | `final_merge.py` · `final_merge_daegu.py` | 판정 · 손확인 · 블로그 근거를 합쳐 최종 판정 (대구 전역 표본 904곳) |

- 프로그램은 작업 컴퓨터의 원자료 폴더를 읽어서 돌아간다. 원자료와 결과 CSV는 공개 저장소라 올리지 않았으므로, 이 폴더만으로는 다시 돌릴 수 없다.
- 프로그램 안에 적힌 경로(`매칭도구/…`, `작업기록_…`)는 작업할 때의 위치다.
