## 채우는 방법

1. 각 항목의 **지금 → 바꾸면**과 **왜**를 읽는다.
2. 근거를 직접 확인했으면 **검증** 칸에 `○`(맞음), `✕`(틀림), `?`(확인 못 함) 중 하나를 쓴다.
3. **팀 결정** 칸에 다음 중 하나를 쓴다.
   - `추천대로`
   - `다르게: (어떻게)`
   - `빼기`
4. 다르게 하거나 ✕를 쓴 경우에는 **메모** 칸에 이유를 쓴다.
5. ✅ 표시 항목은 이미 정한 것이다.
   이견이 있을 때만 메모 칸에 적는다.

표시 뜻:

| 표시 | 뜻 |
|---|---|
| [출처 n] | `sources.md` 번호 |
| [I] | 해석 |
| [U] | 확인 안 됨 |
| ✅ | 이미 정함 |
| ❓ | 정할 것 |

기본 원칙 (2026-11-24 정함):

- 논의 기준은 발표용 html 맵이다.
  md(mermaid 그림 + 근거 표)는 html 결정에 맞춰 고친다.
- 맵에는 화살표와 상자를 늘리지 않는다.
  라벨만 짧게 바꾸고, 숫자와 자세한 설명은 근거 표로 보낸다.
