# 07 혼밥 챗봇 (11-24)

밸류체인에서 고른 우선 기회 **O2 "1인분 + 취향 한 화면 거르기"** 의 첫 판이다.

## 여는 법

`혼밥챗봇_완성본.html`을 내려받아 더블클릭한다.
인터넷과 서버 없이 동작하고, 식당 데이터가 파일 안에 들어 있어 이 파일 하나만 옮겨도 된다.

## 하는 일

1. 고객이 지역 · 음식 · 가격을 말하면 조건으로 알아듣는다.
   예: "성서 고기 1만2천원 이하", "동성로 국밥 만원", "추어탕 먹고 싶어"
2. 조건에 맞는 식당 가운데 2인분 이상인 곳은 빼고, 1인분이 확인된 곳부터 보여 준다.
3. 확인되지 않은 곳은 "1인분 확인 안 됨"으로 따로 보여 준다.
4. 뺀 2인분 이상 가게 수를 알려 주고, 원하면 따로 보여 준다.

## 대화 방식: 규칙 + Gemini 보조

- 규칙이 먼저 지역(구 · 동네), 음식 종류, 가격, 메뉴 이름을 알아듣는다.
- 규칙이 아무 조건도 못 찾은 문장만 Gemini에게 보내 조건(JSON)으로 바꾼다.
  식당 이름과 1인분 판정은 항상 팀 데이터에서만 나온다.
- Gemini 키는 화면 오른쪽 위 "Gemini 설정"에서 사용자가 직접 넣는다. 키가 없으면 규칙만으로 동작한다.
- 비용을 막으려고 한 브라우저에서 하루 30회까지만 Gemini를 부른다.

## 1인분 배지

| 배지 | 뜻 |
|---|---|
| 혼자 가능 확인 | 1인 메뉴 · 세트, 혼밥 자리, "혼자면 예외"가 확인됨 |
| 2인분 조건 없음 | 메뉴판 · 후기 · 블로그에서 2인분 조건을 못 찾음 |
| 1인분 메뉴 표기 | 메뉴판에 1인분 · 1인 메뉴 표기가 있음 |
| 일부 메뉴 2인 이상 | 일부 메뉴만 2인 이상 |
| 1인분 확인 안 됨 | 자료 없음 |
| 2인분 이상 | 2인분 · 3인분부터, 혼밥 불가 명시 |

새로 모은 식당은 `수집양식_빈양식.csv`를 복사해 채우고, 파일 이름에 `수집양식`을 넣어 `식당목록/`에 둔다.
그다음 아래 명령을 실행하면 `혼밥챗봇_완성본.html`이 새로 만들어진다 (어느 폴더에서 실행해도 같다).

```bash
python 혼밥/07_챗봇/만드는_프로그램/build_data.py
```
