## 두 체인

| 체인 | 단계 |
|---|---|
| 산업 | 1 메뉴·주문 단위 정하기 → 2 정보 올리기 → 3 찾기·알아보기·고르기 → 4 주문·식사·결제 → 5 후기·재방문 |
| 서비스 | 1 식당 정보 모으기 → 2 1인분·시간대 판정 → 3 1인분 + 취향 거르기·추천 → 4 주문·식사·결제 (서비스 밖) → 5 후기·피드백 |
