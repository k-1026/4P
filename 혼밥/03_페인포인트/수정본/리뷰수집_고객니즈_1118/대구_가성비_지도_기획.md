# 대구 가성비 지도 기획안

> 근거 데이터: 대구 10개 구·군, 300개 매장의 네이버 방문자 리뷰 (2026-11-18 수집)

---

## 1. 컨셉

**"리뷰가 증명한 대구 가성비 맛집 지도"**

별점이 아니라 실제 방문 고객이 "가성비가 좋다", "양이 많다"고 남긴 리뷰를 근거로 점수를 매긴 지도입니다.

### 왜 필요한가
- 고객이 맛(67%) 다음으로 많이 찾는 가치가 **가성비(23%)**와 **양(20%)**입니다.
- 리뷰를 보면 고객이 말하는 가성비는 단순히 "싸다"가 아니었고, 세 가지가 함께 맞아야 했습니다.
  1. 낸 돈에 비해 양이 충분하다
  2. 반찬이나 기본 안주 구성이 알차다
  3. **숨은 비용이 없다** (공깃밥·된장찌개 추가 요금, 안내 없는 카드 수수료, 1인 1메뉴 강제 등)

---

## 2. 용어 설명: 가성비 태그란?

네이버 방문자 리뷰를 쓸 때 고객은 **"이런 점이 좋았어요"** 키워드 목록에서 몇 개를 직접 골라 체크합니다. 그중 **"가성비가 좋아요"**를 고른 경우를 이 기획안에서는 **가성비 태그**라고 부릅니다.

CSV의 `키워드태그` 열 예시:
```
음식이 맛있어요 | 가성비가 좋아요 | 양이 많아요
```

| 표현 | 의미 |
|---|---|
| 서구 가성비 태그 33.3% | 서구 리뷰 100건 중 33건에서 "가성비가 좋아요"를 고름 |
| 활수산 리뷰 20건 중 가성비 태그 16 | 리뷰 20건 중 16건에 해당 키워드가 체크됨 |
| 양 많음 태그 | 같은 방식으로 "양이 많아요" 키워드를 센 값 |

> 리뷰 본문에 "가성비 좋다"라고 쓴 것과는 별개입니다. 본문 표현은 가격 불만("비싸다", "바가지" 등)을 찾아 **감점**하는 데만 사용했습니다.

---

## 3. 가성비 지수 설계

```
가성비 지수 = (가성비 태그 + 0.5 × 양 많음 태그 + 0.3 × 반찬·구성 태그 − 1 × 가격 불만 언급) ÷ 리뷰 수
```

| 구분 | 요소 |
|---|---|
| 가점 | "가성비가 좋아요", "양이 많아요", "반찬이 잘 나와요", "기본 안주가 좋아요", "메뉴 구성이 알차요" 태그 |
| 감점 | 본문의 "비싸", "바가지", "창렬", "가격에 비해" 등의 표현 |
| 신뢰도 기준 | 리뷰 5건 이상인 매장만 표시 (현재 179곳) |

## 4. 지도 기능

| 기능 | 내용 | 근거가 된 고객 니즈 |
|---|---|---|
| 가성비 등급 핀 | 지수에 따라 색상 3단계로 표시 | 가성비, 양 |
| 숨은 비용 없음 배지 | 추가 요금 불만이 없는 매장 | 기본 메뉴 추가 요금에 대한 반감 |
| 방문 목적 필터 | 혼밥 / 가족 / 단체 / 술자리 | 목적별로 다른 니즈 |
| 1인 예산 필터 | 1만 원 이하 / 1~2만 원 / 2만 원 이상 | 제값 하는 가치 |
| 편의 정보 | 주차, 늦은 영업, 예약 가능 여부 | 기다림과 편의성 |
| 대표 리뷰 한 줄 | 가성비 근거가 된 실제 리뷰 문장 | 신뢰성 |

## 6. 현재 데이터의 한계

- **실제 가격 정보 부족:** 본문에 금액이 나온 리뷰는 49건뿐입니다. 1인 예산 필터를 만들려면 메뉴판 가격을 따로 수집해야 합니다.
- **표본 크기:** 매장당 리뷰가 최대 20건만 수집되어 있어 점수가 흔들릴 수 있습니다.
- **좌표 없음:** 주소를 위도·경도로 바꾸는 지오코딩이 필요합니다.
- **누락 매장:** 리뷰가 없는 매장이 약 76곳이고, 네이버에서 찾지 못한 매장도 있습니다.
