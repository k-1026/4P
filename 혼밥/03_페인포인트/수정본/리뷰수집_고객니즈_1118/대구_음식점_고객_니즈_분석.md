# 대구 음식점 방문자 리뷰로 본 고객 Want

> 대구 10개 구·군, 300개 매장의 네이버 방문자 리뷰 2,842건 분석 (2026-11-18 수집 데이터 기준)

## 한눈에 보기

| 항목 | 값 |
|---|---|
| 분석 리뷰 | 2,842건 |
| 매장 수 | 300곳 |
| 지역 | 10개 구·군 (중구, 동성로, 수성구, 동구, 달서구, 북구, 남구, 달성군, 서구, 군위군) |
| 사장님 답글률 | **12%** (349건) |

**한 줄 요약:** 고객은 "맛있는 음식을, 제값에, 깨끗한 곳에서, **사람 대접받으며** 먹고 싶다"고 말합니다. 마지막 조건이 무너지면 앞의 세 가지가 다 좋아도 다시 오지 않습니다.

## 고객이 원하는 6가지

### 1. 맛과 일관성 (67%)
- 기본은 맛있는 음식입니다.
- **변하지 않는 맛**을 원합니다. "1년 전과 맛이 달라 실망" 같은 지적이 바로 나옵니다.

### 2. 사람 대접 (33%) ⭐ 가장 중요
- 혹평의 대부분은 **맛이 아니라 응대** 때문입니다.
- 고객이 원하는 것:
  - 들어오고 나갈 때 인사, 눈을 마주치는 응대
  - 메뉴 질문(맵기, 볶음밥 등)에 귀찮아하지 않고 답하기
  - 반찬 추가나 셀프바 이용에 눈치 주지 않기
  - 주문 순서 지키기
  - 직원 및 외국인 직원 교육
- "맛은 괜찮은지 챙겨줌", "먹는 법을 설명해줌" 같은 세심함이 단골이 되는 이유입니다.
- 가족 모임이나 부모님 생신 같은 자리에서 겪은 불친절은 특히 오래 기억됩니다.

### 3. 제값 하는 가치 (가성비 23% · 양 20%)
- 반감을 사는 경우:
  - 기본 구성으로 생각한 것에 붙는 추가 요금 (된장찌개·공기밥 1,000원)
  - 사전 안내 없는 카드 결제 추가금
  - 방송 출연 뒤 가격만 오른 "초심 잃은" 가게
  - 1인 1메뉴 의무 주문, 인원 제한이 있는 소(小) 메뉴
- 확실한 가성비(예: 손칼국수 5천 원)는 열광적인 재방문으로 이어집니다.

### 4. 정직한 재료 (신선 24% · 고기 질 16% · 특별 메뉴 22%)
- 칭찬받는 점: 직접 담근 반찬과 김치, 집밥 같은 맛, 잡내 없음
- 실망하는 점: "식당용" 된장찌개 맛, 수입산 밀가루, 덜 익은 도우, 퍼진 면

### 5. 깨끗한 매장 (13%)
- 닦지 않은 테이블, 이물질, 냄새는 단골도 떠나게 만듭니다.
- 셀프바와 오픈 주방은 위생이 그대로 보이므로 더 엄격하게 평가받습니다.

### 6. 기다림에 대한 배려
- **웨이팅 관리:** 명확한 대기 안내와 예약 방법 (54분 대기, 선결제 안내가 없어 순서를 놓친 사례 등)
- **품절 정보:** 빵이나 디저트가 다 팔렸다는 사실을 미리 알고 싶어 합니다.
- **편의성:** 주차 공간, 늦은 시간 영업, 모바일 주문(패스오더)
- **기본 시설:** 화장실, 물 제공, 에어컨

| 방문 목적 | 원하는 것 |
|---|---|
| 데이트·기념일 | 조명, 분위기, 코스처럼 즐기는 구성, 세심한 서비스 |
| 가족·부모님 모임 | 룸, 넓은 자리, 정중한 응대 |
| 아이 동반 | 아기 의자, 아이에게 눈치 주지 않기, 덜 시끄러운 환경 |
| 혼밥·혼술 | 혼자 앉기 편한 분위기 |
| 카페 | 인테리어(19%), 사진이 잘 나오는 공간, 디저트 |
| 모임·회식 | 단체석, 넓은 매장(12%) |

## ❌ 다시 오지 않게 만드는 순간

- 짜증 내거나 무시하는 말투, 인사 없음
- 나중에 온 손님에게 먼저 서빙
- 반찬 추가나 셀프바 이용에 눈치 주기
- 방송 출연 뒤 가격만 오름
- 테이블 미정리, 이물질
- 안내 없는 대기 및 선결제 방식

## 💡 시사점

- 사장님 답글률이 12%에 불과하고, 혹평에 답한 사례는 거의 없습니다. **고객 리뷰에 반응하는 것만으로도** 차별화할 여지가 큽니다.
- 맛보다 **응대 품질 관리(직원 교육, 응대 매뉴얼)**가 재방문에 더 큰 영향을 줍니다.

- 긍정 리뷰는 집계 수치와 일부 본문으로 확인했습니다.
