# 루브릭 — 잡 스토리

채점 대상: `ax/work/jtbd/batch_NN.md` 한 묶음 (페인포인트 하나).
기준 문서: `ax/tasks/jtbd.md`, `painpoint/혼밥페인포인트_최종본.md`, `voc_clean.csv`.
채점 단위는 잡 스토리 한 개다.

## 0. 근거 (관문, 필수)

- 상황 · 동기 · 결과 세 부분 모두에 voc_id가 하나 이상 붙어 있어야 한다.
- 붙은 voc_id가 모두 `voc_clean.csv`에 실제로 있어야 한다.
- 어긴 잡 스토리는 점수와 상관없이 재작업 목록에 넣는다.

## 셈 방식

- 항목 점수 = 배점 × (기준을 지킨 잡 스토리 수 ÷ 묶음 전체 잡 스토리 수), 소수 첫째 자리에서 반올림.
- 범위 항목만 묶음 단위로 센다 (아래 2).
- 확인하지 못한 항목은 "확인 못 함"으로 쓰고 0점.
- 총점 80 이상이면 통과.

## 1. 정확성 40

잡 스토리 하나가 아래를 모두 지키면 "지킨 것"이다.
채점자는 붙은 voc_id의 원문을 직접 읽고 확인한다.

- 상황 · 동기 · 결과가 붙은 원문과 뜻이 같다.
  원문에 없는 시간 · 장소 · 감정 · 결과를 더하지 않았다.
- `대구거주`가 `모름`인 글을 대구 고객 글이라고 쓰지 않았다.
- 해결책 표현(앱 · AI · 필터 · 검색 · 서비스 · 기능)이 없다.
- 보류(H2) 글(v_242 등)을 근거로 쓰지 않았다.

## 2. 범위 30

묶음 단위로 본다.
아래 세 가지를 각 10점으로 매긴다.

- 개수 10: 카드가 정한 개수(4개)를 채웠다.
  모자란 개수 하나마다 2.5점 뺀다.
- 차원 10: 잡 스토리마다 기능적 · 감정적 · 사회적 중 하나가 표시되어 있다.
  표시가 없거나 다른 말이면 개수만큼 2.5점 뺀다.
- 메모 10: 근거가 없어 뺀 조건과, 동기를 결과로 뒤집어 쓴 잡 스토리가 메모에 적혀 있다.
  해당이 없으면 "없음"이라고 적혀 있어야 한다.
  메모가 아예 없으면 0점.

## 3. 형식 30

잡 스토리 하나가 아래를 모두 지키면 "지킨 것"이다.

- "~할 때(…), ~하고 싶다(…), 그래서 ~할 수 있도록(…)." 순서와 형식을 따른다.
- 한 줄에 잡 스토리 하나다.
- 쓴 voc_id가 묶음 끝 근거 표(`voc_id | 대구거주 | 원문 요지 | 쓴 곳`)에 모두 있다.

## 보고 형식

```
총점: NN / 100 (통과 80)

| 항목 | 배점 | 지킨 것 / 전체 | 점수 | 감점 이유 (대표 J번호) |
|---|---|---|---|---|
| 근거 (관문) | - | | 통과/미통과 | |
| 정확성 | 40 | | | |
| 범위 | 30 | | | |
| 형식 | 30 | | | |

| 재작업할 J번호 | 어긴 항목 | 이유 (원문과 다른 말이면 그 말) |
|---|---|---|
```

## 재작업 보낼 때 작업자에게 넘길 것

- 재작업할 J번호와 감점 이유, 원문과 다른 표현이 있으면 그 표현.
- 재작업은 그 잡 스토리만 다시 쓰고, 나머지는 건드리지 않는다.
