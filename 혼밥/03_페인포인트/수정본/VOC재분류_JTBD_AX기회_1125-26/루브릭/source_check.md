# 루브릭 — 원문 대조

채점 대상: `ax/work/source_check/batch_NN.md` 한 묶음.
기준 문서: `ax/tasks/source_check.md` (판정 값 4개), 대상 문서, `voc_clean.csv`.
채점 단위는 대조표의 한 행(주장 하나)이다.

## 0. 근거 (관문, 필수)

- 행마다 voc_id가 있어야 한다.
- 판정이 `id 없음`이 아닌 행은 voc_id가 `voc_clean.csv`에 실제로 있어야 한다.
- 판정이 `id 없음`인 행은 voc_id가 `voc_clean.csv`에 정말 없어야 한다.
- 어긴 행은 점수와 상관없이 재작업 목록에 넣는다.

## 셈 방식

- 항목 점수 = 배점 × (기준을 지킨 행 수 ÷ 묶음 전체 행 수), 소수 첫째 자리에서 반올림.
- 범위 항목만 따로 센다 (아래 2).
- 확인하지 못한 항목은 "확인 못 함"으로 쓰고 0점.
- 총점 80 이상이면 통과.

## 1. 정확성 40

한 행이 아래를 모두 지키면 "지킨 행"이다.
채점자는 voc_id의 원문을 직접 읽고 확인한다.

- 판정이 원문과 맞다 (카드의 판정 값 뜻대로).
- 원문 요지가 원문 내용과 같다.
- 대구거주 표기(`맞음` · `틀림` · `해당없음`)가 원문 `대구거주` 값과 맞다.

## 2. 범위 30

- 채점자가 대상 문서의 맡은 범위에서 voc_id가 나온 곳을 Grep으로 센다 (기대 개수).
- 대조표에 빠진 주장 하나마다 감점한다.
- 셈: 30 × (대조표에 있는 주장 수 ÷ 기대 개수), 30을 넘지 않는다.
- 한 문장에 voc_id가 여러 개면 voc_id마다 한 주장으로 센다.

## 3. 형식 30

한 행이 아래를 모두 지키면 "지킨 행"이다.

- 열이 `위치 | voc_id | 문서 주장 | 원문 요지 | 판정 | 대구거주 표기 | 고칠 안` 일곱 개다.
- 판정이 `일치` · `과장` · `원문에 없음` · `id 없음` 중 하나다.
- 판정이 `일치`가 아니면 고칠 안이 있다.
- 원문 요지가 30자 이내다.

## 보고 형식

```
| 항목 | 배점 | 지킨 행 / 전체 | 점수 | 감점 이유 (대표 위치) |
|---|---|---|---|---|
| 근거 (관문) | - | | 통과/미통과 | |
| 정확성 | 40 | | | |
| 범위 | 30 | 대조표 주장 수 / 기대 개수 | | |
| 형식 | 30 | | | |

| 재작업할 위치 · voc_id | 어긴 항목 | 이유 |
|---|---|---|

빠진 주장: (위치 · voc_id 목록)
```

## 재작업 보낼 때 작업자에게 넘길 것

- 재작업할 행과 감점 이유, 빠진 주장의 위치와 voc_id.
- 재작업은 그 행만 고치고 빠진 주장을 더하며, 나머지 행은 건드리지 않는다.
