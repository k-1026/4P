# 웹데이터 판정 규칙 v0 (달서구) — 2026-11-24

목적: 팀 웹페이지가 쓸 **달서구 식당 한 곳당 한 줄** 원본 데이터. 표본 연구용 판정(수집안내 3장)을 바탕으로, 웹에 보여 줄 값으로 바꾼다.
v0은 **초안**이다. 지도 수집을 하기 전이라 대부분 '업종 기준' 또는 '모름'이고, 수집이 끝날 때마다 v1, v2로 채운다.

## 1. 대상 가게

- 바탕: 소상공인 상가정보 달서구 음식점 전체 7,397곳 (`원본자료/달서구_음식점_전체_202609.csv`)
- 뺌(식사하는 곳이 아님): 카페, 빵/도넛, 일반 유흥 주점, 무도 유흥 주점, 구내식당, 떡/한과, 아이스크림/빙수, 생맥주 전문
  - 단, 프로젝트의 2인분 후보 목록에 든 가게는 업종이 위에 있어도 넣는다.

## 2. 업종 갈래 (`업종_갈래`)

| 갈래 | 정의 | 판정 방식 |
|---|---|---|
| 2인분 의심 | 프로젝트 기존 정의: `대구_2인분후보업종_202609.csv`에 든 가게(소분류 + 상호 키워드) | 지도 → 블로그 → 판정 (지금까지 방식) |
| 한 그릇 업종 | 백반/한정식, 국/탕/찌개류, 김밥/만두/분식, 국수/칼국수, 냉면/밀면, 중국집, 일식 카레/돈가스/덮밥, 일식 면 요리, 경양식, 버거, 토스트/샌드위치/샐러드, 베트남식 전문, 파스타/스테이크, 전/부침개, 기타 한식·서양식, 그 외 기타 간이 음식점 | 지도 메뉴를 한 번 훑고, 2인분 조건이 보이면 그 가게만 깊게 본다 |
| 그 밖 | 요리 주점, 치킨, 피자, 일식 회/초밥, 뷔페, 패밀리레스토랑, 동남아 외 기타 등 위 두 갈래에 없는 업종 | 업종만으로 정하지 않는다 (지도로 확인) |

> ⚠ '한 그릇 업종' 목록은 Claude 초안이다. 사용자 확인 필요.

## 3. 웹에 보여 줄 값

### 1인분_여부: `1인분 가능` / `2인분 이상` / `모름`
### 근거_수준: `확인됨` / `추정` / `업종 기준` / `없음`

| 상황 | 1인분_여부 | 근거_수준 |
|---|---|---|
| 기존 판정 2인분이상_확정 | 2인분 이상 | 확인됨 |
| 기존 판정 2인분이상_추정 | 2인분 이상 | 추정 |
| 기존 판정 1인분가능_확정 | 1인분 가능 | 확인됨 |
| (지도 수집 후) 한 그릇 단위 가격이 대표 메뉴에 있고, 2인분 조건이 어디에도 없음. 단 아래 '1인분 가격 표기 불신 업종'은 제외 | 1인분 가능 | 추정 |
| 아직 확인 전이거나 정보가 없는 **한 그릇 업종** (기존 판정 미상 포함) | 1인분 가능 | 업종 기준 |
| 2인분 의심·그 밖 갈래에서 확인 안 됨 (기존 판정 미상 포함) | 모름 | 없음 |

- 한 그릇 업종이라도 기존 판정이 확정·추정이면 그 판정을 따른다. 기존 판정이 미상이면 업종 기준.
- **1인분 가격 표기 불신 업종** ("○○ 1인분 ○원"으로 적고 실제로는 2인분부터 받는 일이 많은 업종): 돼지고기·소고기·닭/오리고기 구이/찜, 곱창 전골/구이, 요리 주점(막창 등), 횟집, 해산물 구이/찜, 족발/보쌈, 복 요리 전문, 마라탕/훠궈. 이 업종은 '1인분 ○원'만으로 1인분 가능을 주지 않는다.

### 조건_인분, 조건_범위
2인분 이상일 때만. 기존 판정의 인분(2, 3 …)과 범위(가게 전체 / 일부 메뉴).

### 혼자_입장: `가능` / `불가` / `모름`
기존 판정의 1인입장. 지도 수집의 '혼자' 동행 태그 수와 '혼밥하기 좋아요' 수는 **숫자 칸으로만 모으고**, 몇 건부터 '가능'으로 볼지는 사용자가 정한다(v0에서는 판정에 쓰지 않음).

### 혼밥_유형 (1인분 × 혼자 입장)

| 1인분_여부 \ 혼자_입장 | 가능 | 불가 | 모름 |
|---|---|---|---|
| 1인분 가능 | ① 혼밥 가능 | ② 1인분 있지만 혼자 불가 | 1인분 가능 (혼자 입장 모름) |
| 2인분 이상 | ③ 혼자 가서 2인분 주문 | ④ 혼밥 불가 | 2인분 이상 (혼자 입장 모름) |
| 모름 | 혼자 입장 가능 (1인분 모름) | 혼자 입장 불가 (1인분 모름) | 모름 |

## 4. 웹 파일에 넣지 않는 것

- 블로그·리뷰 작성자 이름 (처음부터 모으지 않음).

## 6. 사용자 결정 (2026-11-24, 시범 100곳을 보고)

1. **일부 메뉴만 2인분** → `1인분_여부`=1인분 가능, `근거_수준`=추정, `1인분_메모`='일부 메뉴 2인분', `조건_범위`=일부 메뉴.
2. **혼자 입장**: 리뷰·사장님 답글 판정(judge_signals)이 먼저(근거 수준 확인됨). 없으면 '혼자' 동행 태그 3건 이상 또는 '혼밥하기 좋아요' 5명 이상 → 가능(추정). 칸 `혼자_근거_수준` 추가.
   - 비율은 판정에 쓰지 않는다: "혼자 가도 되나"는 사람 수가 증거이고, 비율은 "혼밥 손님이 많은 곳인가"를 뜻하므로 따로 칸 `혼밥_키워드_비율`(%, 혼밥하기 좋아요 ÷ 키워드 참여자)로만 둔다. 웹에서 혼밥 분위기 순서·추천에 쓸 수 있음.
   - 용어: '혼밥하기 좋아요' = 네이버 방문자 리뷰 키워드('이런 점이 좋았어요', 가게 전체 누적). '혼자' 태그 = 방문자 리뷰의 동행 태그(최근 리뷰 약 50개에서 셈).
3. **범위 오판 고치기**: 1차 도구가 '가게 전체'로 봤어도, 가게 규칙(첫 주문·기본 N인분)이 아니고 대표 메뉴에 2인 이상·크기·세트·포장·배달 표기 없는 단품 가격이 있으면 '일부 메뉴'. 단 1인분 가격 표기 불신 업종에는 적용하지 않음.
4. **1인분 가격 불신 업종인데 일부 메뉴만 2인분**(예: 경희횟집, 코끼리막창) → 1인분 가능(추정)으로 두고 `따로_확인`=예. 팀이 나중에 모아서 직접 확인.
- Codex 검증(11-24) 반영: 원문 어디에든 '주문은 2인부터', '인원수대로' 같은 가게 전체 규칙이 있으면 일부 메뉴로 낮추지 않고 한 그릇 추정도 주지 않음. 소/중/대 크기 메뉴는 단품으로 보지 않음.
- 함께 적용(기존 수집안내 3장): 곁들임(볶음밥·사리 등)에만 붙은 2인분 조건은 최소 주문 근거로 보지 않는다.
