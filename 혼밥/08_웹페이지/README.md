# 08 웹페이지 — 혼밥 밥친구 화면 시안 (11-24)

| 파일 | 종류 | 내용 |
|---|---|---|
| `혼밥_홈화면.html` | 결과물 | 발표 · 검토용 **동작 시안**. 화면 전체가 이 파일 하나에 들어 있다 |

## 여는 법

`혼밥_홈화면.html`을 내려받아 더블클릭한다.
인터넷 없이 동작하고, 글꼴과 캐릭터 그림이 파일 안에 들어 있다.
찜 · 일기 · 레벨은 **그 브라우저에만** 저장된다 (화면 위에 "미리보기 모드"라고 나온다).

## 화면 구성 (아래 탭 4개)

| 탭 | 하는 일 |
|---|---|
| AI 추천 (홈) | AI 밥친구 채팅. 취향 3문항(음식 · 예산 · 분위기) → 추천 카드 3장 |
| 지도 | 동네 지도와 가게 목록, 필터(대기 없음 · 1인석 · 국물 · 고기 · 콘센트) |
| 혼밥일기 | 모두 공유 / 이웃 공유 피드, 일기 쓰기 |
| 마이 | 프로필, 이웃, 혼밥 레벨, 혼밥 MBTI, 찜한 식당 |

가게를 누르면 가게 카드(평점 · 혼밥러 별점 · 거리 · 메뉴 · 편의 · 최근 일기 · 방문 기록 · 찜 · 길찾기)가 나온다.

## 알아 둘 점

- 식당은 화면을 보여 주기 위한 **예시 데이터 16곳**이다. 실제 대구 식당 데이터는 `../07_챗봇`에 있다.
- "AI 밥친구"는 실제 AI가 아니라 단어 규칙으로 고른다.
- 기능별 진행 상태는 `혼밥_수정본` 브랜치의 `08_웹페이지/수정본/진행사항_1124.md`에 있다.
