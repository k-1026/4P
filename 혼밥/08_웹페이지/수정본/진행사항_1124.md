# 혼밥 웹페이지 (혼밥 밥친구) 진행사항

- 작성일: 2026-11-24
- 파일: `혼밥_홈화면_v2.html` (화면 전체가 이 파일 하나에 들어 있음)
- 성격: 발표·검토용 **동작 프로토타입**. 식당은 예시 데이터 16곳(역삼·강남·선릉)이고, AI 밥친구는 실제 AI가 아니라 단어 규칙으로 고른다.

## 여는 법

`혼밥_홈화면_v2.html`을 더블클릭해서 브라우저로 연다.
인터넷 없이도 동작하고, 글꼴(Pretendard)과 캐릭터 그림이 파일 안에 들어 있다.
파일을 그냥 열면 찜·일기·레벨이 **그 브라우저에만** 저장된다. (화면 위에 "미리보기 모드"라고 나옴)

여러 사람이 혼밥일기를 함께 보려면 Claude 아티팩트(공유 저장소가 붙은 페이지)로 올려서 공유해야 한다.
지금 올려 둔 아티팩트는 작성자만 볼 수 있는 상태다.

## 화면 구성 (아래 탭 4개)

| 탭 | 하는 일 |
|---|---|
| AI 추천 (홈) | AI 밥친구 채팅. 취향 3문항(음식·예산·분위기) → "MBTI대로 / 새롭게 찾기" 선택 → 추천 카드 3장 |
| 지도 | 동네 지도와 가게 목록, 필터(대기 없음·1인석·국물·고기·콘센트) |
| 혼밥일기 | 🌏 모두 공유 / 👥 이웃 공유 탭, 피드(예시 일기 10개 포함), 일기 쓰기 |
| 마이 | 프로필 사진, 이웃 수·이웃 목록, 혼밥 레벨, 혼밥 MBTI, 찜한 식당 |

가게를 누르면 나오는 **가게 카드**: 평점 + 혼밥러 별점, 거리, 식사 시간, 메뉴, 편의, 최근 일기, `오늘 방문 기록하기`, 찜하기, 길찾기(카카오맵).

## 기능별 현재 상태

### 1. AI 추천

- 처음 오면 취향 3문항을 묻고, 다시 오면 저장된 취향을 보여준다.
- MBTI 결과가 있으면 "MBTI대로 추천해줘 / 새롭게 찾아볼래"를 고른다.
  결과가 없거나 예전 기준 결과면 "MBTI 테스트하고 추천받기"로 마이 탭에 연결한다.
- 추천 점수: 평점, 취향(음식·분위기), 예산(초과 시 제외), 대기, 거리, 찜한 곳과 비슷한 종류, MBTI.
- 카드마다 추천 이유가 붙는다. 예: "1인석 있음 · 가봤던 곳 (1번) · 1만원 이하"
- 빠른 버튼: 오늘 뭐 먹지, 다른 곳 추천, 더 싼 곳, 빨리 먹을 곳, 따뜻한 국물, 추천 방식 바꾸기, 취향 바꾸기.

### 2. 혼밥 MBTI (마이 탭에서 테스트)

- 4개 기준 × 8문항 = 32문항, 16유형.
- 글자는 영어 단어의 첫 글자.

| 기준 | 앞 글자 | 뒤 글자 | AI 추천에서 보는 것 |
|---|---|---|---|
| 가게 고르는 법 | **C**heck 리뷰파 | **I**mpulse 즉흥파 | 리뷰파: 평점 4.6↑·리뷰 150↑ / 즉흥파: 대기 없고 300m 안 |
| 자리 취향 | **B**ooth 아늑파 | **O**pen 당당파 | 아늑파: 1인석 있는 곳 / 당당파: 상관없음 |
| 새로움 vs 익숙함 | **N**ew 탐험파 | **R**egular 단골파 | 탐험파: 안 가본 곳 / 단골파: 가봤던 곳(방문 기록 기준) |
| 돈 쓰는 법 | **V**alue 가성비파 | **P**remium 플렉스파 | 가성비파: 1만원 이하 / 플렉스파: 1.2만원 이상 |

- 처음에 만든 "식사 속도(후딱파/느긋파)" 기준은 리뷰파/즉흥파로 바꿨다. 예전 결과(F/S 코드)는 다시 테스트해야 한다.
- 결과 화면: 유형 이름·설명, 영어 단어 풀이, 기준별 비율 막대, 팁, 결과 복사, 이 결과로 추천받기.

### 3. 혼밥 레벨 (혼밥일기를 쓸수록 오름)

- 방문 = 사진 1장 이상 든 혼밥일기 저장. 같은 가게도 쓸 때마다 1번씩 기록(하루 제한 없음).
- 가게 카드의 `오늘 방문 기록하기` → 일기 쓰기로 이동 → 저장하면 버튼이 초록색 "오늘 방문 기록 완료"로 바뀐다.
- 레벨 10단계. 레벨마다 캐릭터(밥톨이)와 이모지가 더 비싼 음식으로 바뀐다.

| 레벨 | 이름 | 캐릭터 | 누적 방문 |
|---|---|---|---|
| 1 | 혼밥 새싹 | 🍙 삼각김밥 | 0 |
| 2 | 혼밥 입문자 | 🍜 라멘 | 10 |
| 3 | 혼밥 러너 | 🍲 국밥 | 25 |
| 4 | 혼밥 단골 | 🍱 정식 도시락 | 45 |
| 5 | 혼밥 고수 | 🍣 초밥 | 70 |
| 6 | 혼밥 미식가 | 🍝 파스타 | 100 |
| 7 | 혼밥 마스터 | 🥩 한우 스테이크 | 140 |
| 8 | 혼밥 그랜드마스터 | 🦀 대게 | 190 |
| 9 | 혼밥 레전드 | 🦞 랍스터 | 250 |
| 10 | 혼밥의 신 | 🍽 파인다이닝 코스 | 320 |

- 마이 레벨 카드: 캐릭터가 레벨 막대 위를 뛰어가고, 음식 컬렉션 줄(10칸)과 최근 방문이 보인다.
- 레벨이 오르면 LEVEL UP 화면에서 캐릭터가 점프한다.
- 캐릭터 그림은 팀이 준 일러스트에서 10개를 잘라 배경을 투명하게 만들어 넣었다.

### 4. 혼밥일기

- 일기 항목: 가게, 별점, 혼밥 포인트 태그, 후기, **사진(필수 1장 이상)**, 공개 범위.
- 공개 범위: 🌏 모두 공유 / 👥 이웃 공유.
  - 이웃 공유는 글쓴이가 이웃으로 추가한 사람에게만 보인다.
  - **별점은 어느 쪽이든 가게 혼밥러 별점에 반영된다.**
- 피드 위 탭(🌏 모두 공유 / 👥 이웃 공유)으로 조건에 맞는 글만 본다. 아래 정렬: 최신순·인기순·내 동네·내 일기.
- 글마다 공감, 댓글, 공유(내용 복사), 식당 찜, `+ 이웃`. 내 글은 수정만 가능(삭제 버튼 없앰).
- 닉네임 옆에 레벨 배지와 MBTI 배지가 붙는다.
- 예시 일기 10개가 '예시' 표시와 함께 들어 있다(그중 3개는 이웃 공유 글).

### 5. 이웃

- 혼밥일기에서 `+ 이웃`을 눌러 추가, 마이 탭에서 `이웃 끊기`.
- 마이 프로필에 "이웃 N · 나를 추가한 이웃 N"이 보인다.
- 예시 혼밥러는 내가 추가하면 바로 서로 이웃으로 본다.

### 6. 마이

- 맨 위 프로필 사진 칸(사진이 없으면 레벨 음식 이모지), 닉네임 변경.
- 내 이웃, 혼밥 레벨, 혼밥 MBTI, 찜한 식당(예전 "찜/저장" 탭을 이리로 옮김), 데이터 초기화.

## 진행 기록 (2026-11-24, 순서대로)

1. 홈 화면 목업 사진을 동작하는 화면으로 구현 (검색·카테고리·배너·카드·AI 추천·탭 5개).
2. 홈을 AI 챗봇 화면만 남기고, 취향 3문항 기반 추천으로 변경.
3. 혼밥일기를 공유 피드로 변경 (일기 쓰기·사진·공감·댓글·공유) → 아티팩트 공유 저장소로 실제 공유 연결.
4. 처음의 "혼밥 레벨(Lv.1~4 식당 난이도)" 삭제.
5. 혼밥 MBTI(32문항·16유형) 추가 → 테스트는 마이 탭으로 이동, 챗봇에서는 "MBTI대로 / 새롭게" 선택만.
6. 방문 기반 혼밥 레벨 + 달리는 캐릭터 추가 → 기준을 점점 어렵게(10·25·45…) → 10단계로 확장.
7. MBTI 추천 기준 재정의(속도 축 미사용 → 리뷰파/즉흥파로 교체, 1인석·방문 여부·가격대 사용).
8. 마이 정리: 취향 표시·통계 줄 삭제, 찜을 마이로 이동, 프로필 사진 칸, 이모지 대신 레벨 음식 이모지.
9. 가게 카드 정리: 혼잡도 삭제, 일기 쓰기 버튼 삭제, `오늘 방문 기록하기` → 일기 쓰기, 완료 시 초록 버튼.
10. 일기 사진 1장 필수, 유의사항 안내, 하루 1번 제한 삭제.
11. 캐릭터를 팀 일러스트로 교체, 글꼴 Pretendard 적용.
    (중간에 "깔끔한 디자인" 시도는 팀 의견으로 되돌림 → 원래 주황·갈색 디자인 유지)
12. 이웃 기능, 모두/이웃 공유, 별점 반영, 이웃 수 표시, 예시 일기 10개, 피드 삭제 버튼 제거.

## 아직 남은 것 · 주의할 점

- 식당 데이터는 예시 16곳이다. 팀 데이터(`../2인분식당_데이터`, `../챗봇`)와 아직 연결하지 않았다.
- AI 밥친구는 단어 규칙 방식이라 문장을 깊게 이해하지 못한다. (`../챗봇`의 Gemini 보조 방식을 붙일 수 있음)
- "이웃 공유"는 화면에서 걸러서 보여주는 방식이라 완전한 비공개가 아니다. 진짜 비공개는 서버 권한 관리가 필요하다.
- 피드에서 삭제 버튼을 없애서, 부적절한 글을 화면에서 내릴 방법이 없다.
- 같은 가게에 일기를 연달아 쓰면 레벨을 빨리 올릴 수 있다(하루 제한 없음).
- 파일을 그냥 열었을 때의 기록은 그 브라우저에만 남는다.
