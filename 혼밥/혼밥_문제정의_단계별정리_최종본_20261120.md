# 혼밥 서비스 문제 정의: 단계별 정리

> 정리일: 2026-11-20
> **서비스**: 대구 혼밥 1인가구에게 ① 1인분 되는 가게를 구분해 주고 ② 취향에 맞는 혼밥집을 추천
> **점수 기준 (주장 1개당 10점)**: 출처 등급(A 4 · B 3 · 직접 확인 3 · 민간 B 2 · B 2차 인용 2 · C 2 · D 1) + 대상 일치(대구·1인가구·혼밥, 최대 3) + 교차검증(최대 2) + 원문 확인(1)
> **신호등**: 🟢 8~10점 · 🟡 5~7점 · 🔴 0~4점 (구분별 평균: 80점 이상 🟢 · 50~79점 🟡 · 49점 이하 🔴)
> **규칙**: 숫자는 A·B 등급에서만 사용. D 등급은 사례로만 인용.

## 종합 점수

|---|---|---|---|

| **문제 ① 1인분** | **55점** | 🟡 | 앱에 기능이 없는 것은 확실함. 가게 공급 부족은 근거가 약함 |
| **문제 ② 취향** | **58점** | 🟡 | 필터가 흩어진 것은 확실함. 사전 정보 부족은 D등급 사례뿐 |

## 전체 흐름

```
[배경]   1단계 1인가구 증가 🟢 → 2단계 혼밥 많음 🟢 → 3단계 혼밥 증가 🟢(전국)/🟡(대구) → 4단계 밖에서 혼밥 🔴
                                          ↓
[문제①] 5단계 1인 메뉴를 따짐 🟡 → 6단계 1인분 가게 적음 🔴 → 7단계 앱에 필터 없음 🟢 → 8단계 실제 불편 🟡
[문제②] 9단계 혼자 갈 때 기준이 있음 🟡 → 10단계 필터 흩어짐 🟢 → 11단계 사전 정보 부족 🔴
                                          ↓
[서비스] 12단계 1인분 + 취향을 한 화면에서 거르기
```
