# 11_앱 — 혼밥 앱 '혼밥 밥친구' (11-25 ~ 11-26)

> 만든 사람: 손효민
> 대구 동성로에서 혼자 먹을 식당 3곳을 추천하는 앱. 화면 하나(HTML)와 파이썬 에이전트 서버로 되어 있다.

## 흐름

혼밥 MBTI(16문항) → 중요 순위 정하기 → 업종 → 예산 → 에이전트 상의 → 사용자가 점수 선택 → 추천 3곳 · 내 주변 지도

## 지금 규칙

| 항목 | 규칙 |
|---|---|
| 가중치 (총합 10) | 거리 2 고정. 날씨 · 자리 · 새로움 · 가격은 사용자가 정한 순위대로 3.2 / 2.4 / 1.6 / 0.8 |
| 후보 | 고른 업종 안에서 1km 이내 가까운 20곳. 2인분 메뉴 제외 |
| 가격 | 말한 예산 초과 탈락. 가장 싼 곳 10점 ~ 가장 비싼 곳 0점 |
| 혼밥 | 후보 안 후기 순위 8점 + 1인석 2점 |
| 상의 | 에이전트끼리 결론 내지 않음. 반론이 나온 가게의 점수를 높일지 사용자가 고름 |

## 폴더

| 폴더 | 내용 |

| [`결과화면/`](결과화면/) | 순위 선택 · 상의 후 점수 선택 · 지도 화면 3장 |

- 날씨 · 취향 · 조율자 에이전트는 이찬영 님 코드를 바탕으로 고쳤다 ([`../10_에이전트/`](../10_에이전트/)).
