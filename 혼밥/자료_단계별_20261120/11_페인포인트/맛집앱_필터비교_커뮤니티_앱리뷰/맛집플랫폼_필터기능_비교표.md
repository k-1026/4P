# 맛집 플랫폼 필터 기능 비교표
확인일: 2026-11-20 / 대구 검색 화면에서 필터 목록을 직접 확인 / 캡처: `필터비교_캡처` 폴더

표기: O 있음 / △ 비슷한 대체 기능 / X 없음 / ? 미확인. 가게에 붙는 태그나 리뷰 키워드는 필터가 아니어서 제외했습니다.

## 플랫폼별 전체 필터 구성

- **네이버**: 정렬, 영업시간, 속성(배달·포장·예약), 네이버 예약·주문·결제, 인기 메뉴, 목적(데이트·회식 등), 테마, **분위기**(분위기좋은·조용한·편한좌석·대화·혼밥·혼술·이국적인), **시설·서비스**(룸·단체석·카운터석·입식·좌식·바테이블·테라스·연인석·루프탑·**1인석**·주차 등)
- **카카오맵 웹**: 필터 없음. PC는 정확도순·인기도순, 모바일 웹은 정확도순·거리순 정렬만
- **다이닝코드**: 대표 음식, 지역, 영업시간, 방문 연령대·성별, 음식 종류, **방문목적**(혼밥·혼술·혼카페 포함 18개), 편의기능(개별룸·대형룸·테라스·주차 등), **분위기**(현지인맛집·가성비좋은·분위기좋은·조용한 등 13개), 인증맛집(방송·미쉐린 등)
- **캐치테이블**: 날짜·인원·시간, 지역, 음식 종류, **가격**(슬라이더 + 10만 원 이하~40만 원대 이상), **테이블 타입**(룸·바·홀·테라스·창가·대관), **분위기**(데이트·조용한·모던한 등 11개), 편의시설

## 정리

- **'1인 메뉴' 필터는 네 곳 모두 없습니다.**
- **'1인석' 필터는 네이버만** 정식 항목으로 있습니다. 캐치테이블은 '바' 좌석이나 '1명' 예약으로 대신할 수 있습니다.
- **'가격대' 필터는 캐치테이블만** 있습니다(예약·고가 매장 중심).
- **'혼밥'을 직접 고르는 항목**은 네이버(분위기)와 다이닝코드(방문목적)에 있습니다.
- 한계: 카카오맵 앱과 네이버·다이닝코드 앱 화면은 확인하지 못했습니다. 앱은 업데이트로 항목이 바뀔 수 있어 확인일을 함께 적어야 합니다.
