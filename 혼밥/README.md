# 혼밥 프로젝트 전체 진행 (2026-11-20 ~ 11-24)

> 대구 안에서만 쓰는 웹 AI 챗봇. 혼자 갈 식당을 찾아 주고 1인분·혼밥이 되는지 알려 준다.
> 이 문서는 전체 흐름을 한곳에 모은 것이다. 자세한 내용은 번호 폴더에 있다.

## 2. 진행 흐름

| 날짜 | 단계 | 한 일 | 결과 |
|---|---|---|---|
| 11-20 | 자료 · 페르소나 | KREI 2025 원자료로 "혼밥러" 고객 집단부터 찾음 → 페르소나 0~14단계 칸 확정 | 페르소나 확정안 |
| 11-21 | 페르소나 보완 | 생활시간조사 2024 원자료로 "집 밖 혼밥" 집계 → 시나리오를 저녁에서 **점심**으로 바꿈. 직업을 KREI 2025로 다시 계산 | |
| 11-21 | 페인포인트 | 대구 거주자 글 수집, 달서구 인기 식당 289곳 · 무작위 114곳 1인분 직접 확인, 맛집 앱 필터 비교 | ①②③ 확정 |
| 11-21 | 근거 수정 | 2인분 이상 59곳 중 45곳은 조건을 메뉴판 **사진**에 적어 둠 → "정보가 없다"를 "사진 속 글씨라 못 찾는다"로 고침 | |
| 11-23 | 무작위 표본 재확인 | 114곳을 네이버로 다시 확인 → 온라인으로 판단 불가 63% → **39%** | |
| 11-23 | 혼술 검토 | 혼술을 혼밥 범주에 넣으려고 근거를 모음 | 팀 결정으로 다시 뺌 (기록만 남김) |
| 11-23 | 고객여정지도 | 고객 글 331건 정리 → 분류 → 점수 → Top 3 → 7단계 여정 지도 → 대조 검증 | 페인포인트 ④ 추가 |
| 11-23~24 | 밸류체인 | 산업 체인 · 서비스 체인 맵, 기회 O1~O3 점수, 팀 검증 23항목 반영 (v2: 배달 제외) | O2 선택, 11-27 기한 안 범위 확정 |
| 11-21~24 | 2인분 식당 데이터 | 공공 식당 목록 + 지도 · 리뷰 · 블로그로 1인분 판정, 달서구는 4명이 나눠 지도 직접 수집 | 대구 1차 데이터 4,487곳 |
| 11-24 | 챗봇 · 웹페이지 | 규칙 + Gemini 보조로 조건을 알아듣는 챗봇, 앱 화면 동작 시안 | 1차 프로토타입 |
