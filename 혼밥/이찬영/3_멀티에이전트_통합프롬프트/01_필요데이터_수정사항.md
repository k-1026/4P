### 2.2 10점 만점으로 바꾼 숫자

| 에이전트 | 기존 | 1126proto |
|---|---|---|
| 공통 | 취향 점수만 소수(8.6 등) | 개별 점수 모두 0~10 정수, 총점 0.0~10.0 |
| 공통 | 총점 소수 둘째 자리 | 소수 첫째 자리, "x.x / 10"으로 표기 |
| 취향 | 별점 기준 4점·3점·2.5점 | 10점 환산 8점·6점·5점 |
| 취향 | 후기 보정 ±0.5(별점) | ±1점 |
| 취향 | 제안 2점 이상 차이 | 3점 이상 차이 |
| 예산 | 10·6·2 / 10·6·4 / 8·6·4 (절대 금액) | 상대 비교 0~10 |
| 조율자 | 상의 기준 0.5 (5곳, 총점 0~10) | 0.5 그대로 (총점 0~10이라 같은 뜻) |

`honbap/ax/`의 `review-grader`는 100점 만점(80점 기준)이다.
1126proto 안의 판정에는 쓰지 않는다.
같이 쓰려면 루브릭을 10점 만점(8점 기준)으로 옮겨야 한다.
