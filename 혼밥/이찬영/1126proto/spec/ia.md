# IA — 사이트맵과 스토리 ↔ 화면 대응표

- 작성일: 2026-11-26
- 기준: 웹페이지 <https://honbap-bapchingu.vercel.app> 실제 화면 (`spec/userflow.md` v1과 같은 날 확인)
- 라벨은 앱에 보이는 사용자의 말을 그대로 썼다.

## 1. 사이트맵 (깊이 3 이내)

- AI 추천 (첫 화면)
  - 중요 순위 고르기 — "어떤 걸 더 중요하게 보세요?"
  - 업종 고르기 — "오늘 어떤 업종으로 선택할까요?"
  - 예산 고르기 — "예산은 얼마로 할까요?"
    - 위치 정보 시트 — "위치 정보를 쓸까요?"
  - 상의 진행 — ① 첫 의견 · ② 후보 고르기 · ③ 탈락 확인 · ④ 1차 점수 · ⑤ 상의
  - 최종 답 — "반짝이의 최종 답" 3곳 + 검증
  - 바로 가기 버튼 — 다시 상의하기 · 음식 종류 바꾸기 · 예산 바꾸기 · 순위 바꾸기 · 위치 다시 가져오기
- 지도 — "내 주변 혼밥 지도"
  - 가까운 순 가게 목록
    - 가게 상세 — 1인분 가능 · 혼밥 후기 · 거리 · 1인 메뉴 · 정보 확인 · 1인석 · 길찾기
- 혼밥일기 — "혼밥러들이 진짜 다녀온 곳"
  - 일기 목록 — 모두 공유 · 이웃 공유 · 최신순 · 인기순 · 내 동네 · 내 일기
  - 일기 쓰기 (사진 1장 이상)
- 마이
  - 나의 혼밥 레벨
  - 찜한 혼밥 맛집

## 2. 스토리 ↔ 화면

| 스토리 (`spec/spec.md` 4절) | 닿는 화면 | 인수 조건 확인 |
|---|---|---|
| US1 [필수] 근처 3곳 받기 | AI 추천 → 위치 정보 시트 → 최종 답 | 3곳·도보 분·1인 가격 있음. 위치 거부 문구 있음. 예산 1만 원 넘는 가게 없음. 결과 없음은 확인 못 함 |
| US2 [필수] 혼자 가도 되는지 근거 보기 | 지도 → 가게 상세 | 1인 메뉴·가격·혼밥 후기 수·본날 있음. "AI가 지도 메뉴 화면을 보고 적은 값 (사람 확인 전)" 있음. 1인석 짐작 안 함 |
| US3 [필수] 추천 이유 보기 | 상의 진행 → 최종 답 | 총점·이유·"AI 추천" 라벨 있음. "시간이 없어요"는 없음(중요 순위로 대신). 에이전트 실패는 확인 못 함 |
| US4 [나중] 1인석 있는 곳 먼저 | 가게 상세 | 칸만 있음 ("아직 모으는 중") |
| US5 [나중] 다녀온 뒤 기록 | 가게 상세 → 혼밥일기 | 일기 쓰기 있음. 1인분·1인석을 묻는 칸은 확인 못 함 |

- 화면이 없는 필수 스토리: 없음.
- 스토리가 없는 화면: 마이(혼밥 레벨·찜).
  `spec.md`에 스토리를 더할지 팀이 정한다.
