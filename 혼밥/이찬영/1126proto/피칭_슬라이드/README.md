# 피칭 슬라이드 (HTML)

- 작성일: 2026-11-26 (2026-11-27 재료·도구 폴더 추가)
- 팀 피칭 자료 `혼밥 피피티.pdf`(14쪽, 한 쪽 960×540pt)와 같은 크기·디자인으로 만든 HTML 슬라이드다.
- 파일 이름 앞 숫자는 피칭 PDF의 쪽 번호다.
  그 쪽의 빈 자리("넣을 자리")를 채우는 용도다.

## 1. 폴더 구조

```text
피칭_슬라이드/
├─ 08_유저플로우_실제.html              8쪽 · 1쪽
├─ 08_유저플로우_실제_계획_비교.html     8쪽 + 부록 · 3쪽
├─ 11_시장규모_TAM_SAM_SOM.html          11쪽 + 부록 · 2쪽
├─ 재료/                                 슬라이드 내용의 근거 (복사본)
│  ├─ 디자인_기준.md                     크기 · 색 · 틀 · 글꼴
│  ├─ 유저플로우/                        userflow.md · 계획_실제_플로우_차이.md · ia.md · spec.md
│  └─ 시장규모/                          market_model.xlsx · verify.md
└─ 도구/                                 슬라이드·시트를 만든 프로그램
   ├─ build_userflow_compare.py          08 실제 1쪽 → 실제·계획·비교 3쪽
   ├─ make_market_model.py               시장 규모 시트 만들기
   ├─ render_pdf_pages.swift             피칭 PDF를 쪽마다 PNG로
   └─ sample_colors.swift                PNG에서 색 뽑기
```

## 2. 슬라이드

| 파일 | 피칭 쪽 | 쪽 수 | 내용 |
|---|---|---|---|
| `08_유저플로우_실제.html` | 8쪽 | 1 | 실제 웹앱을 직접 써 본 유저플로우 |
| `08_유저플로우_실제_계획_비교.html` | 8쪽 + 부록 | 3 | 실제 · 계획 · 계획과 실제 비교 |
| `11_시장규모_TAM_SAM_SOM.html` | 11쪽 + 부록 | 2 | TAM 경상도 388만 · SAM 대구 77만 · SOM 동성로 2.4만, 바뀐 점 부록 |

- 브라우저로 열면 창 크기에 맞춰 커진다.
- 인쇄 → "PDF로 저장"을 하면 쪽마다 960×540 한 장으로 나온다.
  피칭 PDF의 같은 쪽과 바꿔 끼우면 된다.
