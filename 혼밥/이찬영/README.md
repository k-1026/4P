## 6. 한계와 주의

- 이 저장소는 **공개**라서 고객 글 원문(`voc_clean.csv`, 11-23 VOC 분류 md), 날씨 API 키, 빈 기록 파일은 넣지 않았다.
  VOC 결과에는 voc_id와 15자 이내 근거 구절만 있다.
- `api_key.txt`는 안내 문구만 있는 빈 틀이다.
  쓰려면 공공데이터포털 키를 직접 넣는다.
- 고객 글은 모두 D등급이다.
  건수는 분류 결과를 센 것이고, 혼밥 고객 전체의 비율로 읽으면 안 된다.
- `2_날씨_취향_에이전트`의 일부 코드는 내 컴퓨터의 `마이/` 폴더(거리 에이전트 js, 혼밥 DB)를 찾는다.
  그 파일이 없으면 해당 기능과 시험은 건너뛴다.
- 혼밥일기 · 취향요약 · 가게정보 파일은 시험용 예시다.
