# 작업 카드 — VOC 분류

## 목적

`voc_clean.csv` 331행을 팀이 정한 페인포인트 태그로 다시 분류한다.
이미 손으로 센 집계(2026-11-23)와 같은 결과가 나오는지 확인하는 것이 목적이다.

## 입력

- 원문: `voc_clean.csv` (331행, N번째 행 = 파일의 N+1번째 줄)
- 태그 정의: `painpoint/페인포인트정의서_A2-A4.md` (P1~P4 진술문 · 판정 힌트 · 분류 규칙)

## 작업자 · 루브릭

- 작업자: `voc-tagger`
- 루브릭: `ax/rubrics/voc_tagging.md`

## 태그 (이 목록 밖의 태그는 쓰지 않는다)

| 태그 | 뜻 |
|---|---|
| P1 | 가게가 1인분·1인 양을 팔지 않거나 혼자 온 손님을 받지 않아서 막힘 |
| P2 | 그 가게·업종이 혼자 와도 받아 주는지 미리 몰라서 막힘 |
| P3 | 근처에서 혼자 먹을 만한 곳을 한 번에 찾지 못해서 막힘 |
| P4 | 혼자 앉을 자리가 없거나 눈치가 보여서 막힘 |
| H1 | 배달 양이 혼자 먹기에 많음 (범위 밖) |
| H2 | 혼자 먹는 게 외롭거나 지겨워서 같이 먹을 사람을 찾음 (보류) |
| G | 좋은 경험: ① `메모` 칸에 `혼밥태그=1`이 있는 리뷰 (네이버 키워드 "혼밥하기 좋아요"), 또는 ② 혼밥태그가 없어도 본문이 혼밥을 칭찬하는 리뷰 (아래 판정 규칙) |
| 해당없음 | 칭찬 · 맛/품질 평가 · 가격 언급만 있는 글, 혼밥·1인분 경험을 적었지만 혼밥 칭찬은 없는 글, 추천만 묻는 질문 |
| 검토 | 원인이 둘 이상 섞임, 본인 경험이 아닌 전언, 외국어 등으로 판단이 불확실함 |
| 제외 | `행위자`가 `아니오`인 행 (외지인 등, 분류하지 않음) |

## 판정 규칙

- 정의서의 판정 힌트를 따른다.
- 특정 가게·업종이 되는지 물으면 P2, 근처 전체에서 못 찾았다고 하면 P3.
- 1인분 때문에 같이 갈 사람을 찾으면 P1, 혼자인 것 자체가 싫어서 찾으면 H2.
- G는 P1~P4보다 뒤에 본다.
  `혼밥태그=1`이라도 본문에 P1~P4의 막힘이 있으면 그 태그를 쓴다.
- 혼밥태그가 없는 리뷰(`혼밥태그=0`)는 본문에 혼밥 칭찬이 있을 때만 G다 (2026-11-25 사람 결정).
  - G: 본문이 "혼밥하기 좋아요", "혼밥 하시기에도 좋을 거", "혼밥,혼술하기에도 너무좋은 곳"처럼 혼자 먹기 좋다고 칭찬함 (v_025 · v_065 · v_187 · v_188).
  - 해당없음: "1인메뉴구성도 있어서", "혼밥했어요"처럼 혼밥·1인분 경험만 적고 혼밥 칭찬은 없음 (v_019 · v_204).
  - 혼술만 칭찬하면 G가 아니다.
- 이 카드는 voc-tagger의 기본값을 덮어쓴다.
  - 맞는 태그가 없을 때는 `보류`가 아니라 `검토`를 쓴다.
  - 근거 문장은 원문 구절을 그대로 **15자 이내**로 옮긴다.
  - `혼밥태그=1`로 정한 G의 근거 문장은 `[키워드] 혼밥하기 좋아요`로 쓴다.
  - 본문 칭찬으로 정한 G의 근거 문장은 혼밥 칭찬 구절을 원문 그대로 15자 이내로 쓴다.
  - 제외의 근거 문장은 `행위자=아니오`로 쓴다.

| 묶음 | 행 범위 | 출력 |

## 출력

- 합본: `ax/demo/voc_tagged.csv` (열: `voc_id,태그,근거 문장,확신도,메모`, voc_id 순서)
- 채점 보고: `ax/demo/grade_report.md`

## 완료 기준

1. 331행이 빠짐·중복 없이 모두 있고, 행마다 태그가 하나다.
2. 묶음마다 루브릭 80점 이상이다.
3. 태그별 건수를 기존 집계와 나란히 놓고, 차이가 있으면 voc_id와 이유를 적는다.

| 태그 | 기존 집계 (2026-11-23) | 에이전트 분류 + 사람 확인 (2026-11-25, 지금 기준) |
|---|---|---|
| P1 | 5 | 5 |
| P2 | 18 | 17 |
| P3 | 4 | 4 |
| P4 | 10 | 12 |
| H1 | 2 | 2 |
| H2 | 3 | 4 |
| G | 178 | 182 |
| 해당없음 | 65 | 59 |
| 검토 | 0 | 0 |
| 제외 | 46 | 46 |
| 합계 | 331 | 331 |

- 다음 실행부터는 2026-11-25 열과 비교한다.
  2026-11-23 열은 G를 `혼밥태그=1`로만 정하던 때의 집계다.
- 2026-11-25 열의 행별 태그는 `ax/demo/voc_tagged.csv`에 있다.
  차이가 나면 이 파일과 voc_id별로 대조한다.

## 사람 확인 지점

- 무작위 10행을 원문과 나란히 보여 준다.
- P1~P4로 분류된 행은 전부 원문과 나란히 보여 준다.
- 기존 집계와 다른 행은 전부 보여 준다.

## 하지 말 것

- 태그 정의를 바꾸거나 새 태그를 만들지 않는다 (팀 결정이 필요한 일).
- 점수(빈도 × 강도 × 해결)를 다시 매기지 않는다.
- 원문을 길게 옮기지 않는다.
