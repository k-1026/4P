# 네이버 지도 리뷰 수집 — 02_동구

> **팀원 사용법 (Aside에 붙여 넣기 전에 읽기)**
> 1. 아래 "이번 회차" 칸의 **회차 번호와 순서 범위만 바꿔서** 이 파일 전체를 Aside에 붙여 넣는다 (1회차 = 순서 1~30, 2회차 = 31~60, … 10회차 = 271~300)
> 2. Aside가 만든 `네이버리뷰_동구_<회차>.csv`를 팀 폴더 `painpoint/수집_네이버리뷰_1118/결과/`에 넣는다
> 3. 로봇 확인(캡차) · 접속 제한이 나오면 그날은 멈추고 다음 날 이어서 한다. 순서 1~300을 다 했는데 리뷰 있는 가게가 300곳이 안 되면 **11회차(예비 301~450)**로 채운다

---

## 이번 회차

- **회차: 1**
- **순서: 1번부터 30번까지** (예비 회차면: 301번부터, 리뷰 있는 가게가 ___곳 더 모일 때까지)

---

너는 네이버 지도(map.naver.com)에서 대구 음식점의 **방문자 리뷰**를 모으는 조사 도우미야. 아래 "가게 목록"에서 **이번 회차 순서 범위에 있는 가게만** 차례대로 찾아서, 가게마다 **최신 방문자 리뷰 20개**를 모아 CSV 파일 하나로 저장해 줘.

## 가게 찾는 법
1. 네이버 지도에서 **상호 + 도로명주소**로 검색해 (상호만 검색하면 다른 지점이 나올 수 있어)
2. 검색 결과의 주소가 목록의 도로명주소와 **같은 건물(도로명 + 건물번호)**인지 확인해
   - 같으면 "같은가게 = 예"
   - 상호는 같은데 주소가 다르면 "아니오" — 리뷰는 모으지 마
   - 상호는 바뀌었지만 같은 주소에 음식점이 하나뿐이면 "모름" — 리뷰를 모아
3. 못 찾으면 "찾음여부 = 못찾음", 지도에 "폐업" · "영업 종료" 같은 표시가 있으면 "찾음여부 = 폐업표시"

## 리뷰 모으는 법
1. 가게 페이지의 **리뷰 → 방문자 리뷰** 탭으로 가
2. 정렬을 **"최신순"**으로 바꿔
3. 위에서부터 **20개**를 모아. 긴 리뷰는 "더보기"를 눌러 **본문 전체**를 적어
4. **방문일이 2025년 1월 1일보다 이전인 리뷰가 나오면 거기서 멈춰** (20개가 안 돼도 됨)
5. 블로그 리뷰 · 사장님 답글 본문은 모으지 마

## 꼭 지킬 것
- **작성자 닉네임 · 프로필 · 팔로워 수 · 사진 파일은 적지 마** (개인정보)
- 로그인하지 마. 리뷰 쓰기 · 저장 · 좋아요 · 신고를 누르지 마
- 가게 사이에 **5초 이상 쉬어** (서버에 부담 주지 않기)
- **로봇 확인(캡차) · 접속 제한 화면이 나오면 바로 멈추고**, 그때까지 모은 것만 저장한 뒤 어디까지 했는지 알려 줘. 우회하지 마
- 화면에 없는 값은 지어내지 말고 빈칸으로 둬

## 저장할 CSV — `네이버리뷰_동구_<회차>.csv` (UTF-8)

**한 줄 = 리뷰 1개.** 리뷰 20개를 모은 가게는 20줄이 되고, 줄마다 가게 정보 열을 똑같이 채워. 못 찾았거나 리뷰가 0개인 가게도 **한 줄** 남겨 (리뷰 칸은 빈칸).

첫 줄(열 이름)은 그대로 써:

```
구군,순서,구분,관리번호,상호,네이버_상호,네이버_주소,같은가게,찾음여부,영업상태_문구,방문자리뷰_수,리뷰순번,방문일,몇번째방문,인증,키워드태그,본문,사장님답글,확인시각
```

| 열 | 적는 법 |
|---|---|
| 구군 · 순서 · 구분 · 관리번호 · 상호 | 아래 목록 그대로 |
| 네이버_상호 · 네이버_주소 | 네이버 지도에 보이는 그대로 |
| 같은가게 | 예 / 아니오 / 모름 |
| 찾음여부 | 찾음 / 못찾음 / 폐업표시 |
| 영업상태_문구 | 화면에 보이는 그대로 (예: "영업 중", "오늘 휴무", "브레이크타임") |
| 방문자리뷰_수 | 가게 페이지에 표시된 방문자 리뷰 개수 |
| 리뷰순번 | 1~20 (리뷰가 없는 줄은 빈칸) |
| 방문일 | 화면 표시 그대로 (예: "25.11.3.월") |
| 몇번째방문 | "2번째 방문"처럼 표시되면 숫자만, 없으면 빈칸 |
| 인증 | 영수증 / 예약 / 결제 / 표시 없음 |
| 키워드태그 | "음식이 맛있어요" 같은 선택 태그를 " \| "로 이어서 |
| 본문 | 큰따옴표로 감싸고, 줄바꿈은 공백으로 바꿔 |
| 사장님답글 | 있음 / 없음 (답글 내용은 적지 마) |
| 확인시각 | 그 가게를 본 시각 (예: 2026-11-19 14:05) |

파일 저장이 안 되면 CSV 전체를 코드 블록으로 답변에 붙여 줘.
