## 3. 정한 것 · 지킨 원칙

- **식당 이름과 1인분 판정은 팀 데이터에서만 나온다.** 챗봇·에이전트 모두 LLM은 "알아듣기"와 "말하기"만 하고, 판정·점수·검증은 코드로 한다.
- 카카오는 좌표만 붙이고, 블로그 신호는 점수만 더하거나 뺀다. 블로그에 "2인분부터"가 보여도 판정은 바꾸지 않고 "팀 확인 필요"로 남긴다.
- 검증에서 통과가 3곳 미만이면 반려 사유를 보드에 적고, 오케스트레이터가 조건 하나를 풀어 다시 돈다 (최대 3회).
- 리뷰 판정은 AI가 붙이고 **사람이 직접 읽어 검수**한다 (AI가 AI를 검사하지 않음).
- 지도에서 본 자료는 비율(%)로 쓰지 않고, 공개 저장소에 올리지 않는다.
