# 메뉴 갱신 에이전트 — 1단계 (2026-11-26)

뭉쳐 있는 메뉴 글을 **메뉴 한 줄 = 한 행** 표로 풀고, 가게마다 **대표메뉴**를 하나 고른다.
가격 에이전트는 `stores_signature.csv`의 `대표가격`을 바로 쓰면 된다.

## 실행

```bash
python build_menus.py          # 식당목록/ 을 읽어 결과/ 에 만든다
python test_menu_parse.py      # 테스트 (12개)
```

`식당목록/`에는 저장소 `혼밥/07_챗봇/식당목록/`의 두 파일을 넣는다.
- `대구푸드_맛집DB_905곳.json`
- `대구_수집양식_1차_20261124.csv` (이름에 `수집양식`이 들어간 CSV는 모두 읽음)

## 파일

| 파일 | 하는 일 |
|---|---|
| `menu_parse.py` | 메뉴 글 풀기, 대표메뉴 고르기 |
| `build_menus.py` | 두 출처를 읽어 결과 파일 2개를 만든다 |
| `test_menu_parse.py` | 실제 데이터 예시로 만든 테스트 |
| `결과/menus.csv` | 메뉴 표 (메뉴 한 줄 = 한 행) |
| `결과/stores_signature.csv` | 가게 한 곳 = 한 행. 대표메뉴 · 대표가격 · 근거 |

## 메뉴 표 칸

| 칸 | 예 |
|---|---|
| 메뉴명 · 가격 · 가격_최대 | 아귀찜 · 45000 · 60000 |
| 가격종류 | 고정 · 범위 · 변동(시가·가격 변동) · 없음 |
| 크기 · 인분 | 소/중/대 · 1인분, 2인, 2인분부터 (혼밥 에이전트가 쓸 신호) |
| 곁들이 | 공기밥·사리·추가·음료·술이면 Y (대표메뉴에서 뺌) |
| 대표메뉴 · 대표_근거 | Y · 가게이름 / 메뉴판첫번째 / 메뉴판첫번째(가격없음) |

## 대표메뉴 고르는 규칙

1. 가게 이름과 겹치는 메뉴: `할매돼지국밥` → 돼지국밥
2. 없으면 메뉴판 맨 앞의 가격 있는 메뉴
3. 그것도 없으면 메뉴판 맨 앞의 메뉴 (가격 없음)
- 곁들이 메뉴와 "가격 변동" 메뉴는 고르지 않는다.

## 결과 (11-26 실행)

가게 5,392곳 · 메뉴 8,366줄

| 출처 | 대표가격 있음 | 대표메뉴만 (가격 없음) | 대표메뉴 없음 |
|---|---|---|---|
| 대구푸드 905곳 | 895 | 7 | 3 |
| 수집양식 4,487곳 | 151 | 2,617 | 1,719 |

- 수집양식은 1인분 판정용으로 모은 자료라 메뉴 칸에 **가격이 거의 없다**. 대표메뉴 없음 1,719곳은 메뉴 칸이 비었거나 "한식"·"분식" 같은 업종 이름만 있다.
- 두 출처에 같은 가게가 있어도 아직 합치지 않았다 (`store_id`가 다름). 합치기는 다음 단계에서 `store_match.py` 규칙으로 한다.
