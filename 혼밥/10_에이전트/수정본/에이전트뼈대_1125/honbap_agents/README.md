# 09 혼밥 에이전트 뼈대

혼밥 챗봇(`../07_챗봇`)을 **오케스트레이터 + 에이전트 4개** 구조로 나눈 뼈대입니다.
파이썬 기본 기능만 써서 설치할 것이 없고, API 키가 없어도 팀 데이터만으로 돌아갑니다.

## 그림과 파일

| 그림의 칸 | 파일 | 쓰는 도구 · API | LLM |
|---|---|---|---|
| 오케스트레이터 | `agents/orchestrator.py` | 다른 에이전트 부르기 | Gemini (계획 · 재계획) |
| 탐색 | `agents/explore.py` + `store_lookup.py` | 팀 데이터 + **카카오 장소 검색** (+ 네이버 지역 검색 보조) | 안 씀 |
| 혼밥 분석 | `agents/honbap.py` | 팀 1인분 판정 + **카카오 블로그 검색** | Gemini (블로그 신호 읽기) |
| 상황 | `agents/context.py` | 영업시간(팀 데이터) + **기상청 초단기실황** + **TMAP 보행자** | 안 씀 |
| 검증 | `agents/verify.py` | 규칙 체크리스트 `CHECKS` | 안 씀 (if문이 더 정확) |
| 공유 상태 | `board.py` | — | — |
| 도구 (회색 칸) | `tools.py` | 위 API 호출 모음 | — |

Gemini 키가 없거나 호출이 실패하면 LLM이 하던 일을 규칙으로 대신합니다.

## 흐름

```
사용자 말
  → 오케스트레이터: 조건 뽑기 (구 · 음식 · 메뉴 · 예산 · 걷는 시간)
  → 탐색 → 혼밥 분석 → 상황 → 검증   (모두 같은 Board를 읽고 씀)
  → 검증 통과 3곳 미만이면 반려 사유를 Board에 적음
  → 오케스트레이터가 사유를 읽고 조건 하나를 풀어 다시 (최대 3회)
```

### 가게 하나를 물어볼 때 ("○○ 혼밥 가능해?")

```
오케스트레이터: 문장에서 가게 이름 꺼내기 (store_lookup.extract_store_name)
  ├ 팀 데이터에 1곳      → 채택, 탐색 건너뜀
  ├ 팀 데이터에 여러 곳  → "어느 가게인가요?" 되묻기
  └ 팀 데이터에 없음     → 탐색 에이전트 (explore.find_store)
         카카오(없으면 네이버)에서 대구 음식점만 찾음
         → 찾은 가게를 상호+주소로 팀 데이터와 다시 맞춤 (가게잇기_규칙 A·B·C)
         → 1곳: 혼밥 분석으로 / 여러 곳: 되묻기 / 0곳: 못 찾음
→ 혼밥 분석 → 상황 → 검증 (가게를 빼지 않고 걸린 규칙만 알려 줌, 재계획 없음)
```

"추어탕집", "국밥" 같은 음식 이름은 가게 이름이 아니므로 조건 검색으로 넘어갑니다.

재계획 예: `"달서구 고기 걸어서 5분"`에서 30곳이 모두 멀어 반려되면 걷는 한도를 15분으로 늘려 다시 돌립니다.

## 팀 원칙을 코드로 지킨 곳

- **가게 목록과 1인분 판정은 팀 데이터에서만 나옵니다.** 카카오는 좌표만 붙이고, 블로그는 점수만 더하거나 뺍니다.
- 블로그에 "2인분부터"가 보여도 판정은 바꾸지 않습니다. 대신 `flags`에 "팀 확인 필요"로 남깁니다.
- 2인분 이상 가게는 기본으로 빠지며, 재계획에서도 넣지 않습니다.
- LLM이 낸 조건은 `clean()`을 거쳐 허용된 값만 남습니다.
- 검증의 `not_team_data` 규칙이 팀 데이터에 없는 가게(지어낸 가게)를 막습니다.

## 돌려 보기

```bash
python main.py "달서구 국밥 만원"
python main.py "성서 고기 1만2천원 이하 걸어서 10분" --origin 128.4958,35.8547
```

팀 데이터는 `data/혼밥챗봇_완성본.html`이나 `../07_챗봇/혼밥챗봇_완성본.html`에서 읽습니다.

## 키 넣기

`.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 채웁니다. `.env`는 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다.

| 키 | 받는 곳 | 없으면 |
|---|---|---|
| `GEMINI_API_KEY` | Google AI Studio | 규칙으로 계획하고 블로그도 규칙으로 읽음 |
| `KAKAO_REST_KEY` | 카카오 디벨로퍼스 (REST API 키) | 좌표 · 블로그 없음 → 걷는 시간 모름 |
| `KMA_SERVICE_KEY` | 공공데이터포털 기상청 단기예보 (Decoding 키) | 날씨 모름 |
| `TMAP_APP_KEY` | SK open API (선택) | 직선거리로 걷는 시간 어림 |
| `NAVER_CLIENT_ID` · `NAVER_CLIENT_SECRET` | 네이버 개발자센터 검색 API (선택) | 카카오에서 못 찾은 가게는 '못 찾음' |
