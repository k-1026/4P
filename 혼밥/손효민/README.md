## 3. 지금 규칙

| 항목 | 규칙 |
|---|---|
| 가중치 (총합 10) | 거리 2 고정. 날씨·자리·새로움·가격은 순위대로 3.2 / 2.4 / 1.6 / 0.8 |
| 후보 | 고른 업종 안에서 1km 이내 가까운 20곳. 2인분 메뉴 제외 |
| 가격 | 말한 예산 초과 탈락. 가장 싼 곳 10점 ~ 가장 비싼 곳 0점 |
| 혼밥 | 후보 안 후기 순위 8점 + 1인석 2점 |
| 상의 | 에이전트끼리 판정하지 않음. 사용자가 반론 가게의 점수를 높일지 선택 |

## 4. 정한 것 (사람 결정)

- 고정 가중치 35·20·20·15·10은 쓰지 않고, 사용자가 정한 순위로 가중치를 정한다.
- 업종을 먼저 묻고 그 업종의 가까운 20곳을 본다. 버거·토스트는 기타.
- 상의는 에이전트끼리 결론 내지 않고 사용자가 고른다.
- 지도는 내 주변을 크게 보여 주고, 아래 목록에는 반경 안 가게를 모두 넣는다.

## 5. 팀원 작업과의 관계

- **가게 DB**(동성로 391곳)와 혼밥 점수 규칙은 [`../이재훈`](../이재훈) 의 최종본을 썼다.
- **날씨·취향·조율자·메뉴 에이전트의 바탕**과 멀티 에이전트 설계는 [`../이찬영`](../이찬영) 에 정리돼 있다. 이 폴더의 코드는 그 위에서 11-26에 고친 판이다.

## 6. 앱 실행 (`02_앱_중간본`)

```
copy .env.example .env      (KMA_API_KEY, KAKAO_JS_KEY 를 직접 채운다. 올리지 말 것)
python run_local.py         -> http://localhost:8770
```

- 파이썬 3만 있으면 된다. 배포 방법은 안의 `README.md`.
- 가게 DB는 **공개용**(`data/혼밥_동성로.db`)이라 지도 링크가 없다. 앱의 "지도에서 가게 정보 보기" 버튼은 나오지 않는다.
