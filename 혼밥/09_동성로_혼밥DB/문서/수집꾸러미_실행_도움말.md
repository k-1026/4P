# 동성로 수집 실행 도움말 (팀원용, 2026-11-26)

`동성로_추가1~4` 꾸러미를 돌릴 때 자주 막히는 것을 모았습니다. 각 폴더의 `안내.md`와 함께 보세요.

## 1. 어떻게 도는지

- **1묶음 = 가게 5곳**입니다. `prompt_000.txt`, `prompt_001.txt` … 하나가 한 묶음입니다.
- **`수집시작.bat`을 두 번 클릭**하면 파이썬 프로그램(`수집.py`)이 아래를 자동으로 되풀이합니다.

```
① prompt_000(가게 5곳)을 Aside에 넣음
② Aside가 네이버 지도를 보며 5곳 확인 (약 5분)  ← 그동안 캡차·오류를 지켜봄
③ 답을 out_000.csv로 저장
④ 다음 prompt_001을 넣음 → ② → ③ …
⑤ 마지막 묶음까지 끝나면 '모두 끝'
```

- 사람은 **처음에 한 번만** 누르면 됩니다. 한 번에 한 묶음씩만 돕니다.
- 멈췄다가 다시 누르면 **끝난 묶음은 건너뛰고** 이어서 합니다.

## 2. 꼭 지킬 것

| 하지 말 것 | 이유 |
|---|---|
| **Claude(채팅·Claude Code)에게 실행을 맡기기** | Claude는 명령을 몇 분만 기다리고 끕니다. 그래서 **첫 묶음만 하고 꺼집니다.** 웹 채팅 Claude는 Aside를 움직일 수 없어 지도를 보지 않고 답을 지어낼 수도 있습니다 |
| **결과 파일(`out_*.csv`)을 엑셀로 열고 저장하기** | 한글과 따옴표가 바뀌어 합칠 때 깨집니다. 엑셀로 **보기만** 하는 것은 괜찮습니다 |
| 결과를 손으로 고치거나 덧붙이기 | 지도에서 본 그대로여야 합니다 |
| 검은 창을 여러 개 띄우기 | 캡차가 뜨기 쉽습니다 |
| 캡차를 다른 프로그램·AI로 풀기 | 사람이 직접 풉니다 |

**Claude로 꼭 돌려야 한다면** "이 bat을 **백그라운드로** 실행해 줘" 또는 "**터미널 탭에서** 실행해 줘"라고 부탁하세요. 그래도 가장 확실한 것은 **직접 두 번 클릭**입니다.

## 3. 윈도우에서 안 될 때

| 검은 창에 나온 글 | 원인 | 해결 |
|---|---|---|
| `'python'은(는) 내부 또는 외부 명령 … 이 아닙니다` | 파이썬이 없거나 PATH가 안 켜짐 | python.org에서 다시 설치. 첫 화면에서 **'Add python.exe to PATH'** 켜기 |
| `aside 명령을 찾지 못했습니다` | Aside 명령 도구(CLI)가 없음 | Aside 설정(Settings) 화면을 찍어 담당자에게 보내기 |
| 파란 창 'Windows의 PC 보호' | 윈도우 보안 경고 | **'추가 정보' → '실행'** |
| 창이 바로 꺼짐 | 위 중 하나 | 폴더 빈 곳에서 Shift+오른쪽 클릭 → '터미널에서 열기' → `.\수집시작.bat` 입력 → 나온 글을 담당자에게 |

## 4. 멈췄을 때

폴더의 **`진행.txt`** 마지막 줄을 보세요.

| 마지막 줄 / 화면 | 할 일 |
|---|---|
| `000 정상 5/5곳`처럼 정상인데 더 진행이 없음 | 누가 프로그램을 끈 것(Claude 시간 제한 등). **bat을 직접 다시 클릭** |
| `25분 넘음` | 한 묶음이 25분을 넘겨 스스로 멈춘 것(평소엔 5분 안팎). 다시 클릭. 같은 묶음이 두 번 멈추면 담당자에게 |
| `결과 없음`, `빠진 가게`, `오류로 끝남` | 다시 클릭 |
| 'Authentication failed' / 시작하자마자 `오류로 끝남` 반복 | Aside › Settings › Models › Claude가 'Reauthentication required'면 다시 로그인 후 다시 클릭 |
| 사용량 한도(limit, usage) | `멈춤.txt`를 만들고, 한도가 풀리면 지우고 다시 클릭 |
| '캡차가 뜬 것 같습니다' 알림 창 | Aside 브라우저에서 **직접** 풀고 `막힘.txt`를 지운 뒤 다시 클릭. **학원 컴퓨터는 모두 같이 멈추고** 담당자에게 알리기 |
| '이용 제한' 화면 | **아무것도 누르지 말고** 담당자에게 |

**한 묶음 25분 제한**은 Aside가 멈춰 버렸을 때 영원히 기다리지 않게 하는 안전장치입니다. 끄지 마세요.

## 5. 끝나면

1. 검은 창에 **'모두 끝'**이 나오면 창을 닫습니다.
2. **`동성로_추가N` 폴더를 통째로 압축**해 담당자에게 보냅니다(`out_*.csv`, `err_*.txt`, `진행.txt` 포함). 엑셀로 저장한 파일은 빼 주세요.
3. 공용 컴퓨터라면 Aside의 Claude 연결을 끊고 로그아웃합니다.
4. 결과에는 지도 정보가 들어 있으니 **팀 안에서만** 주고받고 깃허브에 올리지 마세요.
