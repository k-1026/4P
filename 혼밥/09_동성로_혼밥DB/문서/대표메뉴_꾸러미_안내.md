# 대표 메뉴·가격 수집 꾸러미 — 처음 보는 사람용 안내 (2026-11-26)

메뉴·가격 에이전트 담당 팀원이 **혼자서 처음부터 끝까지** 할 수 있게 만든 꾸러미입니다.
혼밥 DB **최종본(391곳)** 가게마다 네이버 지도 메뉴 탭에서 **가게가 '대표'라고 표시한 메뉴와 가격**을 모읍니다.
명령어를 몰라도 됩니다. **bat 파일을 두 번 누르는 것**만으로 수집, 진행 보기, 합치기를 합니다.

## 0. 준비 (처음 한 번)

1. **압축 풀기**: zip을 오른쪽 클릭 → '압축 풀기'. 바탕화면처럼 **경로가 짧은 곳**에 푸세요. 폴더 이름은 바꾸지 마세요.
2. **파이썬 확인**: 시작 메뉴에서 'cmd'를 열고 `python --version`을 입력합니다. `Python 3.…`이 나오면 됩니다.
   안 나오면 python.org에서 설치하고, 설치 첫 화면의 **'Add python.exe to PATH'를 꼭 체크**하세요.
3. **Aside 확인**: Aside 앱을 설치하고 자기 계정으로 로그인합니다.
   Aside › Settings › Models › Claude 가 **'Subscription'** 으로 연결돼 있어야 합니다. 'Reauthentication required'가 보이면 다시 로그인하세요.
4. 네이버 로그인은 필요 없습니다.

## 1. 수집 시작

1. 폴더 안의 **`수집시작.bat`을 두 번 누릅니다.** 검은 창이 뜹니다.
2. 처음에 `묶음 79개 중 79개 남음`이 나오고, 묶음이 끝날 때마다 `000 정상 5/5곳 4.2분 …`처럼 한 줄씩 찍힙니다.
3. **검은 창을 닫지 말고 켜 두세요.** 컴퓨터가 잠들지 않게 전원 설정에서 '절전 안 함'으로 두면 좋습니다.
4. 창이 꺼지거나 컴퓨터를 껐다 켜도 괜찮습니다. **다시 `수집시작.bat`을 누르면 끝난 묶음은 건너뛰고 이어서** 합니다.
5. 끝나면 `모두 끝`이 나옵니다.

**하지 말 것**
- Claude·ChatGPT에게 "실행해 줘"라고 시키지 마세요. 그쪽 도구의 시간 제한 때문에 첫 묶음 뒤 꺼집니다. **bat은 직접** 누르세요.
- 수집이 도는 동안 **같은 컴퓨터에서 네이버 지도를 따로 열지 마세요**(캡차 위험). 같은 Aside 계정으로 다른 수집을 동시에 돌리지도 마세요.
- `out_*.csv`를 엑셀로 열고 **저장하지 마세요**(글자가 깨집니다).

## 2. 진행 보기

**`진행보기.bat`을 두 번 누르면** 이렇게 나옵니다. 아무것도 바꾸지 않으니 언제 눌러도 됩니다.

```
묶음 79개 중 끝난 것 12개, 남은 것 67개 (한 묶음 5곳)
최근 기록:
   011 정상 5/5곳 3.8분 11-27 10:41:02
마지막 기록은 2분 전입니다.
남은 시간은 대략 3시간 21분 ~ 6시간 42분입니다.
```

- '마지막 기록'이 **30분 넘게** 그대로면 검은 창이 꺼졌는지 보고, 꺼졌으면 `수집시작.bat`을 다시 누르세요.

## 3. 멈췄을 때

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| "캡차(사람 확인)" 알림 창 | 네이버가 사람인지 물음 | ① Aside 브라우저에서 캡차를 **직접** 풀기 ② 폴더의 `막힘.txt` 지우기 ③ `수집시작.bat` 다시 누르기 |
| "이용 제한" 화면 | 네이버가 잠시 막음 | **아무것도 누르지 말고** 몇 시간 쉰 뒤 `막힘.txt`를 지우고 다시. 또 나오면 그날은 그만 |
| "Aside 작업이 아직 돌고 있을 수 있습니다" | 프로그램이 Aside를 못 멈춤 | Aside 앱에서 도는 작업을 직접 멈추고, `막힘.txt`를 지우고 다시 |
| `빠진 가게 n곳`, `결과 없음`, `25분 넘음` | 그 묶음만 잘 안 됨 | `수집시작.bat`을 다시 누르면 그 묶음부터 다시 함. 같은 묶음이 3번 넘게 안 되면 아래 '도움받기' |
| `aside 명령을 찾지 못했습니다` | Aside가 없거나 설치가 덜 됨 | Aside를 설치하고 로그인한 뒤 다시 |
| `'python'은(는) … 아닙니다` | 파이썬이 없음 | 0번의 2를 다시 |
| 잠깐 멈추고 싶을 때 | | 폴더에 빈 파일 `멈춤.txt`를 만들면 지금 묶음 뒤 멈춤. 이어서 하려면 지우고 다시 누르기 |

## 4. 다 끝나면: 합치기

**`합치기.bat`을 두 번 누릅니다.** 폴더에 두 파일이 생깁니다.

| 파일 | 한 줄에 | 칸 |
|---|---|---|
| `대표메뉴_결과.csv` | 가게 하나 | 식당ID, 상호, 찾음, 대표메뉴(화면 글 그대로), 대표수, 메뉴_최근업데이트, 링크, 메모, 본날 |
| `대표메뉴_목록.csv` | 메뉴 하나 | 식당ID, 상호, 메뉴명, 가격_글('12,000원', '시가' 그대로), 가격_원(숫자, 범위면 작은 값), 본날 |

- 엑셀로 열어 봐도 됩니다(이 두 파일은 저장해도 됨. 합치기를 다시 누르면 새로 만들어짐).
- 끝에 `답 없음 n곳`이 나오면 `수집시작.bat`을 한 번 더 누르세요. 그 묶음만 다시 돕니다. 그다음 합치기를 다시 누르세요.
- `대표수`가 **0**이면 가게가 '대표' 표시를 하나도 안 한 곳입니다. 대표가 아닌 메뉴로 **대신 채우지 않았습니다.** 이런 곳을 어떻게 할지는 **메뉴·가격 담당(나)이 정하면 됩니다.** 예: 혼밥 DB의 `주요메뉴`로 채우기, 빈칸으로 두기.

## 5. 혼밥 DB와 잇기

- 가게는 **식당ID**로 잇습니다(이름은 지점 표기가 달라질 수 있음).
- 꾸러미 안의 `혼밥_동성로.db`(SQLite, 최종본)에 같은 식당ID가 있습니다. 파이썬 예:

```python
import sqlite3, csv
con = sqlite3.connect("혼밥_동성로.db")
for r in con.execute("SELECT 식당ID, 상호, 메뉴명, 가격 FROM 주요메뉴 JOIN 식당 USING(식당ID) LIMIT 5"):
    print(r)
```

- `L`로 시작하는 식당ID는 나중에 매주 갱신(인허가)으로 새로 들어온 가게입니다.

## 6. 가게가 늘었을 때 (최종본, 매주 갱신)

이재훈에게서 **새 혼밥 DB 파일**을 받으면, 이미 본 가게는 빼고 **새 가게만** 새 폴더에 묶습니다. 이것만 명령 창에서 합니다.

1. 꾸러미 폴더 주소창에 `cmd`를 입력하고 Enter → 그 폴더에서 명령 창이 열립니다.
2. 아래를 입력합니다(새 DB 경로와 폴더 이름만 바꾸기).

```
python -I 만들기.py --db "C:\받은곳\혼밥_동성로.db" --out 추가_20261203 --새것만
```

3. 새로 생긴 `추가_20261203` 폴더 안의 **`수집시작.bat`** 을 두 번 누릅니다.
4. 끝나면 꾸러미 폴더의 명령 창에서 `python -I 합치기.py . 추가_20261203` → 처음 결과와 새 결과가 한 파일로 합쳐집니다.
