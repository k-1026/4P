# 혼밥 문제 정의 — 근거표 v2 (3가지 기준 · 출처 등급 표기)

> 작성·확인일 2026-11-19 · 서비스 정의(사용자): 대구에서 혼밥을 자주 하는 1인가구가 취향(분위기·가격·업종 등)을 선택해 혼자 가기 편한 혼밥집을 추천받는 서비스
> 기록 형식(슬라이드 5단계): 주장 한 줄 + 출처 + 등급 + 기준 시점 + 확인일 · 숫자는 A·B 등급만 사용
> 등급: **A** 공식 통계·원시자료 · **B** 연구 보고서·학술 논문(논문·KB금융 경영연구소 보고서는 작성자가 B로 매겼고 사용자가 확정, KB는 비확률 표본이라 보조로만 사용) · C 언론 · D 블로그·SNS·리뷰
> 상태: 🟢 충분 · 🟡 부분·주의 · ⚪ 없음 · 🔵 사용자 파일 경유(원문 직접 확인 못 함)

## 쓰지 않은 자료
- 대구 2015·2023·2024·구·군별 신문 수치: KOSIS CSV(A)로 대체 확인되어 원자료를 사용
- (정정) KB금융 보고서의 혼밥 비율(67.8%·65.2%)은 보고서 원문(2024 보고서 4쪽)에서 확인되어 3-4로 반영. 단 민간 연구소·비확률 표본이라 보조로만 사용
- VOC 건수·묶음 비율, 4P 설문(81명): 숫자 근거로 쓰지 않음(사례·체감으로만)
- 대구 혼밥 구조 관련 신문·블로그 수치(1인 메뉴 10.4% 등): C·D 등급 또는 미확인
- 생활시간조사 2004→2009 혼자 식사 행위자 비율, 국민건강영양조사 저녁 가족동반식사율: 사용자 결정으로 제외

## 주의
- 2-3의 혼밥 정의·비율은 논문 기준이며 생활시간조사·KREI와 측정이 달라 서로 비교·합산 금지. 오즈비는 "몇 배 더 먹는다"가 아님(인용은 비율로).
- 2-3·2-4는 횡단 연구로 인과가 아니라 연관성이며, 2020년 코로나 영향 가능성, 대구 구분 없음.
- 문장에서 "혼밥이 늘고 있다"는 전 국민 기준으로 한정(3-1). 대구 1인가구 혼밥 증가는 단정 금지.
- 1인가구 비율은 가구 기준(국가데이터처 36.1%/36.6%)과 주민등록 세대 기준(약 44만)을 섞지 않음.
