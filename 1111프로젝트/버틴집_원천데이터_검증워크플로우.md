**D6. 카카오 로컬 API** — 키 발급 필요 (9-3, R9)
- 쓰는 곳
  - 좌표 없는 3,990건의 주소 → 좌표 변환
  - 변환한 좌표가 맞는지 표본 대조

- 확인할 것: 하루 호출 한도, 결과 저장·재사용이 약관상 허용되는지 (외부 공개 전 필수, 6-5)

**D7. 메뉴 정보** — 없음 (6-1, R1, 12-2)
- 업종 기준 생존배수(같은 메인 메뉴끼리 비교)의 전제 조건

**D8. 영업시간** — 없음

- 지도 서비스 페이지를 긁어 오는 방식은 약관 위반 가능성이 있으므로 쓰지 않음 (**제안**)

**D9. 가맹 브랜드 목록** — **제안**

## 2. 전체 워크플로우

```
[원천 확보] → [수집] → [정제] → [좌표] → [분류] → [계산] → [결과 검증] → [산출] → [공개]
    ↑           G1        G2       G3       G4       G5          G6          G7
    └──────────────────── 월 1회 갱신 루프 (G8) ────────────────────────────────┘
```
G1~G8은 각 단계 끝의 **통과 조건(게이트)**입니다. 통과하지 못하면 표시된 단계로 돌아갑니다.

| 단계 | 하는 일 | 입력 | 출력 | 담당 |
|---|---|---|---|---|
| 0. 원천 확보 | D1~D10 다운로드·발급, 항목 설명서 확보 | — | `raw/` 원본 (읽기 전용) | 이재훈 · 손효민 |
| 1. 수집 | 원본 읽기, 행 수·열 구조·기준일 기록 | raw | 수집 기록표 | 이재훈 |
| 2. 정제 | 결측 제외, 중복 정리, 날짜 형식 통일, 30일 하한 표시 | raw | `processed/정제.csv` | 이재훈 |
| 3. 좌표 | X·Y → WGS84 변환, 결측 좌표 주소로 보완 | 정제본 | `processed/좌표.csv` | 이재훈 |
| 4. 분류 | 업태 매핑, 메인 메뉴 추정, 프랜차이즈 표시, D2·D3 합치기 | 좌표본, D6·D9 | `processed/분류.csv` | 이재훈 |
| 5. 계산 | 영업연수, KNN(k=10), 중앙값 분모, ε 평탄화, 생존배수, 상위 % | 분류본 | `output/결과.csv` | 이재훈 · 이건협 |
| 6. 결과 검증 | 백년가게 비교, 민감도, 표본 직접 확인 | 결과, D5 | 검증 보고서 | 손효민 · 이찬영 |
| 7. 산출 | 화면용 JSON 생성, 배지 대상 표시 | 결과 | `output/stores.json` | 이건협 |
| 8. 공개 | 웹페이지 반영, 문구·한계 표시 점검 | JSON | 배포 | 이건협 · 이찬영 |

원칙 (9-1, 14-1): 원본은 수정하지 않고, 단계마다 결과를 따로 저장하며, 실행할 때마다 기준일·행 수를 기록합니다.

## 3. 데이터 검증 루프

각 루프는 **점검 → 판정 → (실패 시) 되돌아가기 → 기록** 순서로 돕니다. 기준 값 중 기획서에 없는 것은 **제안**이며, 첫 실행 결과를 보고 팀이 확정합니다.

### 루프 A. 수집 검증 (G1) — 원본을 받을 때마다

| 점검 | 통과 기준 | 실패 시 |
|---|---|---|
| 행 수 | 지난번과 비교해 ±5% 이내 (**제안**) | 다시 내려받기, 제공처 공지 확인 |
| 열 구조 | 열 이름·개수가 지난번과 같음 (현재 14열) | 열 대응표 수정 후 재수집 |
| 인코딩 | UTF-8로 읽힘, 한글 깨짐 없음 | 인코딩 변환 |
| 기준일 | 파일의 가장 최신 날짜를 기록, 서비스 기준일과 차이 기록 | 기준일 결정 |
| 지역 | 구군 값이 대구 9개 구·군만 | 다른 지역 행 제외 |

|---|---|---|
| 필수 값 | 영업시작일 없는 행은 제외 목록에 따로 저장 (현재 14건) | — |

## 5. 기획서에서 확인이 필요한 부분

- **중도절단 방향**: 기획서 3-3은 영업 중 가게의 배수가 "높게" 나올 수 있다고 했고, 11/9 발표는 "낮게" 계산된다고 했습니다. 두 효과가 모두 있을 수 있으니(오래된 영업 가게는 높게, 갓 연 가게는 낮게) 표현을 하나로 맞춰야 합니다.
- **기준일**: 2026-10-26(데이터 최신일)과 2026-10-28(발표 기준일) 중 하나로 정해야 합니다 (3-7 8번). 원본이 2일 전 기준으로 갱신되므로 데이터 최신일(10-26)을 기준일로 쓰는 것을 제안합니다 (D4).

- **정할 값**: ε 값, 최소 표본 N, 비교 기간 제한(10년) 적용 여부, 루프마다 붙인 **제안** 기준 값
