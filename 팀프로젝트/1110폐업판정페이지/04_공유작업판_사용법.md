# 공유 작업판 사용법

주소: https://store-check-board.vercel.app

## 조원이 하는 일

1. 페이지를 열고 **이름**과 **팀 코드**로 로그인합니다. 팀 코드는 단톡방에서 확인하세요. 로그인하지 않아도 보기는 됩니다.
2. 위쪽 **구·군 칸**에서 맡은 구·군을 누릅니다. 칸마다 "판정한 수 / 전체"가 보입니다.
3. 가게마다 **카카오맵 / 네이버 지도**를 눌러 확인합니다. "근거 원문 보기"를 펼치면 인허가·상가정보·카카오 근거가 나옵니다.
4. **영업중 / 폐업 / 확인불가** 중 하나를 누릅니다. 같은 버튼을 다시 누르면 취소됩니다. 누가 언제 눌렀는지 남습니다.
5. 필터: 구·군, 사람 확인 이유, 상태(아직 안 한 것 / 판정한 것 / 내가 한 것), 상호 검색

## 판정 기준 (먼저 정하기)

조원마다 기준이 다르면 판정을 비교할 수 없습니다. 시작 전에 하나로 정하세요.
예: "최근 3개월 안에 리뷰가 있으면 영업중", "로드뷰에 다른 가게 간판이면 폐업", "지도에 '폐업' 표시가 있으면 폐업"

## 판정이 전체 파일에 반영되는 방식

- 조원이 누른 판정은 인터넷 저장소(Vercel Blob, 비공개)에 쌓입니다.
- 작업 폴더에서 `python 00_스크립트/sync.py`를 실행하면 판정을 가져와 반영합니다.
  - `04_조원확인/조원판정.csv`: 조원 판정 목록
  - `05_최종결과/최종판정_대구전체.csv`: 전체 가게의 최종판정 (조원 판정 우선, 없으면 자동 판정)
  - `03_아카이브/<구군>/<관리번호>.md`: 해당 가게 파일의 "조원 판정 · 최종 판정" 칸
- 판정을 취소하면 다음 sync 때 파일에서도 빠집니다.
- 페이지의 **판정 결과 CSV 받기**로 언제든 내려받을 수 있습니다.

## 보안

- 팀 코드를 아는 사람만 판정을 기록할 수 있습니다. 틀린 코드는 로그인 단계에서 막힙니다.
- 팀 코드는 Vercel 설정에만 있고, 코드나 문서에는 적지 않습니다.
