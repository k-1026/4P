# 대구 음식점 폐업 판정: 지금까지 진행 정리

> 작업 폴더: 내 PC `Desktop\팀프로젝트`

## 1. 무엇을 하는가

**목표:** 대구의 모든 음식점(일반음식점·휴게음식점·제과점)이 지금 **영업 중인지, 폐업했는지** 판정하는 것입니다. 사람이 직접 보는 일은 최대한 줄입니다.

**방법:** 판정은 4단계를 차례로 거칩니다. 앞 단계에서 확실히 정해진 가게는 다음 단계로 넘어가지 않습니다.

| 단계 | 하는 일 | 결과 |
|---|---|---|
| 1 인허가 | 행안부 인허가 자료에 폐업 신고가 있거나 최근 새로 생긴 가게 | 폐업 / 영업중 **(확정)** |
| 2 상가정보 | 소상공인 상가정보(11/05)에서 같은 건물에 같은 가게가 있는지 대조 | 영업중 (추정) |
| 3 카카오 | 카카오 지도 검색. 상호가 0.8 이상 비슷하고 100m 안에 있으면 영업중. 검색 결과가 없거나 상호가 0.5 미만으로 다르면 폐업 | 영업중 / 폐업 (추정) |
| 4 사람 확인 | 위 단계로 정하기 애매한 가게만 조원이 공유 작업판에서 확인 | 조원 판정 |
