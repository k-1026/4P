# 인허가 전체 다시 받기 · 검증 (완료)

## 결론

- 대구 일반음식점 인허가 **97,708곳**을 행안부 **대구 지역별 파일**(11/10 밤 기준)로 새로 받아 검증했습니다.
- 10/28 자료 97,575곳은 **하나도 빠짐없이** 들어 있고, 새로 생김 133곳 · 바뀐 곳 293곳입니다.
- 이 자료로 자동 판정 · 아카이브 · 최종판정을 다시 만들었고, 가게당 한 줄짜리 **기본 파일**을 만들었습니다 ([04_기본파일_열설명.md](./04_기본파일_열설명.md)).

## 어떻게 받았나 (처음 계획에서 바뀐 점)

| 시도 | 결과 |
|---|---|
| 1. API(15154916)로 구·군별 전체 받기 | 한 번에 100건까지만 줘서 느리고(1분에 85~370건), 서버가 자주 504(시간 초과)를 냄. 16시간 넘게 걸릴 예정이었음 |
| 2. 막히면 다음 구·군으로, 막힌 쪽은 10건씩 나눠 받기 | 조금 나아졌지만 여전히 느림. 오후 4시까지 약 44% (4만 3천여 건) |
| 3. **전국 파일**(15045016 → localdata 파일 다운로드, 669MB) | 30초 만에 받음. 11/10 밤 기준으로 API(2일 전 기준)보다 최신 |
| 4. **대구 지역별 파일** (같은 화면, 대구광역시 · 전체) | **2초, 28.5MB**. 전국 파일에서 뽑은 대구와 **한 칸도 다르지 않음** → 앞으로 이 방법을 기본으로 |

API로 먼저 받은 4만여 곳(중구·동구·서구 전체, 남구·북구 일부)은 **모두 파일에 있었고**, 상태가 다른 6곳은 파일 쪽이 더 최신이었습니다.
