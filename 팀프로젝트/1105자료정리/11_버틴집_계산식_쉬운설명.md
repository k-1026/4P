# 버틴집 계산식과 쉬운 설명

> 2026-11-05 기준 합의 내용입니다. 값은 분포와 보정 결과를 보고 바꿀 수 있습니다.
> 아래 예시 숫자는 설명용 가상 숫자입니다.

## 한눈에 보는 흐름

```
명단 정리 → 영업 기간 계산 → 생존배수 계산 → 구별 위쪽 10% 표시 → 근거 3개 추가
```

버틴집 계산은 **"이 가게가 비슷한 가게들보다 얼마나 오래 버텼나?"** 를 숫자로 보는 것입니다.

## 1단계. 명단 정리

계산을 망치는 기록을 먼저 뺍니다.

| 빼는 것 | 이유 | 반영 |
|---|---|---|
| 30일 이내 폐업 | 축제 부스 같은 임시 신고가 많음 | 반영 |
| 주소에 `일원`, `축제`, `행사`, `페스타`, `박람회` | 행사용 신고 | 반영 |
| 대구 밖 본사의 프랜차이즈 | 본사 지원으로 버틸 수 있음 | **미반영** |

대구 자체 프랜차이즈는 지점까지 모두 판정합니다. 업태 `기타`는 지도에 표시하되 생존배수와 단계를 계산하지 않습니다.

## 2단계. 영업 기간

```
영업 기간 = 기준일 − 시작일
시작일 = 인허가일. 대표자·상호 변경이 확인되면 마지막 변경일 (미반영)
```

## 3단계. 생존배수 (순위 기준)

```
기준 평균 = 평균(폐업일 − 인허가일)
  대상: 같은 구·업태에서 최근 10년 안에 폐업한 가게

생존배수 = 영업 기간 ÷ 기준 평균
```

- 비교할 폐업 가게가 30곳 미만이면 대구 전체의 같은 업태를 기준으로 합니다.
- **예시:** 수성구 한식당들이 평균 8년 만에 문을 닫았고 내 가게가 24년째라면, 24 ÷ 8 = **3배**입니다.

## 4단계. 1단계 판정 (오래 버틴 집)

```
구별 기준배수 = 같은 구 가게의 생존배수 상위 10% 지점
생존배수 ≥ 구별 기준배수 → 오래 버틴 집
```

**기준배수는 미리 정한 숫자가 아니라 시험 합격선과 같습니다.** 가게들을 줄 세워 위에서 10%째 가게의 값을 찾습니다.

가게가 10곳뿐이라고 하면, 상위 10%는 1곳이고 1등의 값이 합격선입니다.

| 순위 | 생존배수 | 합격선 2.9배 기준 |
|---|---|---|
| 1 | 2.9배 | 통과 |
| 2 | 2.1배 | 탈락 |
| 3 | 1.8배 | 탈락 |
| … | … | … |

탈락해도 지도에서 사라지지 않고, 표시만 붙지 않습니다. 구마다 기록 상태가 달라 구끼리는 비교하지 않습니다.

## 5단계. 카드의 근거 (순위에는 쓰지 않음)

| 지표 | 쉬운 뜻 | 식 |
|---|---|---|
| 동년배 생존율 | 같은 시기에 시작한 가게 중 몇 %가 남았나 | 같은 구·업태·개업 5년 구간의 영업 중 수 ÷ 그 구간 전체 수 × 100 |
| 업태 폐업률 | 이 업종이 요즘 얼마나 힘든가 | 같은 구·업태 최근 12개월 폐업 수 ÷ (영업 중 수 + 최근 12개월 폐업 수) × 100 |
| 30년 표시 | 절대적으로도 오래됐나 | 영업 기간 30년 이상이면 "인허가 기준 30년 이상" |

동년배 생존율은 구간 가게가 30곳 미만이면 대구 전체의 같은 업태·구간을 쓰고, 2000년 이후 개업 가게만 표시합니다. 그 이전은 폐업 기록이 빠져 있어 값이 부풀려집니다.

## 전체 예시

수성구 한식 가게, 2000년 개업, 영업 기간 24년으로 가정합니다.

| 항목 | 계산 | 결과 |
|---|---|---|
| 기준 평균 | 수성구 한식 최근 10년 폐업 가게 평균 | 8년 |
| 생존배수 | 24 ÷ 8 | 3.0배 |
| 수성구 합격선 | 수성구 상위 10% 지점 | 2.9배 |
| 1단계 | 3.0 ≥ 2.9 | 통과 |
| 동년배 생존율 | 영업 중 40곳 ÷ 전체 200곳 × 100 | 20% |
| 업태 폐업률 | 폐업 90곳 ÷ 1,000곳 × 100 | 9% |
| 30년 표시 | 24 < 30 | 표시 안 함 |

**카드 문구 예시**

> 문 닫은 수성구 한식당 평균보다 **3배** 오래 영업 중
> 함께 개업한 가게 중 **20%만** 남았습니다

## 식의 출처

| 항목 | 출처 |
|---|---|
| 기준 평균의 계산 | 서울시 평균영업기간과 같은 방식. 단위는 구·업태로 다름 |
| 동년배 생존율 | 공공 n년 생존율을 응용 |
| 업태 폐업률 | 서울시 폐업률을 응용. 행사용 신고 제외 |
| 30년 기준 | 백년가게 업력 요건을 참고 |
| 생존배수, 구별 상위 10% | **우리가 만든 기준** |

## 해석 주의

- 이 숫자들은 **오래 버텼다**는 것만 보여 줍니다. 맛이 좋다는 증명이 아닙니다.
- 구별 상위 10%는 어느 구든 약 10%가 뽑히는 상대 기준입니다.
- 분모가 폐업 가게 평균이라 절반 넘는 가게가 1배를 넘습니다. "평균보다 오래 버틴 가게"가 드물다는 뜻이 아닙니다.
- 카드 문구는 "수성구 한식 평균"이 아니라 "**문 닫은** 수성구 한식당 평균"이어야 정확합니다.
