## 3단계. 묶기

예시로 주신 4개 묶음에 "기본이 안 돼 있었다"를 하나 추가했어요. 원래 묶음에 넣으면 성격이 달라서요. 한 사례가 여러 묶음에 들어갈 수 있어요.

### A. 리뷰나 평가가 가짜 같았다 (9곳)

| 세부 유형 | 사례 |
|---|---|
| 평점이 너무 높아서 의심 | 구테이블: 4.9점인데 "왜 이렇게 높은지 모르겠다" |
| 리뷰를 쓰면 혜택을 줌 | 죠죠: 영수증 리뷰 쓰면 음료 서비스. 갈치야: 리뷰 이벤트로 커피 |
| 블루리본 표기가 과장됨 | 호호식당, 글로리칼국수: 알고 보니 본점이 받은 것 |
| 추천인을 의심하게 됨 | 갈치야: 펜션 사장님과 협력 관계인지 의심. 도희네: 호객행위 |

|---|---|
| 남기고 나옴 | 덕자네, 섭죽마을, 신 해바라기, 전라도 맛집 |
| 그 자리에서 대처하거나 항의함 | 죠죠(항의 후 포기), 아카리라멘(재조리 거절), 구테이블(컵 교체), 청춘조개(직접 주방으로 감), 도희네(메뉴 추가) |
| 내 탓을 함 | 한꼬막두꼬막("주문을 잘못했나", "내 마음이 문제") |
| 다른 집과 비교하며 대안을 제시 | 안덕(자하손만두), 윤밀원(장충동 원조집), 손선장(다른 노량진 가게) |
| 교훈과 경고를 남김 | 거동탕수육("지인 말을 더 믿자"), 도희네("다른 데 가세요") |

**핵심: 실망이 가장 커지는 순간은 6단계 첫입이에요. 다만 그 크기는 1~3단계에서 쌓인 기대가 결정해요. 방송, 높은 평점, 긴 웨이팅이 겹칠수록 첫입의 실망이 커졌어요.**

## 5단계. 사람에 붙이기 (페르소나)

따로 정해 둔 페르소나는 받지 못해서, 사례에서 반복되는 습관으로 4가지 유형을 만들었어요. 가지고 계신 페르소나가 있으면 아래 습관을 붙이시면 돼요.

### 페르소나 1. "방송 보고 떠나는 여행자"

방송이나 릴스에 나온 집을 여행 일정에 넣고, 실패하면 "다음엔 지인 말을 믿자"는 교훈을 남기는 사람

| 항목 | 내용 |
|---|---|
| 해당 사례 | 섭죽마을, 거동탕수육, 갈치야, 신 해바라기, 도미, 이치니산도, 초록고등어 |
| 상황 | 연인, 부부, 혼자 여행. 여행의 첫 끼나 마지막 끼 |
| 믿는 정보 | 방송, 또간집, 릴스, 숙소 사장님 추천 |
| 실망하면 | 남기고 나오고, 후기에 교훈을 적음 |
| 나만의 방법 | 여행 첫 일정으로 일찍 웨이팅 등록 |
| 특징 | 한 번뿐인 여행이라 실패가 더 아프게 느껴짐 |

### 페르소나 2. "평점과 리뷰 수를 믿는 검색형"

네이버 평점과 리뷰 수를 보고 고르고, 실패하면 "평점이 왜 이렇게 높지?" 하며 별점을 항목별로 쪼개 리뷰하는 사람

| 항목 | 내용 |
|---|---|
| 해당 사례 | 구테이블, 한꼬막두꼬막, 청춘조개, 전남상회, 도희네, 성수완당, 아르포, 아카리라멘 |
| 상황 | 2~4인 식사, 나들이 |
| 믿는 정보 | 네이버 평점, 리뷰 수, 리뷰에 많이 나온 메뉴 |
| 실망하면 | 그 자리에서 요청하거나 항의하고, 맛·가격·위생을 항목별로 평가한 리뷰를 씀 |
| 나만의 방법 | 리뷰에 가장 많이 나온 메뉴 시키기, 평점이 낮아도 직접 판단하기 |
| 특징 | 리뷰 이벤트, 블루리본 표기 같은 신뢰 문제에 가장 민감함 |

### 페르소나 3. "웨이팅도 감수하는 줄서기형"

미슐랭이나 유명 웨이팅 맛집을 캐치테이블로 노리고, 실패하면 "한 번이면 충분"이라며 다른 집과 비교하는 사람

| 항목 | 내용 |
|---|---|
| 해당 사례 | 개성만두궁, 안덕, 매향, 일산칼국수, 죠죠, 요아케, 가메골, 대림국수, 글로리칼국수 |
| 상황 | 주말이나 점심, 나들이 겸 방문 |
| 믿는 정보 | 미슐랭, 블루리본, 줄 길이 |
| 실망하면 | 조용히 다시 안 가고, 비슷한 다른 맛집과 비교하는 글을 씀 |
| 나만의 방법 | 캐치테이블로 대기 확인, 평일 오전이나 오픈런, 원격 웨이팅 |
| 특징 | 기다린 시간이 그대로 기대치가 되어서, 무난한 맛도 실망으로 느낌 |

### 페르소나 4. "지인 추천과 모임 대표형"

지인의 극찬을 믿고 가거나 모임 장소를 직접 고르고, 실패하면 "내가 잘못 골랐나" 하고 미안해하는 사람

| 항목 | 내용 |
|---|---|
| 해당 사례 | 윤밀원, 올라아보, 한꼬막두꼬막, 덕자네 |
| 상황 | 직장 동료 8명, 다이빙 모임 4인, 가족, 자매 모임 |
| 믿는 정보 | 지인이 "인생 맛집"이라고 한 곳, 검색 상위 |
| 실망하면 | 자책하거나 먹는 방법을 바꿔봄 (감자샐러드를 비벼 짠맛 줄이기) |
| 나만의 방법 | 인원이 많으면 예약을 나눠서 하고 오픈런 |
| 특징 | 내 입맛보다 일행의 만족이 더 중요함 |
