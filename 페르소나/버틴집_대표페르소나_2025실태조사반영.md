## 1. 한 줄

**정하준 (가상), 33세, 경북 구미에 사는 회사원. 주말에 아내와 차로 대구에 당일 나들이를 온다. 밥집을 고를 때 네이버 · 카카오 리뷰를 꼼꼼히 보지만, 리뷰 이벤트와 광고 때문에 더는 리뷰를 믿지 않는다.**

> "별점 5점인데 리뷰마다 '서비스 받고 씀'이야. 뭘 믿고 골라?"

## 3. 페인포인트

### 1순위: 리뷰를 믿을 수 없다 (핵심)

| 무엇이 문제인가 | 근거 (2022년 이후) |
|---|---|
| **리뷰 이벤트가 별점을 부풀림** | 리뷰 작성자의 65.2%가 이벤트 때문에 씀, 이벤트 참여자의 79.6%가 별점에 영향, 그중 98.3%가 실제보다 높게 줌 (한국소비자원 2024, 배달앱) · 고기가 나오기도 전에 "별 5개 + 사진이면 계란찜 공짜" 안내 (브런치 2024-04) · 일행 모두 리뷰를 쓰게 하려고 영수증을 여러 장으로 나눠 발급 (경기일보 2026-04, 용인 25세) |
| **별점과 실제가 다름** | 별점 5점 가게에서 리뷰와 정반대인 양과 맛 → 지금은 "리뷰 이벤트를 하지 않는 곳의 리뷰를 찾아본다" (경기일보 2026-04, 수원 26세) · 배달앱 평점 4.8 식당 품질 민원, 서울시가 공정위에 공문 (2025-08) |
| **리뷰를 사고파는 시장** | 5년간 허위 후기 2만 8,886건, 약 19억 원, 의뢰업체 707곳에 음식점 포함 (머니투데이 2026-07) · 리뷰 1건에 최대 7,000원, 사업주끼리 리뷰를 주고받는 단체방 (머니투데이 2025-12) · 허위 후기 대행업자 벌금 (한국경제 2025-10) |
| **광고 표시를 지운 후기** | 광고대행사가 인플루언서에게 "협찬" 표시를 지우게 함, 음식 · 숙박 광고 2,337건 (공정위 2025-09) · SNS · 인플루언서 광고 관련 소비자 상담 2025년 3,642건 (소비자원, 2026-09 보도, 상품 전반) |
| **앱 사용자들의 불만** | 지도 · 맛집 앱 리뷰 129건 중 **71건(55%)**이 광고 또는 리뷰 조작 · 이벤트 불만, 그중 39건이 별점 1점 [직접 셈] · "한 아이디로 하루에 음식점 10개 넘게 평점 매기고 … 평점 자체를 믿을 수가 없네" (카카오맵, 2026-09) |

**참고:** 71건 중 일부는 앱 화면의 광고가 거슬린다는 불만입니다. 식당 리뷰만 본 숫자는 "리뷰 조작 · 이벤트 불신" 39건(30%)입니다 [직접 셈].

### 2순위 (보조): 문 닫은 집에 헛걸음

- 앱 리뷰 불만 중 가장 많은 단일 주제 43건, 공감 349 [직접 셈]. 품절 · 휴무 헛걸음 (한국경제 2025-11)
- 리뷰 문제와 함께 생김: 리뷰 많은 집을 골랐는데 이미 문을 닫았음 [해석]

### 3순위 (보조): 줄 서고 실망

- SNS 유명 집 웨이팅 최대 180분 (한국경제 2025-11), "2시간 기다릴 정도는 아님" (루리웹 2025)
- 리뷰 · SNS를 믿고 줄을 섰다가 실망하는 흐름이라 1순위와 이어짐

## 5. 원하는 것과 버틴집이 줄 것

| 원하는 것 | 버틴집이 줄 것 | 확인 상태 |
|---|---|---|
| 돈이나 이벤트로 바꿀 수 없는 기준 | **인허가 기록**(개업일 · 폐업일)은 리뷰 이벤트로 바뀌지 않음 → 업력 · 생존배수 | 기준이 필요하다는 것은 근거 있음 (소비자원 2024: 63%가 별점 리뷰 개선 필요, 대안으로 재주문율 같은 **행동 기반 지표**를 꼽음) |
| | **"업력"이 그 기준이 된다는 것** | **[가정] 직접 근거 없음 → 인터뷰 핵심** |
| 헛걸음하지 않기 | 매일 갱신하는 영업/폐업 판정 | 근거 있음. 단, 휴무 · 영업시간은 없음 |
| 아내와의 한 끼를 실패하지 않기 | 같은 메뉴 주변 가게와 비교 | [가정] |

**주의할 점:** 업력도 완벽한 기준은 아님. 가게를 넘겨받으면 인허가일이 그대로라 업력이 길게 잡힘 (서비스 대상 중 주인 바뀜 의심 3,511곳, 우리 데이터 2026-11-12). 발표에서 "광고는 못 바꾸지만, 주인 바뀜은 표시한다"로 설명

## 9. 한계

- 리뷰 문제의 사례는 대구 밖(수원 · 용인 · 서울)이고, 대구 사례는 2022년 이후 0건 → 대구 후기를 모아야 함
- 소비자원 조사(65.2% 등)는 **배달앱** 대상이라 식당 방문과는 다름을 밝혀야 함
- 데이터랩 값(30대 방문 · 소비 비중, 경북 · 구미 거주지, 20대 소비, 외지인 방문 순위)은 화면 차트에서 읽은 값 → 발표 전 공식 다운로드로 최신 값 확인
- "어디로"의 두 근거는 재는 방식이 다름: 실태조사는 응답자 비율, 데이터랩은 방문자 수
- 앱 리뷰는 불만 쓰러 온 사람이 많은 표본 (별점 1점 47%) → "몇 %가 불만"이 아니라 "이런 불만이 있다"로만 씀
