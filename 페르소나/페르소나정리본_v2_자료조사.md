## 0. 먼저 알려 드릴 점 (100건을 채우지 못한 이유)

요청하신 100건 중 **기간 조건을 맞추고 원문까지 확인한 사례는 6건**입니다. 근거 자료 4건은 따로 정리했습니다. 이유는 다음과 같습니다.

| 문제 | 내용 |
|---|---|
| 네이버 블로그 접근 차단 | 네이버 검색과 블로그 페이지는 이 작업 환경에서 열 수 없었습니다 (사이트 차단). |
| 브라우저 연결 실패 | 크롬 확장 프로그램으로 네이버를 직접 검색하려 했지만 실행 오류가 났습니다. |
| 웹 검색 한계 | 검색 결과에 체험단 모집, 광고 대행 글이 대부분이었고, 실제 실망 후기는 적었습니다. 오래된 글(2017~2023)도 많았습니다. |
| 대구 사례 없음 | **대구 음식점에 실망한 후기는 기간 안에서 한 건도 확인하지 못했습니다.** |

**100건을 모으는 방법은 7번에 정리했습니다.** (네이버 검색 API 또는 브라우저 연결)

## 3. 불만 유형 정리 (확인한 사례 기준)

| 유형 | 내용 | 해당 사례 |
|---|---|---|

| ② 대가성 리뷰를 믿지 않음 | 리뷰 이벤트, 협찬 리뷰가 많아 내용 자체를 의심함 | C3, D2 |

| ④ 유명해진 뒤 품질 저하 | 손님이 몰리자 음식이 식고 맛이 떨어짐 | C2 |
| ⑤ 헛걸음 (품절, 휴무, 영업 정보) | 영업일과 품절 정보를 미리 알기 어려움 | C5, 참고 사례 |

**버틴집과의 연결**
- ①② → 기획서 2-1의 문제 1번(광고 리뷰를 믿기 어렵다)을 뒷받침합니다.
- ③④ → "최근 SNS로 뜬 가게"와 "오래 버틴 가게"를 구분할 필요가 있다는 문제 2번을 뒷받침합니다.
- ⑤ → 문제 3번(영업 정보가 흩어져 있다)과 연결됩니다.

## 7. 100건을 모으는 방법 (제안)

| 방법 | 내용 | 필요한 것 |
|---|---|---|
| 1. 네이버 검색 API (블로그) | 네이버 공식 API로 블로그 글을 키워드별로 모읍니다. 한 번에 100건, 키워드당 최대 1,100건. 날짜, 제목, 요약, 링크가 나옵니다. 모은 뒤 기간(2025.5~2026.11)과 "실망" 내용으로 거릅니다 | 네이버 개발자센터(developers.naver.com) 애플리케이션 등록 후 Client ID와 Secret (사용자가 발급) |
