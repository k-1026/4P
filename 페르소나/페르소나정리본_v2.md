## 1. 페르소나 A: "줄 서고 실망한" 외지인 여행자 (주 사용자)

| 항목 | 내용 | 근거 |
|---|---|---|
| 이름 | 정하준 (가상) | – |
| 나이·직업 | 20~30대 직장인 | C3 인터뷰 대상 25·26세 직장인 참고. 나이대는 **추정** |
| 맛집 찾는 방법 | 인스타·유튜브에서 유명인·인플루언서가 올린 가게, 검색 상단에 자주 보이는 가게, 별점 높은 가게 | C1, C5 |
| 실제 행동 | 오픈 전에 가서 줄 섬(오픈런), 2~3시간 웨이팅, 원격 줄서기 앱 사용 | C5 (최대 180분 이상), C6 |
| 겪은 일 | 2시간 기다린 음식이 평범한 맛이었음. 비싼 값(1인 12만 원)을 냈지만 재료와 서비스가 기대에 못 미침. 휴무일과 품절로 헛걸음함 | C1, C2, C5, C6, 참고 사례 |
| 실망의 이유 | 기다린 시간과 기대가 커서 실망도 커짐. "맛은 괜찮지만 2시간 기다릴 정도는 아님" | C2, C6 |
| 남긴 반응 | 별점을 낮게 줌. 재방문하지 않음 | C6, 참고 사례 |
| 깨달은 것 | "온라인에서 많이 언급된다고 내 입맛에 맞는 건 아니다" | C1 |
| 원하는 것 | 줄 서지 않고도 실패하지 않는 가게. 유명세가 아닌 다른 기준 | C1, C6에서 도출 (**추정** 포함) |
| 대구 방문 상황 | 주말 1박 2일 대구 여행 | **추정** (대구 사례 없음) |

**상황 시나리오** (사례를 합쳐 구성)
토요일 점심, 인스타에서 본 대구 동성로의 인기 식당에 갑니다. 대기 2시간. 기다려서 먹었지만 맛은 평범합니다(C2, C6). 저녁만큼은 실패하고 싶지 않아 버틴집을 엽니다. 숙소 근처에서 "주변 가게보다 오래 영업한 식당"을 찾아 줄 없이 들어갑니다.
→ 대구 지명과 버틴집 사용 장면은 **추정**입니다.

**이 사람에게 버틴집이 줄 것**
- 유명세·별점이 아닌 **영업 기간**이라는 다른 기준 (C1의 "검색 노출 ≠ 맛" 문제에 대응)
- 웨이팅 정보에 의존하지 않는 선택지 (C5, C6)
- 영업 중인지 확인 (C5의 휴무·헛걸음 문제, 기획서 문제 3번)

**상황 시나리오** (사례를 합쳐 구성)
가족 외식 장소를 찾다가 별점 5점짜리 가게를 봅니다. 그런데 리뷰에 "서비스 받고 씀"이 많습니다(C3). 지난번에 이런 가게에서 실망한 기억이 납니다. 버틴집 지도에서 동네의 오래 버틴 식당을 찾습니다. 리뷰가 아닌 영업 기간으로 고릅니다.
→ 버틴집 사용 장면은 **추정**입니다.

**이 사람에게 버틴집이 줄 것**
- 리뷰 이벤트와 협찬의 영향을 받지 않는 **인허가 데이터 기준** (C3, D2)
- 최근 뜬 가게와 오래 버틴 가게의 구분 (C2)
