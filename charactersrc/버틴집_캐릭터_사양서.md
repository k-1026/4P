# 버틴집 캐릭터 사양서: 장수 거북이 + 픽셀 검

> 이 문서는 사람과 AI 에이전트가 함께 읽는 구현 사양서입니다.
> 이미지 파일 없이 이 문서만으로 캐릭터를 똑같이 다시 그리고, 웹과 앱에서 움직이게 만들 수 있습니다.
> 4P · 버틴집 서비스 기획 (2026.11)

---

## 0. 에이전트에게 주는 지시

이 문서를 받은 에이전트는 아래 규칙을 지켜 구현합니다.

1. **픽셀 데이터를 그대로 씁니다.** 4장(픽셀 데이터)의 격자와 3장(색상표)의 색만 사용합니다. 칸을 새로 그리거나 색을 바꾸지 않습니다.
2. **흐리게 확대하지 않습니다.** 확대는 정수 배율(2배, 3배, 4배…)로만 합니다. 웹은 `image-rendering: pixelated`, 캔버스는 `imageSmoothingEnabled = false`를 씁니다.
3. **없는 동작은 만들지 않습니다.** 5장에 정의된 상태만 구현합니다. 새 동작이 필요하면 "추가 제작 필요"로 표시하고 멈춥니다.
4. **움직임 줄이기 설정을 따릅니다.** 사용자가 움직임 줄이기를 켜 두면 걷기·반짝임을 멈추고 기본 자세 한 장만 보여 줍니다.
5. **캐릭터 이름은 아직 정해지지 않았습니다.** 화면에 이름을 띄워야 하면 `{CHARACTER_NAME}` 자리표시자를 씁니다. (가칭: 버틴거북)

## 1. 캐릭터 개요

| 항목 | 내용 |
|---|---|
| 종류 | 거북이 (옆모습, 오른쪽을 봄) |
| 상징 | 장수. "오래 버틴 가게를 끈질기게 찾아낸다"는 버틴집의 메시지 |
| 성격 | 느리지만 포기하지 않습니다. 오래된 것을 알아봅니다 |
| 특징 | 흰 눈썹, 볼 홍조, 진초록 등껍질에 금색 육각 무늬, 금색 껍질 테두리 |

## 5. 상태와 동작

| 상태 | 언제 | 프레임 | 시간 |
|---|---|---|---|
| `idle` 기본 | 대기 화면, 빈 화면 | 프레임 1 한 장 | 고정 |
| `walk` 엉금엉금 | 검색 중, 불러오는 중 | 0 → 1 → 2 → 3 반복 | 프레임당 180ms |
| `crawl` 이동 | 화면을 가로질러 검까지 감 | `walk` 반복 + 위치 이동 | 110ms마다 1~2칸 (번갈아) 오른쪽으로 |
| `notice` 발견 | 검 앞에 도착 | 프레임 1 + 머리 위 '!' 말풍선 | 6프레임 × 140ms |
| `celebrate` 기쁨 | 결과 보여 줄 때 | 프레임 1 + 위로 폴짝 | 높이 0,2,3,2,0,0칸 순서 × 110ms, 2번 반복 |

### '!' 말풍선
- 흰 사각형(가로 9칸 × 세로 11칸)에 외곽선 `K`, 아래쪽에 작은 꼬리를 그립니다.
- 느낌표는 적갈색 `#A8452F`. 세로 4칸 막대 + 2칸 띄고 점 1칸입니다.
- 위치: 거북이 머리 위. 말풍선 꼬리 끝이 머리 윗변에서 2~3칸 위에 오게 합니다.

### 검 찾기 장면 (전체 약 13초)
1. `crawl`: 화면 왼쪽 밖에서 들어와 검 왼쪽 약 15칸 앞까지 기어 갑니다.
2. `notice`: 멈추고 말풍선을 띄웁니다.
3. `celebrate` + 검 빛남: 검 주위에 금빛 무리와 픽셀 별이 반짝입니다 (6장).

### 움직임 줄이기
`prefers-reduced-motion: reduce`(웹) 또는 기기 설정의 움직임 줄이기(앱)가 켜져 있으면 모든 상태를 `idle` 한 장으로 바꾸고, 검 빛은 정지된 밝기로만 보여 줍니다.

## 6. 검의 빛 = 생존배수

검 크기는 바꾸지 않습니다. 생존배수는 **색과 밝기, 반짝임**으로만 보여 줍니다.

| 생존배수 | 등급 이름 | 검 색 기준 | 효과 |
|---|---|---|---|
| 0.5배 미만 | 부러질 듯한 검 | `#60483E` | 없음 |
| 0.5~1배 | 녹슨 검 | `#846858` | 없음 |
| 1~2배 | 무딘 강철 검 | `#9EA0A6` | 1.5배부터 별 반짝임 시작 |
| 2~4배 | 은빛 검 | `#D6DEEC` | 별 반짝임 |
| 4~8배 | 황금빛 검 | `#FFD068` | 금빛 무리 + 별 반짝임 |
| 8배 이상 | 전설의 엑스칼리버 | `#FFF4C8` | 가장 큰 금빛 무리 + 별 최대 |

- **색 계산:** 생존배수 m을 log2(m)으로 바꾼 뒤 위 표의 색 사이를 직선으로 섞습니다. log2 기준점은 -2(0.25배), -1, 0, 1, 2, 3(8배)입니다. 표의 색을 검 칼날·가드에 곱해서 입힙니다.
- **별 개수:** `min(16, 2 + 세기 × 2.2)`. 세기 = `min(6, log2(m) × 1.6 + 0.4)`이고, m이 1.5보다 작으면 0입니다.
- **별 모양:** 5×5칸 + 모양, 작을 때는 3×3칸 + 모양. 색 `#FAC846`, 가운데 칸 `#ECAA28`.
- **금빛 무리:** 2칸 단위 계단 모양 원 3겹. 바깥부터 투명도 약 12%, 18%, 26%. 색 `#FFC850`. 반지름은 18칸에서 ±6칸으로 천천히 숨 쉬듯 움직입니다.

| 빈 화면·안내 화면 | 5~6배 | 200 × 95px ~ |
| 첫 화면·발표 화면 | 8~12배 | 320 × 152px ~ |

- 배율은 정수만 씁니다. 고해상도 화면에서는 기기 픽셀 비율까지 곱해서 정수로 맞춥니다.
- 거북이 둘레에 최소 2칸(배율 적용 후) 여백을 둡니다.
- 거북이는 항상 오른쪽을 봅니다. 왼쪽으로 가야 하면 좌우 반전을 쓰되, 반전한 채로 글자와 겹치지 않게 합니다.

## 8. 구현 예시

### 8-1. 웹: 캔버스로 직접 그리기 (권장)

```html
<canvas id="turtle" aria-label="버틴집 거북이" role="img"></canvas>
<script>
async function drawTurtle(canvas, data, scale = 6) {
  const ctx = canvas.getContext('2d');
  canvas.width = data.width * scale;
  canvas.height = data.height * scale;
  ctx.imageSmoothingEnabled = false;
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  const frames = data.frames.walk;
  let i = 1;
  function paint(rows) {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    rows.forEach((row, y) => [...row].forEach((ch, x) => {
      if (ch === data.transparent) return;
      ctx.fillStyle = data.palette[ch];
      ctx.fillRect(x * scale, y * scale, scale, scale);
    }));
  }
  paint(frames[i]);
  if (reduce) return;
  setInterval(() => { i = (i + 1) % frames.length; paint(frames[i]); }, 180);
}
fetch('turtle.json').then(r => r.json()).then(d => drawTurtle(document.getElementById('turtle'), d));
</script>
```

### 8-2. 웹: 스프라이트 시트 + CSS

시트 파일 `거북이_스프라이트시트.png`는 프레임 4장을 가로로 붙인 12배 이미지이고, `turtle-sheet-1x.png`는 같은 시트의 1배(160 × 26px) 원본입니다. 12배 시트는 한 장이 480 × 312px입니다(위아래 여백 포함). 아래 CSS는 1배 시트 기준입니다.

```css
.turtle {
  width: calc(40px * var(--s, 4));
  height: calc(26px * var(--s, 4));
  background: url(turtle-sheet-1x.png) 0 0 / calc(160px * var(--s, 4)) 100% no-repeat;
  image-rendering: pixelated;
  animation: turtle-walk .72s steps(4) infinite;
}
@keyframes turtle-walk { to { background-position-x: calc(-160px * var(--s, 4)); } }
@media (prefers-reduced-motion: reduce) {
  .turtle { animation: none; background-position-x: calc(-40px * var(--s, 4)); }
}
```

### 8-3. React

```jsx
import { useEffect, useRef } from 'react';
import data from './turtle.json';

export function Turtle({ scale = 4, state = 'walk' }) {
  const ref = useRef(null);
  useEffect(() => {
    const c = ref.current, ctx = c.getContext('2d');
    c.width = data.width * scale; c.height = data.height * scale;
    ctx.imageSmoothingEnabled = false;
    const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
    let i = 1, id;
    const paint = rows => {
      ctx.clearRect(0, 0, c.width, c.height);
      rows.forEach((row, y) => [...row].forEach((ch, x) => {
        if (ch !== '.') { ctx.fillStyle = data.palette[ch]; ctx.fillRect(x*scale, y*scale, scale, scale); }
      }));
    };
    paint(data.frames.walk[i]);
    if (state === 'walk' && !reduce) id = setInterval(() => paint(data.frames.walk[i = (i + 1) % 4]), 180);
    return () => clearInterval(id);
  }, [scale, state]);
  return <canvas ref={ref} role="img" aria-label="버틴집 거북이" style={{ imageRendering: 'pixelated' }} />;
}
```

### 8-4. 모바일 앱

- **React Native:** `react-native-svg`로 칸마다 `Rect`를 그리거나, 1배 시트 PNG를 정수 배율로 키워 씁니다. 안드로이드는 `Image`의 `resizeMethod="scale"`과 정수 배율 크기를 함께 써야 흐려지지 않습니다.
- **Flutter:** `CustomPainter`에서 칸마다 `drawRect`, 이미지라면 `filterQuality: FilterQuality.none`.
- **iOS(SwiftUI):** `Image(...).interpolation(.none).resizable()`.
- **Android(Compose):** `Image(..., filterQuality = FilterQuality.None)`.
- 움직임 줄이기: iOS `UIAccessibility.isReduceMotionEnabled`, 안드로이드 `Settings.Global.ANIMATOR_DURATION_SCALE == 0`.

## 9. 접근성과 문구

- 대체 텍스트: "버틴집 거북이" (장식용으로만 쓰면 `aria-hidden="true"`).
- 상태 문구 예시 (화면 읽기 도구용, 화면에도 함께 표시):
  - `walk`: "오래 버틴 가게를 찾고 있습니다"
  - `notice`: "가게를 찾았습니다"
  - `celebrate`: "생존배수 {N}배 · {등급 이름}"
- 색만으로 생존배수를 전달하지 않습니다. 등급 이름과 숫자를 함께 보여 줍니다.

## 10. 하지 말 것

- 흐린 확대(부드럽게 보간), 소수 배율.
- 색상표에 없는 색, 그라데이션.
- 검 크기로 생존배수를 표현하는 것 (색·밝기·반짝임만 씀).
- 4장에 없는 표정이나 동작을 임의로 그려 넣는 것.
- 거북이를 기울이거나 회전하는 것 (픽셀이 깨짐).
