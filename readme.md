# 버틴집 — 대구 업력 맛집 지도

> 공공 인허가 데이터로 '오래 살아남은 가게'를 찾아, 대구 주민이 검증한 맛집 지도를 만듭니다.

| 항목 | 내용 |
| --- | --- |
| 대상 지역 | 대구광역시 (검증 후 전국 확장) |
| 핵심 가설 | 동종 업종 평균보다 오래 영업한 가게는 수요가 검증된 가게다 |
| 구현 도구 | 클로드코드 (파이썬 분석 + 웹 지도) |

---

## 1. 핵심 메시지

### "동네가 먹여 살린 가게"
**리뷰는 조작할 수 있지만, 20년 영업은 조작할 수 없다.**

- 광고·협찬·체험단 리뷰 대신, 조작이 어려운 **공공 신고 자료(개업일·폐업일)** 를 1차 근거로 삼습니다.
- "맛집"이 아니라 **"검증된 동네 가게"** 로 말합니다. 오래 버텼다는 사실 자체가 동네 주민이 고른 증거입니다.
- 모든 가게에 **"왜 이 가게냐"** 에 답하는 한 줄 근거를 붙입니다.
  - 예: *"수성구 한식 평균보다 2.4배 오래 영업"*

---

## 2. 팀 자산 Top 3

### ① 조작 불가능한 1차 근거 — 인허가 데이터 기반 '생존배수'
- 지방행정 인허가 데이터(일반·휴게음식점)의 개업일·폐업일·영업상태·좌표를 활용합니다.
- 같은 구·같은 업태의 폐업 점포 평균 영업 기간과 비교해 **생존배수**를 산출합니다.
  - `생존배수 = 해당 점포 영업 기간 ÷ 같은 구·업태 폐업 점포의 평균 영업 기간`
  - 생존배수 2 이상 = "동종 가게 평균의 두 배 이상 버틴 집"
- 업종·지역 차이를 걸러낸 공정한 비교라는 점이 다른 맛집 서비스와의 결정적 차이입니다.

### ② 여러 공공데이터를 엮은 단계형 판정 체계
- 착한가격업소, 온누리상품권 가맹점, 대구로페이 가맹·결제 정보, 한국관광공사 외지인 소비 비중을 결합합니다.
- 점수를 합산해 하나의 숫자로 뭉개지 않고, **조건을 하나씩 통과하는 단계**로 판정합니다.

| 단계 | 조건 | 이름 |
| --- | --- | --- |
| 1단계 (필수) | 생존배수 상위 | 오래 버틴 집 |
| 2단계 | 1단계 + 동네 수요 상권 안 | 동네가 고른 집 |
| 3단계 (최상위) | 2단계 + 착한가격업소 또는 전통시장 | **동네가 먹여 살린 집** |

### ③ 실시간 '오늘 영업 확률' + 클로드코드 풀스택 구현
- 폐업 신고 → 영업 확률 0(확정), 인스타그램 최근 게시물의 '휴무·재료 소진·임시 휴업' 문구를 **Claude API로 분류**하고, 과거 공지에서 정기 휴무 요일을 추출합니다.
- 공공 대용량 데이터의 **정제 → 결합 → 점수화 → 웹 지도 서비스화** 전 과정을 클로드코드로 시연합니다.

| 항목 | 내용 |
| --- | --- |
| 이름 / 나이 | 김민지 / 32세 |
| 거주·직장 | 대구 수성구 거주, 동구 직장 |
| 상황 | 주말마다 가족·친구와 갈 동네 밥집을 찾음 |
| 불편 ① 신뢰 | 지도 앱 상위 리뷰가 광고·체험단 글인지 구분할 수 없음 |
| 불편 ② 신선도 | 지도에 남아 있던 가게를 찾아갔더니 이미 폐업 |
| 불편 ③ 영업 확인 | 임시 휴무·재료 소진 공지가 인스타그램에 흩어져 있어 매번 일일이 확인 |
| 원하는 것 | "광고 말고, 동네 사람들이 오래 다닌 집"을 근거와 함께 빠르게 찾기 |

## 4. 스토리보드 & 행동유도(CTA)

| # | 장면 | 사용자 행동 / 화면 | 행동유도 (CTA) |
| --- | --- | --- | --- |
| 1 | **문제 인식** | 민지가 지도 앱에서 맛집을 검색하지만 광고 리뷰만 가득하고, 찾아간 가게는 폐업 상태 | — |
| 2 | **첫 만남** | "리뷰는 조작할 수 있지만, 20년 영업은 조작할 수 없다" 메시지와 함께 버틴집 메인 지도 진입 | **[내 동네 버틴집 보기]** |
| 3 | **탐색** | 구·업종 필터로 '수성구·한식' 선택. 단계별 마커 중 3단계 '동네가 먹여 살린 집'이 강조되어 보임 | **[동네가 먹여 살린 집만 보기]** |
| 4 | **근거 확인** | 점포 카드에서 "수성구 한식 평균보다 2.4배 오래 영업", 개업 연도, 상권 배지('주민 소비 상권', '전통시장') 확인 | **[왜 이 가게인가요?]** (근거 펼치기) |
| 5 | **가성비 선택** | '싸고 오래 버틴 집' 배지와 대표 메뉴·가격을 보고 후보 압축 | **[싸고 오래 버틴 집 필터]** |
| 6 | **방문 결정** | '오늘 영업' 확률(높음·보통·확인 필요)과 최근 휴무 공지 확인 → 헛걸음 걱정 해소 | **[길찾기]** / **[오늘 영업 확인]** |
| 7 | **재방문·확산** | 방문 후 만족. '사라진 가게' 아카이브에서 최근 폐업한 노포를 보며 동네 가게의 가치를 체감 | **[공유하기]** / **[사라진 가게 보기]** |

### 행동유도 설계 원칙
- **근거 먼저, 행동은 그다음**: 모든 CTA 직전에 한 줄 근거(생존배수·상권·영업 확률)를 보여줘 클릭 이유를 만듭니다.
- **헛걸음 제로**: 최종 CTA(길찾기) 바로 옆에 오늘 영업 확률을 배치합니다. 정보가 없는 가게는 '확인 필요'로 정직하게 표시합니다.
- **가격으로 순위를 올리지 않기**: 가성비는 종합 판정이 아닌 필터·배지 CTA로만 제공합니다.
- **단순한 화면**: 지도 하나 + 점포 카드 하나로 클릭 단계를 최소화합니다.
