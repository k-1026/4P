## 업종별로 다른 점

세 업종 모두 같은 단계(인허가 → 상가정보 → 카카오 → 조원 확인)로 판정했습니다 (휴게·제과는 11/12).

| 업종 | 가게 | 다른 점 |
|---|---:|---|
| 일반음식점 | 97,708 | 10/28 자료가 있어 '주의'(지위승계 의심) 표시, 상호·주소 바뀐 가게 다시 대조가 있음 |
| 휴게음식점 (카페·분식·편의점 등) | 31,262 | 상가정보 대조는 11/10 상호 기준. **편의점**은 카카오 검색 때 브랜드 표기로 바꿔 찾음 (씨유→CU, 지에스25→GS25, 코리아세븐→세븐일레븐). **푸드트럭 · 고속도로 휴게소 · 백화점 안 매장**은 위치 검색이 안 맞아 사람 확인으로 보냄 |

휴게음식점 업태에는 커피숍 · 기타 휴게음식점 · 일반조리판매 · 다방 · **편의점** · 패스트푸드 · 과자점 · 백화점 등이 섞여 있습니다. 지도에 쓸 때는 업태로 걸러야 합니다.

## 값의 종류

| 표시 | 뜻 |
|---|---|
| **원본** | 행안부 로우데이터 값 그대로 |

## 열 (29개)

| 열 | 종류 | 뜻 |
|---|---|---|
| 관리번호 | 원본 | 가게 고유 번호. 앞 7자리 = 구·군 코드, 그다음 3자리 = 업종 (101 일반음식점 · 104 휴게음식점 · 121 제과점). 업종 사이에 겹치지 않음 |
| 업종 | 계산 | 일반음식점 / 휴게음식점 / 제과점영업 (어느 원본 파일에서 왔는지) |
| 상호 | 원본 | 사업장명 |
| 업태 | 원본 | 위생업태명 (일반음식점: 한식 · 호프/통닭 등, 휴게음식점: 커피숍 · 편의점 등) |
| 구군 | 계산 | 관리번호 앞 7자리 → 구·군 이름 |
| 법정동 | 계산 | 지번주소에서 뽑은 동 이름 |
| 동성로일대 | 계산 | 중구 동성로 주변 23개 법정동이면 `Y` |
| 도로명주소 · 지번주소 | 원본 | |
| 위도 · 경도 | 계산 | 원본 좌표(EPSG:5174)를 WGS84로 바꾼 값. 좌표 없는 가게는 빈 칸 (일반 4,048 · 휴게 788 · 제과 109) |
| 면적 | 원본 | 소재지면적 (㎡) |
| 인허가일자 | 원본 | 영업 시작일. **주인이 바뀌어도(지위승계) 그대로 유지됨** |
| 인허가상태 | 원본 | `영업/정상` 또는 `폐업` |
| 폐업일자 | 원본 | 폐업 신고한 날 (영업 중이면 빈 칸) |
| 영업연수 | 계산 | (폐업일자, 영업 중이면 2026-11-10) − 인허가일자, 년 단위 |
| 주의 | 계산 | 일반음식점만: `지위승계로 상호·업종이 바뀌었을 수 있음` (10/28 분석 때 표시, 공식 항목 아님) |
| 상가정보_대조 | 판정 | 소상공인 상가정보(11/05) 같은 건물 대조 결과 (영업 가게만. 일반음식점은 10/28 상호, 휴게·제과는 11/10 상호로 대조) |
| 상가정보_다시대조 | 판정 | 일반음식점만: 10/28 뒤 상호·주소가 바뀐 89곳의 다시 대조 결과 |
| 판정단계 | 판정 | `1 인허가 폐업` · `1 인허가 신규` · `2 상가정보 일치` · `3 카카오 자동` · `4 사람 확인` |
| 자동판정 | 판정 | 영업중 / 폐업 / 검토(사람 확인) |
| 확정여부 | 판정 | `확정` = 공식 인허가 기록 · `추정` = 상가정보·카카오로 짐작한 것 |
| 판정근거 | 판정 | 판정 이유 |
| 사람확인_이유 | 판정 | 4단계로 간 이유 |
| 조원판정 · 판정시각 | 판정 | 공유 작업판에서 조원이 누른 판정과 시각 |
