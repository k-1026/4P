# 온누리상품권 가맹점으로 전통시장·골목상권 가게 표시

> 대화 날짜: 2026-10-28 (오후 5시 30분경)
> 표기: **[사용자]** = 사용자가 직접 말한 의견·조건, **[AI 제안]** = AI(Aside)가 제안한 내용

## 배경과 목적

- 대구 맛집 지도에서 **전통시장이나 골목상권에 있는 가게를 표시**하려고 해요.
- [사용자] 소상공인시장진흥공단의 온누리상품권 가맹점 데이터(data.go.kr 3060079)를 주면서 이렇게 말했어요. "전통시장이나 골목상권에 있는 가게를 표시할 때 활용해. 다만 **자료에 주소가 충분히 들어 있는지, 음식점인지 구분할 수 있는지 먼저 확인**해야 해"
- 버틴집 기획서의 3단계 판정에도 '전통시장/온누리' 조건이 있어요. 10/29 기획서 검토 때 AI는 이 결과를 선정 기준 5단계 '배지'(전통시장/온누리 가맹)에 바로 쓸 수 있다고 했어요.

## 핵심 논의

### 1. 점검 결과
**① 주소: 부족해요**
- 전국 225,803건 중 대구는 12,430건이에요.
- '소재지' 칸에 전부 **"대구"라고만** 적혀 있어요. 구·동·도로명·번지가 없어요.
- 위치를 알 수 있는 건 '소속 시장명(또는 상점가)' 하나뿐이에요. 대구에 240개가 있어요.

**② 음식점 구분: 일부만 돼요**
- 업종 코드가 없고 가게가 직접 입력한 '취급품목'만 있어요. 대구에서만 표현이 2,923가지이고, 364건(2.9%)은 비어 있어요.
- "한식", "칼국수"처럼 분명한 것도 있지만 "회", "떡볶이", "떡", "정육+구이"처럼 음식점인지 식품 판매인지 애매한 것도 있어요.

### 2. 보완한 방법 (AI가 실제로 적용)
- **시장 위치:** 전국전통시장표준데이터의 시장 위·경도로 95곳 위치를 확인했어요.
- **골목형상점가 위치:** 표준데이터에 없는 76곳은, 인허가로 위치가 확인된 소속 가게들의 중앙 위치로 추정했어요.
- **음식점 확인:** 취급품목 키워드로 먼저 나누고, 같은 이름의 일반음식점·휴게음식점·제과점 인허가가 시장 근처에 있으면 음식점으로 확정했어요. 확인되면 그 가게의 정확한 주소와 좌표도 가져와요.
- **오매칭 방지:** "홍시", "코코" 같은 짧은 이름이 다른 가게와 겹치지 않게, 시장에서 **700m 안(식품판매는 200m)**만 인정했어요. 의류 같은 비식품 가게는 음식점과 매칭하지 않았어요.

### 3. 결과 (대구 12,430곳)
| 판정 | 가게 수 |
|---|---|
| 음식점, 인허가 확인 | 2,033 |
| 음식점, 품목만 보고 추정 (미확인) | 862 |
| 애매 (음식점인지 식품판매인지) | 59 |
| 식품판매 | 2,819 |
| 비식품 (의류·잡화 등) | 6,395 |
| 품목 공란 | 262 |

| 위치 정확도 | 가게 수 |
|---|---|
| 가게 정확한 위치 (인허가 좌표) | 2,033 |
| 시장 위치로 대신 표시 (같은 시장 가게는 한 점에 겹침) | 9,539 |
| 위치 없음 | 858 |

- 위치 없는 858곳은 대현프리몰, 대신지하상가, 북성로상점가 등 위치를 못 찾은 시장·상점가 69곳 소속이에요.
- 지도 미리보기: 파란 원(시장·상점가, 크기 = 가맹점 수)과 빨간 점(인허가로 확인된 음식점). 빨간 점이 시장 원 근처에 모여 있어서 매칭이 맞게 된 걸로 봤어요.

## 내 의견과 요구사항

- [사용자] 이 데이터는 전통시장·골목상권 가게 표시용이다.
- [사용자] 쓰기 전에 주소가 충분한지, 음식점 구분이 되는지 먼저 확인해야 한다.

## 확정한 사항

- 원자료만으로는 주소가 부족하고(소재지가 "대구"뿐), 음식점 구분도 일부만 돼요.
- **가게 단위로 정확히 찍을 수 있는 건 '음식점(인허가 확인)' 2,033곳뿐이에요.** 나머지는 시장 단위로 표시하는 게 맞아요. (AI가 제시한 지도 사용 기준이고, 사용자의 별도 결정 기록은 없어요.)
