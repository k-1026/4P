### 발표 대본 (첫 버전, 13장 기준 6~7분)
- [사용자] "저 PPT 기준으로 발표 대본 짤까"라고 요청 → 슬라이드별 대본과 시간, 예상 질문 4개를 작성했어요.
- 예상 질문과 답:
  - "모범음식점은 왜 일부 구만?" → 공공데이터포털에 명단 파일이 있는 구만 넣음
  - "20년 이상은 왜 남구만?" → 받은 자료 중 인허가일자가 있는 게 남구뿐
  - "폐업한 가게도 있지 않나?" → 기준일 이후 변화는 반영 안 됐을 수 있음, 현장 확인은 다음 과제
  - "맛은 어떻게 판단?" → 맛을 직접 평가하지 않음. 공공기관 인증·선정이나 오래 영업했다는 '근거'를 보여주는 지도

### 지도 시연 제외
- [사용자] "**지도 안 보여주려고** 생각 중. 다 보여줄 필요는 없을 것 같아서"
- [AI 제안] 7장만 보여주고 나머지 숨김, 약 4분 대본으로 축약
- [사용자] "혹시 PPT를 지도 웹사이트 보여준다는 기준으로 한 거야?" → AI 답: 지도 화면은 한 장도 없지만, 숫자를 사이트 화면에 맞췄고 몇몇 문구(표지 부제 "~붙인 지도", 만드는 과정 5단계 "지도에 올리기", 바탕 데이터 "지도의 뼈대", 8가지 기준 부제, 표지·정리의 사이트 주소)가 지도를 전제로 했다고 설명

## 내 의견과 요구사항

- [사용자] 출처 문서를 고치지 말고, **어떤 데이터를 썼는지**로 PPT를 만들기
- [사용자] 교차 검증은 안 했고 "이 정도 진행해서 확인했다"는 수준으로 표현. **어느 공공기관 데이터를 썼는지 표기**하는 게 좋음
- [사용자] **지도는 시연하지 않음.** 다 보여줄 필요 없음
- [사용자] **자료를 어떻게 찾았고 어느 방향으로 가고 있는지** 중심으로
- [사용자] 5, 6번 슬라이드는 필요 없음
- [사용자] 방향 부분에 **기준 질문을 넣어 청중에게 직접 물어보기**
- [사용자] 기준 정하는 데 **강사님께 도움을 청할 것** (`10_맛집기준정하기_강사님자문_청중질문.md`)
- 발표 대본은 PPT 슬라이드 순서에 맞춰 달라는 요청이었어요.

## 검토 중인 사항

- "5, 6"의 해석 (화면 순서 vs 제목 번호) → 사용자 확인 안 됨
- "밑에 내용"의 뜻 → 사용자 확인 안 됨
- 방향 슬라이드 내용(넓히기·다지기)이 팀 실제 계획과 같은지 → AI가 정리한 것, 팀 확인 안 됨
- v3 최종 대본 전문은 PPT 발표자 노트에만 있어요. 이 파일에는 대본 전문이 없어요(아래 원래 대본 일부만 정리).

## 보류·제외한 방안과 이유

- **출처 문서 수정본** → 사용자 거절
- **지도 시연과 지도 관련 문구** → 사용자가 지도를 보여주지 않기로 함
- **8가지 맛집 기준·쓰지 못한 데이터 슬라이드** → 사용자가 필요 없다고 해서 숨김. AI는 기준을 강사님과 정하는 중이라 기준별 숫자가 오히려 헷갈릴 수 있다고 봤어요.
- **'고민 4가지 + 초안' 중심 7장 재구성** → 사용자가 답하지 않고 질문 슬라이드 방식으로 진행
