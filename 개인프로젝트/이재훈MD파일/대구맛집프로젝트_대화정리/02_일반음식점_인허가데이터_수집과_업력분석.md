### 2. 좌표 변환과 검증
- 원자료 좌표는 **EPSG:5174** (Bessel 중부원점TM, 데이터 설명에는 "보정계수 안 들어간"이라고 적혀 있음). 그대로 지도에 넣으면 위치가 어긋나요.
- 위도·경도(WGS84)로 변환했어요.
- **검증 1 (10/28):** 더현대 대구 변환값(35.86675, 128.59059)과 OpenStreetMap 위치(35.86668, 128.59060)가 약 **8m** 차이였어요.
- **검증 2 (10/29):** 서울 종로, 부산 중구, 대구 중구의 실제 점포 좌표를 두 방식으로 변환해 OSM 주소와 비교했어요.
  - EPSG:5174로 변환: 세 곳 모두 신고 주소와 같은 도로에 찍혔어요 (센트로폴리스 점포 → 우정국로, 롯데백화점 광복점 → 중앙대로, 반월당 점포 → 중앙대로).
  - 원점 보정 없는 EPSG:2097로 변환: 세 곳 모두 서쪽으로 약 260m 밀렸어요.
  - 결론: 데이터는 EPSG:5174 공식 정의(경도 원점 127.0028902777778°)와 일치해요.
- **변환식 (실제 변환에 쓴 값):**
```
+proj=tmerc +lat_0=38 +lon_0=127.0028902777778 +k=1 +x_0=200000 +y_0=500000
+ellps=bessel +units=m +no_defs +towgs84=-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43
```
```python
from pyproj import CRS, Transformer
src = CRS.from_proj4("+proj=tmerc +lat_0=38 +lon_0=127.0028902777778 +k=1 +x_0=200000 +y_0=500000 +ellps=bessel +units=m +no_defs +towgs84=-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43")
tf = Transformer.from_crs(src, "EPSG:4326", always_xy=True)
lon, lat = tf.transform(float(row["CRD_INFO_X"]), float(row["CRD_INFO_Y"]))
```
- **변환 파라미터 주의:** epsg.io의 다른 파라미터(`towgs84=-145.907,505.034,685.756,-1.162,2.347,1.592,6.342`)를 쓰면 결과가 약 15~20m 달라져요. 10/29 첫 답변에서는 epsg.io 값을 소개했고, 이후 답변에서는 실제 검증한 위 값(-115.80…)을 권했어요. 어떤 값을 쓰든 **지도에 올리기 전에 랜드마크 한두 곳으로 확인**하는 게 원칙이에요.
- QGIS에서는 위 문자열로 사용자 정의 좌표계를 만들어 X·Y를 불러오면 돼요.
- **좌표 없는 행:** 중구 516곳, 대구 전체 3,990곳(약 4%). 지도에는 영업 중 28,961곳이 찍혀 있어요. 10/29 중구 샘플 600건 기준으로는 좌표가 566건(약 94%)에 있었어요.

### 4. 출처 표 행 점검 (10/29)

**링크와 형태**
- `15096283`은 실제로 **표준데이터(CSV) 페이지**예요. 메타데이터 기준 전국 2,129,830행, 수정일 2025-11-27이에요.

**API 필드명 (명세와 실제 응답 모두 확인)**
| 필요 항목 | 필드명 | 실제 값 |
|---|---|---|
| 인허가일자 | `LCPMT_YMD` | 명세는 YYYYMMDD, 실제 응답은 `2026-10-23`처럼 하이픈 포함 |
| 폐업일자 | `CLSBIZ_YMD` | 폐업 건에만 값이 있음 |
| 영업상태 | `SALS_STTS_CD` / `SALS_STTS_NM` | 01 = 영업/정상, 03 = 폐업 |
| 상세영업상태 | `DTL_SALS_STTS_CD` / `DTL_SALS_STTS_NM` | 폐업 건은 02 = 폐업 |
| 업태 | `BZSTAT_SE_NM`(업태구분명), `SNTTN_BZSTAT_NM`(위생업태명) | 샘플에서는 두 값이 같음 |
| 소재지면적 | `LCTN_AREA` | 문자열, 빈 값 많음 (중구 샘플 600건 중 346건만 값 있음, 약 58%) |
| 좌표 | `CRD_INFO_X`, `CRD_INFO_Y` | 문자열, 대구 전체 약 4% 없음 |
- 그 밖의 필드: `MNG_NO`(관리번호, 예 `3410000-101-2026-00371`), `BPLC_NM`(사업장명), `ROAD_NM_ADDR`, `LOTNO_ADDR`, `DAT_UPDT_PNT`(데이터갱신시점)
- 휴업시작·종료일자와 인허가취소일자는 API 명세에 없어요.
- **폐업 점포 조회:** `/info`에서 `cond[SALS_STTS_CD::EQ]=03`. 필터는 인허가일자 범위, 영업상태, 사업장명, 도로명주소, 갱신시점, 자치단체코드를 지원해요. 한 번에 최대 100건이에요.
- `/history` 엔드포인트도 있어요(기준일자 `cond[BASE_DATE::EQ]`와 자치단체코드 필수). 직접 호출은 안 해봤어요.
- 영업기간 계산: `CLSBIZ_YMD − LCPMT_YMD` (폐업일 − 인허가일)

## 확정한 사항

데이터로 확인된 사실이에요.
- API(15154916)는 필요한 6개 항목을 모두 제공해요. **폐업일자(`CLSBIZ_YMD`)가 들어 있고 폐업 점포도 조회돼요.**
- 좌표계는 **EPSG:5174가 맞아요** (3개 도시 실측 검증).

- 인허가일자는 지위승계 후에도 유지돼요. 그래서 업력은 "같은 자리에서 음식점이 이어진 기간"으로 봐야 해요 (예: 컴포즈커피 대구경북대병원점이 1971년 인허가로 나옴).
- 출처 표 행은 위 '6. 최종 정리한 엑셀 한 줄'로 정리했어요. 사용자가 이 행을 표에 반영했는지는 **확인 필요**예요.
