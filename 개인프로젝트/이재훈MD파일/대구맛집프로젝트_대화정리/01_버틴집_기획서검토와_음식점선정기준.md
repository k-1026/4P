### 기획서 핵심 (AI가 문서를 읽고 요약한 내용)
- 핵심 지표는 **생존배수**예요. 인허가 데이터의 개업일과 폐업일로 "같은 구·업태에서 폐업한 가게들의 평균 영업 기간보다 몇 배 오래 영업했나"를 계산해요.
- 그다음 상권(대구로페이·온누리), 착한가격, 전통시장 조건을 하나씩 붙여서 **3단계로 판정**해요.
- '오늘 영업 확률'은 인스타그램으로 판단해요.
- 영수증 리뷰는 상위 20~30곳만 표본으로 봐요.
- 문서는 "맛집이 아니라 검증된 동네 가게"라는 표현을 써요. "같은 자리에서 상호만 바뀐 경우"를 점검하고, "근거가 뭉개지지 않게" 하자는 원칙이 있어요.
- 기획서 원문 전체는 이 파일에 없어요. 세부 내용은 원문으로 확인해야 해요(**확인 필요**).

- **다이닝코드:** 블로그 광고성 글 필터링, 빅데이터 기반 맛집 분석, 취향 맞춤 추천과 순위

- **거지맵:** 지도 기반 가성비 식당 푸드위키. 익명 제보로 최신 가격 공유

## 핵심 논의

### 1. 다른 앱과 비교한 버틴집의 위치 [AI 분석]
| 앱 | 실제 방식 (AI가 찾은 근거) |
|---|---|
| 다이닝코드 | 블로그 품질·최신성·클릭수·댓글 분석, 광고성 블로그는 패턴 분석으로 자동 제외. 랭킹에 사용자 별점·좋아요·블로그 평판 반영, 최근 데이터 가중치 |
| 뽈레 | 평점과 별도로 추천/좋음/별로 3단계 평가 개수를 지표로 써서 변별력이 높다는 평가 |
| 테이스트버즈 | 대중적 추천 대신 취향이 비슷한 회원의 맛집을 알고리즘으로 추천 |
| 거지맵 | 사용자들이 공유하는 최신 가격 정보와 제보 기능. 지금은 앱테크 리워드 앱 성격도 강함 |

- 네 앱 모두 근거가 "사람이 남긴 평가"라서 어뷰징과 싸우는 구조예요.
- 버틴집은 공공 신고 자료가 근거라서 **조작에 강한 게 차별점**이에요. 반대로 **맛 신호가 전혀 없는 게 약점**이에요.

### 2. 보완점 7가지 (AI가 중요한 순서로 정리)
1. **생존배수 공식의 편향**
   - 분모(폐업 가게 평균 영업 기간)는 빨리 망한 가게 때문에 짧게 나와요. 분자(영업 중 가게 기간)는 아직 끝나지 않은 값이에요.
   - 그래서 웬만큼 오래된 가게는 다 2배를 넘겨서 변별력이 떨어질 수 있어요.
   - 대안: 같은 구·업태의 영업 중 + 폐업 가게 전체에서 **업력 백분위**를 쓰거나, 생존분석(**Kaplan-Meier**)으로 "이 업력까지 살아남을 확률"을 구하기
   - 카드 문구 예: "수성구 한식 100곳 중 4곳만 이만큼 버팀"
2. **프랜차이즈 필터가 없음**
   - 오래 버틴 가게 상위권에 체인점, 호프, 다방이 대거 들어올 수 있어요.
   - 휴게음식점(카페·제과)과 주점류를 같은 지도에 넣을지 별도 레이어로 뺄지 정해야 해요.
3. **이전·양도 시 업력이 끊기거나 부풀려짐**
   - 기획서는 "같은 자리에서 상호만 바뀐 경우"만 점검해요.
   - 반대로 유명 노포가 이사해서 새로 인허가를 받으면 업력이 리셋돼요.
   - 같은 구 안에서 동일 상호·업태의 폐업 → 개업이 이어지는 기록을 한 가게로 묶는 로직이 필요해요.
4. **맛 검증 레이어가 약함**
   - 영수증 리뷰를 상위 20~30곳만 보지 말고, 후보 전체에 **거부권(veto) 필터**로 쓰자는 제안이에요. 예: 부정 평가 비율이 높으면 제외
   - 점수에는 넣지 않으니 "근거가 뭉개지지 않게" 원칙과도 맞아요.
   - 나중에 자체 평가를 붙인다면 별점보다 뽈레식 3단계(추천/좋음/별로)가 컨셉에 맞아요.
5. **'오늘 영업 확률'이 타깃과 안 맞음**
   - 20년 넘은 노포는 인스타 비즈니스 계정이 없을 가능성이 커서, 상위 점포 대부분이 '확인 필요'로 뜰 수 있어요.
   - 인스타는 보조로 낮추고, 거지맵식 **"폐업/휴무 제보" 버튼**과 정기휴무 정보를 기본으로 두자는 제안이에요.
   - 인허가 폐업 신고가 실제 폐업보다 늦는 문제도 제보로 메울 수 있어요.
6. **사용자 기능이 거의 없음**
   - 다른 앱은 모두 "가봤다/가고싶다" 저장과 리스트 공유가 기본이에요. 저장과 공유 링크 정도는 넣자는 제안이에요.
7. **착한가격 가격 정보가 오래됐을 수 있음**
   - 카드에 가격 기준일을 표시하고 가격 제보를 받자는 제안이에요.

### 3. 음식점 선정 기준 제안 [AI 제안, 사용자 미확정]
단계형 판정은 그대로 두고, 앞에 '대상 범위', 중간에 '검증' 단계를 추가하는 구조예요. 수치는 출발점이고 실제 분포를 보고 조정하자고 했어요.

| 단계 | 조건 | 역할 |
|---|---|---|
| 0. 대상 범위 | 일반음식점 영업 중, 프랜차이즈 제외, 주점·카페는 별도 레이어 | 노이즈 제거 |
| 1. 업력 (필수) | 절대 업력 **10년 이상** 그리고 같은 구·업태 안에서 업력 **상위 10%** | "오래 버틴 집" |
| 2. 동일성 검증 | 이전·양도 연결, 상호 변경 걸러내기 | 업력이 진짜인지 확인 |
| 3. 평판 거부권 | 외부 리뷰가 일정 수 이상이고 부정 비율이 낮을 것 (점수 반영 X, 탈락만) | 맛 최소 보장 |
| 4. 동네 수요 | 주민 소비 상권(대구로페이 밀도, 외지인 비중 낮음) 안 | "동네가 고른 집" |
| 5. 배지 (순위 X) | 착한가격업소, 전통시장/온누리 가맹 | "동네가 먹여 살린 집" 강조 |
| 6. 신선도 | 최근 6개월 안에 리뷰·게시물·제보 같은 활동 신호가 없으면 '확인 필요' | 헛걸음 방지 |

- **절대 업력 하한**을 넣은 이유: 상대 순위만 쓰면 신규 상권에서는 5년짜리 가게도 상위 10%가 될 수 있어서예요.
- **평판 거부권**을 넣은 이유: 기획서의 "오래 버텼다고 맛있다는 보장은 없다"는 한계를 직접 보완하려고요.
- 다른 앱 맛집 목록과 비교해서 겹치는 가게는 검증 근거로, 안 겹치는 가게는 "다른 앱에 없는 숨은 동네 가게"로 홍보하자는 아이디어도 냈어요.

### 4. 보완점별 대안 3가지와 자료 출처 [AI 제안]
사용자가 "대안을 3가지씩 가져오고 자료를 어디서 가져오는지 알려줘"라고 요청해서 정리한 표예요.

**확보 방법 표기:** 바로 = 로그인 없이 다운로드 / 키 = 공공데이터포털 활용신청 후 무료 API / 유료 = 결제 계정 필요 / 자체 = 직접 쌓는 데이터 / 수동 = 사람이 직접 확인

**① 생존배수 대신 쓸 업력 지표**
| 대안 | 방법 | 자료 | 확보 |
|---|---|---|---|
| A. 업력 백분위 | 같은 구·업태 안에서 영업 중 + 폐업 전체 중 순위 | 행정안전부_식품_일반음식점 (인허가일자·영업상태 포함) | 바로 |
| B. 생존확률 (Kaplan-Meier) | "이 업력까지 살아남을 확률 4%"처럼 표현. 영업 중 가게도 계산에 포함 | 같은 인허가 데이터 + 파이썬 lifelines | 바로 |
| C. 개업연도 코호트 | "2005년 수성구에서 문 연 한식집 중 지금 남은 곳 X%" | 같은 인허가 데이터 | 바로 |

- C는 10/28에 만든 대구 전체 음식점 파일(97,575건)에 '개업연도별 생존율' 시트가 이미 있어요.

**② 프랜차이즈 걸러내기**
| 대안 | 방법 | 자료 | 확보 |
|---|---|---|---|
| A. 브랜드명 매칭 | 상호에 가맹 브랜드명이 있으면 제외 | 공정위_가맹정보_브랜드 목록 API (data.go.kr 15125467) | 키 |
| B. 가맹점 상호 직접 매칭 | 브랜드별 실제 가맹점 상호와 대조 | 공정위_가맹정보_브랜드별 가맹점 현황 API (data.go.kr 15110241) | 키 |
| C. 상호 반복 규칙 | 대구 안에서 같은 상호가 여러 번 나오거나 "~점"으로 끝나면 체인 의심 | 인허가 데이터 자체 | 바로 |

- **정정:** B안은 나중에(같은 날 다른 대화) **15110241에는 개별 점포 목록이 없고 브랜드 단위 통계만 있다**고 정정됐어요. 그래서 B안은 쓸 수 없어요. 자세한 내용은 `04_프랜차이즈식별_공정위가맹정보.md`에 있어요.

**③ 업력이 진짜인지 검증**
- 10/28 분석에서 확인된 사실: **지위승계로 주인이 바뀌어도 원래 인허가일이 유지돼요.** 그래서 컴포즈커피 한 지점이 1971년 개업으로 나왔어요. 지금 업력은 "같은 자리의 음식점 업력"이지 "같은 가게 업력"이 아니에요. 노포가 이사하면 반대로 업력이 리셋돼요.

| 대안 | 방법 | 자료 | 확보 |
|---|---|---|---|
| A. 상호 변화 추적 | 과거 시점 파일을 비교해 같은 자리 상호가 바뀌었는지 확인 | 소상공인시장진흥공단_상가(상권)정보 (data.go.kr 15083033)의 주기성 과거 데이터 | 바로 |
| B. 이전 연결 | 폐업 직후 같은 구에서 동일 상호·업태로 새로 개업한 기록을 한 가게로 묶음 | 인허가 데이터 자체 | 바로 |
| C. 공식 장수가게 교차 확인 | 지정된 가게는 업력 확정으로 처리 | 소상공인시장진흥공단_전국 백년가게 지정리스트 (data.go.kr 15132695, 1,511행, 연간 갱신) | 바로 |

**④ 맛 검증 (거부권 필터)**
| 대안 | 방법 | 자료 | 확보 |
|---|---|---|---|
| A. 공식 지정 목록 교차 | 모범음식점·백년가게 지정 여부를 신뢰 신호로 | 행정안전부_모범음식점정보 조회서비스 (data.go.kr 15155052) | 키 |
| B. 구글 평점·리뷰 수 | 평점이 낮거나 리뷰가 너무 적으면 탈락 | Google Places API (New) Place Details의 `rating`, `userRatingCount` | 유료 |
| C. 국내 앱 표본 확인 | 상위 후보만 네이버 영수증 리뷰, 다이닝코드, 뽈레에서 직접 확인 | 각 앱 화면 | 수동 |

- 모범음식점은 위생·서비스 기준 지정이라 맛 근거는 아니에요. "최소 품질" 신호로만 쓰는 게 맞아요.
- 구글 `rating`은 Pro 등급 과금 필드예요.
- 네이버·카카오는 평점 공식 API가 없어서 대량 수집하면 약관 문제가 생겨요. 수동 표본으로만 쓰자고 했어요.

**⑤ 오늘 영업 확인 (인스타 대체)**
| 대안 | 방법 | 자료 | 확보 |
|---|---|---|---|
| A. 구글 영업 상태 | 폐업이면 `businessStatus`에 `CLOSED_PERMANENTLY`. 정기 영업시간도 받음 | Google Places API (New) | 유료 |
| B. 인허가 일간 변동 | 폐업·휴업 신고를 매일 반영 | 행정안전부_식품_일반음식점 조회서비스 (data.go.kr 15154916, 일간 갱신) | 키 |
| C. 사용자 제보 | "폐업했어요 / 오늘 쉬어요" 버튼 (거지맵 방식) | 자체 수집 | 자체 |

- 인스타 분류는 비즈니스 계정이 있는 가게에만 붙이는 옵션으로 낮추자고 했어요.

### 5. 대구 로컬 프랜차이즈
- [사용자] "대구 프렌차이즈도 있을 수 있잖아. 대구만 있는 막창 프렌차이즈나"라고 지적했어요.
- AI가 10/28 데이터(대구 영업 중 일반음식점 29,277곳)에서 같은 상호 5곳 이상을 뽑아 공정위 가맹사업거래 사이트(franchise.ftc.go.kr)에서 하나씩 검색했어요.
- 결과: **태영생막창(21곳), 오빠막창(7곳), 황금막창·고향숯불막창(각 5곳), 정하용선산곱창(6곳), 청도추어탕(21곳)은 공정위 등록 없음.** 막창도둑, 대구반야월막창, 봉자막창, 신참떡볶이, 신불떡볶이, 호식이·종국이두마리치킨은 등록돼 있어요.
- AI는 일괄 제외 대신 ① 전국 프랜차이즈(제외) ② 대구 로컬 체인(본점만 후보, "대구 출신 브랜드" 배지) ③ 동명 상호(개별 가게로 평가)의 **3분류**를 제안했어요.
- 상세 표, 판별 규칙, 공정위 API 필드는 `04_프랜차이즈식별_공정위가맹정보.md`에 따로 정리했어요.

## 내 의견과 요구사항

- [사용자] 기획서를 보고, 다른 맛집 앱을 참고해서 **보완점**과 **음식점 선정 기준**을 파악해 달라고 했어요.
- [사용자] 보완점마다 **대안을 3가지씩**, 그리고 **자료를 어디서 가져오는지** 알려 달라고 했어요.
- [사용자] **대구에만 있는 로컬 프랜차이즈**(막창 체인 등)도 고려해야 한다고 했어요.

## 확정한 사항

- **사용자가 선정 기준이나 보완 방향을 확정한 기록은 없어요.** 아래는 데이터로 확인된 사실이에요.
  - 인허가 데이터는 지위승계 후에도 원래 인허가일이 유지돼요 (예: 컴포즈커피 한 지점이 1971년 인허가로 나옴).
  - 대구 반복 상호 중 태영생막창 등 일부는 공정위 정보공개서에 등록돼 있지 않아요.
  - 공정위 브랜드명으로 부분 일치 검색을 하면 비슷한 이름이 잘못 걸려요 (예: 동궁찜닭 → 설동궁찜닭, 일품돼지국밥 → 나날이일품돼지국밥).

## 검토 중인 사항

모두 **[AI 제안]**이고 사용자 답변은 없었어요.
- 생존배수 대신 업력 백분위·Kaplan-Meier·개업연도 코호트 중 하나를 쓰기
- 0~6단계 선정 기준 (절대 업력 10년 + 구·업태 상위 10%, 평판 거부권, 신선도 6개월 등)
- 프랜차이즈 3분류 처리 (전국 제외 / 대구 로컬 체인은 본점만 / 동명 상호는 개별 평가)
- 인스타 대신 제보 버튼과 구글 영업 상태로 '오늘 영업' 확인
- 저장·공유 기능 (localStorage, URL 공유)
- 가격 기준일 표시와 참가격 비교 문구

## 보류·제외한 방안과 이유

- **생존배수 단독 사용** → AI가 편향(분모가 짧게 나와 대부분 2배를 넘음) 때문에 대안을 권했어요. 팀이 실제로 바꿨는지는 **확인 필요**.
- **인스타 중심 '오늘 영업' 판단** → 노포는 인스타 계정이 없을 가능성이 커서 보조로 낮추자고 제안했어요.
- **네이버·카카오 평점 대량 수집** → 공식 API가 없고 약관 문제가 있어 수동 표본으로만 쓰자고 했어요.
- **공정위 목록만으로 프랜차이즈 일괄 제외** → 미등록 로컬 체인을 놓치고, 로컬 체인 본점은 오히려 핵심 후보일 수 있어서 3분류를 제안했어요.
- **공정위 15110241로 가맹점 상호 매칭** → 개별 점포 목록이 없다는 게 나중에 확인돼서 사용 불가예요.
