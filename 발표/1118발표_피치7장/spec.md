## 1. 한 문장

**리뷰 대신 공공 인허가 기록(개업일·폐업일)으로 "주변 가게보다 오래 버틴 집"을 지도에서 보여 주는 서비스.**
약속 문장 [팀결정]: "살아남았다는 건 인정받았다는 것". "맛이 검증됐다"는 말은 하지 않습니다.

## 3. As-Is → To-Be

| 장면 | As-Is (지금) | To-Be (버틴집) |
|---|---|---|
| 후보 비교 | 별점·리뷰 수로 고름. 이벤트·대행으로 부풀릴 수 있음 | 가게 카드에 **"이 자리 26.7년 · 주변 폐업 가게보다 6.7배"** 처럼 돈으로 못 바꾸는 근거 |

| 노포 찾기 | "노포" 키워드 검색 → 광고 글 | 생존배수 TOP 100 · 백년가게 후보(업력 30년+, 프랜차이즈 제외) · ★ 실제 선정 58곳 |
| 헛걸음 | 지도에 남은 폐업 가게 | 인허가 + 상가정보 + 카카오로 **매일** 영업/폐업 재판정 |
| 가족 설득 | "리뷰 많더라" | "동네 한식 중 상위 N%" 한 줄 근거 |

## 4. 생존배수 정의 (v1.0, 임시)

```
생존배수 = 이 가게 영업연수 ÷ (가까운 폐업 가게 k곳의 평균 영업연수)
```
- 비교 풀: 대구 일반·휴게·제과 폐업 가게 (좌표 있음), 30일 하한
- 기본 k: 화면 10~20 (분석으로 정한 값 아님 → results.md H2)
- 영업 중 가게는 "계속 영업할수록 배수가 올라갑니다" 고지 (중도절단 편향 B2)
- '주인 바뀜 의심' 3,516곳은 업력이 실제보다 길 수 있음 표시 (B3)
