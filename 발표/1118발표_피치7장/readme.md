## 구조의 규칙 (지킨 것)

- 표지 다음 바로 **문제**. 회사·팀 소개로 시작하지 않습니다 (팀은 6장).
- 마지막 장은 "감사합니다"가 아니라 **요청사항 한 문장 + MVP URL**입니다 (7장).
