# VOC 분류 규칙 — `voc_classified.csv` (3b단계, 2026-11-17)

> Day11 16쪽 세 축(단계 · 유형 · 강도)을 따르고, 감정 곡선을 데이터로 내기 위해 **표본** · **감정** 열을 더했다. 같은 규칙이면 누가 해도 같은 결과가 나오도록 적는다.

## 열

| 열 | 값 | 판정 규칙 |
|---|---|---|
| voc_id | S번호-단계 · D · N · G | S = 중립 표본(`voc_표본_중립_원본_2026-11-17.md`), D · N = 불만 검색 대구 VOC, G = 대구 밖 일반 VOC (`voc_대구_수집_2026-11-17.md`) |
| 표본 | 중립표본 / 불만검색 / 일반(대구 밖) | 어떤 검색어로 모았는지. **감정 점수는 중립표본만으로 낸다** |
| 단계 | journey_map.md 6단계 | VOC가 말하는 시점 · 장소로 판정. 한 글에 여러 단계가 나오면: 중립표본은 **단계별로 감정이 드러난 문장만** 따로 한 줄씩(아래), 불만검색 VOC는 Day11대로 **가장 강한 감정이 있는 단계 하나** |
| 유형 | 불만 / 요청 / 질문 / 칭찬 / 언급 / 기대 / 추천 | Day11 네 가지 + "언급"(감정 없이 사실만), "기대"(가 보겠다 · 먹어 보고 싶다), "추천"(남에게 권함) — 기대 · 추천은 2차 검수 뒤 추가 |
| 강도 | 1 언급 · 2 반복 불만 · 3 포기 · 손해 | 불만에만. 3은 돌아섬 · 못 먹음 · "다시 안 감" |
| 감정 | + / 0 / − / 혼합 | 칭찬 = +, 언급 = 0, 불만 = −, 한 문장에 만족과 실망이 함께면 혼합 |
| 원인묶음 | C1~C5 (`candidates.md`) 또는 긍정 묶음 | C1 리뷰 · 광고 신뢰, C3 후기 · 평판 대비 실망, C4 웨이팅 실망, C5 헛걸음(휴무 · 재료 소진 · 대기 마감 · 정보 불일치) |

## 감정 점수 (Day11 14쪽: 같은 단계 VOC의 긍정 · 부정 건수 비율, 3건 미만은 근거 부족)

점수 = 2 × (긍정 − 부정) ÷ (긍정 + 부정), 소수 첫째 자리에서 반올림. 혼합 · 언급(0)은 점수 계산에서 빼고 건수만 적는다.
