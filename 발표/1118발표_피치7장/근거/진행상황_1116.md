## 3. 매일 자동 갱신 (11/13 완성)

매일 **오전 9시 30분**, 이재훈 PC에서 사람 손 없이 돌아갑니다 (약 2분).

```
인허가 3종 받기 → 검증 · 정리 → 자동 판정 → 조원 판정 합치기 → 기본 파일 → daegu.json → 팀 페이지 main에 올림 → 사이트 반영
```

- 안전장치: 받은 파일이 이상하면 멈춤 · 가게 수가 어제와 크게 다르면 되돌림 · 사이트와 크게 다르면 올리지 않음 · 강제 덮어쓰기 없음 · 내용이 같으면 올리지 않음 · 동시에 두 번 안 돌게 잠금
- PC가 꺼져 있으면 그날은 안 돌고, 켠 뒤 로그인하면 바로 한 번 돕니다
