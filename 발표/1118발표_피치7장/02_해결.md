# 2장 해결 — "왜 이 방법인가?"

> 증명할 것: **AI로 무엇이 어떻게 달라지는가**
> 근거 산출물: AX 기회 정의 · [spec.md](spec.md) · As-Is → To-Be

## 슬라이드 한 장 요약

**리뷰는 돈으로 살 수 있지만, 버틴 시간은 살 수 없습니다.**
버틴집은 행안부 인허가 기록 133,125곳을 매일 자동으로 다시 판정하고, 각 가게를 **주변 폐업 가게와 비교한 생존배수**로 보여 줍니다.

## 왜 이 방법인가 — 세 가지 이유

| 이유 | 근거 |
|---|---|
| ① 문제가 생기는 곳(②평가·③노출)에 돈이 닿지 않는 데이터를 놓는다 | 1장 밸류체인 병목 B1 |
| ② 사용자가 이미 그 신호를 원한다 | "이 자리에서 23년째 영업 중"을 참고하겠다 **81%(66명)**, "6개월째"는 36% [확인] 설문 Q13 |
| ③ 실제로 오래 인정받은 가게를 골라낸다 | 백년가게 49곳이 생존배수 **상위 21%**(중앙값)에 몰림, 무작위면 50% (p<0.001) [계산] 5장 |

## As-Is → To-Be (요약, 자세히는 spec.md 3절)

```
As-Is  별점·리뷰 수 ──(이벤트·대행으로 부풀림)──▶ 후보 비교 ──▶ 실망·헛걸음
To-Be  인허가 개업·폐업일 ──(매일 자동 판정)──▶ 생존배수·상위 % ──▶ 근거 있는 선택
```

## AI가 바꾸는 것 (AX 기회)

| 전 (사람이 하면) | 후 (버틴집) |
|---|---|
| 13만 곳 영업 여부를 사람이 확인 — 불가능 | 4단계 자동 판정, 표본 300곳 규칙·Claude 판정 98% 일치, 사람은 1,553곳만 |
| 노포 여부는 블로그 글로 짐작 | 인허가일 기준 업력 + 주변 비교를 계산식과 함께 공개 |
| 데이터는 한 번 모으고 끝 | 매일 9:30 갱신 → 사이트 자동 반영 (11/13부터) |

## 정직하게 밝힐 것

- 업력은 별점을 **대체하지 않고 보완**합니다. "4.8점·8개월 vs 4.2점·23년"에서 전체는 4.8점을 더 골랐습니다 (51% 대 32%). 다만 리뷰 불신이 가장 큰 사람은 23년 가게로 기웁니다 (50%, n=18).
- 생존배수는 아직 임시 정의입니다 (k, 분모, 하한 미확정 → results.md).
