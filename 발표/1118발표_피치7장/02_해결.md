# 2장 해결 — "왜 이 방법인가?"

> 증명할 것: **AI로 무엇이 어떻게 달라지는가**
> 근거 산출물: AX 기회 정의 · [spec.md](spec.md) · As-Is → To-Be
> 11/18 수정: 백년가게 검증 결과(업력만 쓴 순위가 더 잘 맞음)와 맞도록 **"업력이 핵심 근거, 주변 비교는 맥락"** 으로 바꿈. 헛걸음은 "폐업 가게를 지도에서 빼는 것"까지만 약속

## 슬라이드 한 장 요약

**리뷰는 돈으로 살 수 있지만, 버틴 시간은 살 수 없습니다.**
버틴집은 행안부 인허가 기록으로 **"이 자리에서 몇 년 버텼나(업력)"** 를 보여 주고, 주변 가게와 비교해 **"이 동네에서 얼마나 드문가(생존배수)"** 를 덧붙입니다. AI는 13만 곳의 영업 · 폐업을 매일 다시 판정해 **문 닫은 가게를 지도에서 뺍니다.**

## 1장의 아픔과 짝 맞추기

| 1장 여정 | 아픔 | 버틴집이 주는 것 |
|---|---|---|
| 3 후보 걸러내기 | 부풀려질 수 있는 평판을 믿고 고름 (원인) | **돈으로 못 바꾸는 근거 한 줄**: "이 자리 26.7년" |
| 5 가서 들어가기 | 인기 순으로 같은 집에 몰려 줄 섬 | 인기 순이 아닌 **업력 순**으로 다른 후보를 보여 줌 (줄 분산) |
| 6 먹고 돌아보기 | 평판만 못해서 실망 | 기대를 "리뷰 4.8점"이 아니라 **"동네가 오래 먹여 살린 집"** 에 맞춤 |
| 5 헛걸음 (3위 페인) | 폐업 · 휴무로 허탕 | **폐업한 가게는 매일 지도에서 뺌.** 임시 휴무 · 재료 소진은 아직 못 함 (다음 단계) |

## 왜 이 방법인가 — 세 가지 이유

| 이유 | 근거 |
|---|---|
| ① 사람들이 이미 이 신호를 찾는다 | 질문글 "숨은 · 현지인 맛집" 요청 5건, "3년 이상 안 망하고 장사하고 있으면 평타"(유튜브) · 설문 "이 자리에서 23년째"를 참고하겠다 **81%**, "6개월째"는 36% |
| ② 업력은 실제로 인정받은 가게를 골라낸다 | 정부가 고른 백년가게 49곳이 **업력 순위 상위 7.9%**(중앙값)에 몰림. 무작위면 50% |
| ③ 평판이 부풀려지는 곳에 돈이 닿지 않는 데이터를 놓는다 | 1장 밸류체인 병목 B1 (② 평가 · ③ 노출에 식당 돈) |

## 업력과 생존배수 — 각자의 역할

| | 업력 (핵심 근거) | 생존배수 (맥락) |
|---|---|---|
| 무엇 | 이 자리에서 영업한 햇수 | 이 가게 업력 ÷ 가까운 폐업 가게 평균 업력 |
| 답하는 질문 | "오래 버텼나?" | "이 동네에서 그게 얼마나 드문가?" |
| 검증 | 백년가게 상위 **7.9%** | 백년가게 상위 **21.1%** (무작위 50%보다는 확실히 높음, p<0.001) |
| 화면 | 가게 카드 첫 줄 | 둘째 줄 + 비교한 폐업 가게 지도 |

→ 5장 검증 결과(H2 기각)는 반박이 아니라 **이 설계의 근거**입니다. 생존배수는 분모 보정 후 다시 검증합니다 (results.md 계획 1~2).

## As-Is → To-Be (요약, 자세히는 spec.md 3절)

```
As-Is  리뷰 · 인기 순 ──(이벤트 · 대행으로 부풀림)──▶ 같은 집에 몰림 ──▶ 줄 서고 실망
To-Be  인허가 업력 + 주변 비교 ──(매일 자동 판정)──▶ 근거 한 줄로 후보 비교 ──▶ 기대에 맞는 선택
```

## AI가 바꾸는 것 (AX 기회)

| 전 (사람이 하면) | 후 (버틴집) |
|---|---|
| 13만 곳 영업 여부를 사람이 확인 — 불가능 | 4단계 자동 판정, 표본 300곳 규칙 · Claude 판정 98% 일치, 사람은 1,553곳만 |
| 노포 여부는 블로그 글로 짐작 | 인허가일 기준 업력 + 주변 비교를 계산식과 함께 공개 |
| 데이터는 한 번 모으고 끝 | 매일 9:30 갱신 → 폐업 가게 자동 제외 (11/13부터) |

## 정직하게 밝힐 것

- 업력은 별점을 **대체하지 않고 보완**합니다. "4.8점 · 8개월 vs 4.2점 · 23년"에서 전체는 4.8점을 더 골랐습니다 (51% 대 32%). 다만 리뷰 불신이 큰 사람은 23년 가게로 기웁니다 (50%, n=18).
- 업력은 맛을 보장하지 않습니다. "살아남았다는 건 인정받았다는 것"까지만 말합니다.
- 주인이 바뀐 가게(3,516곳 의심)는 업력이 실제보다 길게 나올 수 있어 표시합니다.
