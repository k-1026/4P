# 버틴집 페인포인트 정의서 (2026-11-17)

- **근거 파일:** `painpoint/voc_classified.csv` (VOC 172건), `painpoint/journey_map.md` (단계 이름)
- **진술문 형식:** [누가] [언제] [무엇을 하려다] [왜 막히는가] [근거]
- **좋은 진술문 기준**
  1. 해결책이 문장에 들어 있지 않음
  2. 한 문장에 원인 하나
  3. 근거 VOC 3건 이상, 출처 2종 이상
  4. 여정지도 단계 이름과 정확히 일치 (`② 식당 검색` · `③ 리뷰 확인` · `④ 결정 · 이동` · `⑤ 식사`)

### 근거로 센 VOC

- **센 것:** 유형이 "불만"이고, 2022년 이후 작성이 확인된 VOC
- **세지 않은 것:**
  - "검토"로 표시된 VOC
  - "여정 밖" VOC
  - 2022년 이전 VOC와 작성일 미확인 VOC
  - 칭찬 · 요청 · 질문
- **출처 종류:** 앱 리뷰(Google Play), 언론 보도, 커뮤니티(익명 게시판 · 리뷰 사이트), 블로그, 팀 VOC의 5종

### 행위자에 대해

- 진술문의 [누가]는 **근거 VOC가 실제로 말해 주는 사람**으로 적었습니다.
- 근거 VOC는 모두 대구 밖이거나 지역 미상입니다. 대구 나들이 고객의 VOC는 0건입니다.
- 그래서 여정지도의 행위자 정하준(구미 30대, 아내와 당일 대구 나들이)에게 그대로 적용된다는 것은 **[가정]**입니다.

- **출처가 얇은 진술문:**

  - 기준은 넘지만 출처를 더 모으면 더 튼튼해집니다.
- **같은 VOC를 두 번 쓴 경우:** CY-068은 한 리뷰에 원인 두 개가 들어 있어 PP-02와 PP-03에 같이 썼습니다.
