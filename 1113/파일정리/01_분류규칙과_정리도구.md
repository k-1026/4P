# 분류 규칙과 자동 정리 도구

> 바탕화면과 다운로드에 새로 생긴 파일을 매일 자동으로 정리하는 도구와 그 규칙입니다.
> 정리 기록 요약은 [00_파일정리_요약.md](./00_파일정리_요약.md)에 있습니다.

## 1. 도구가 하는 일

매일 **17:50**에 Windows 작업 스케줄러("바탕화면 날짜별 정리")가 실행합니다. PC가 꺼져 있었으면 다음에 켤 때 실행됩니다.

1. **모으기**: 바탕화면·다운로드에 새로 생긴 파일·폴더를 `바탕화면\기록\MMDD`로 옮깁니다.
   - 바탕화면 항목은 생긴 날짜, 다운로드 항목은 받은 날짜 기준
2. **분류하기**: `기록\MMDD` 안의 항목을 아래 규칙에 따라 알맞은 폴더로 보냅니다.
   - 규칙에 안 맞는 항목은 `기록\MMDD`에 그대로 남습니다.

### 건너뛰는 것

| 대상 | 이유 |
|---|---|
| 정리된 폴더 (`깃허브`, `팀프로젝트`, `개인프로젝트`, `실습`, `강의자료`, `발표`, `졸업시험`, `기록`) | 제외 목록 |
| 바로가기(`.lnk`, `.url`) | 앱 아이콘 |
| 다운로드 중인 파일, 오피스 임시 파일(`~$`) | 아직 완성되지 않음 |
| 5분 안에 수정된 파일 | 작업 중일 수 있음 → 다음 날 정리 |
| 다운로드의 설치 파일(`.exe`, `.msi` 등) | 설치용이라 남김 |
| 사용 중이라 못 옮긴 항목 | 다음 실행 때 다시 시도 |

- 아무것도 지우지 않습니다. 같은 이름이 있으면 `이름 (2)`로 바꿔서 옮깁니다.
- 자모가 분리된 한글 파일 이름(웹에서 받은 파일에서 생김)은 일반 형태로 맞춰서 비교·저장합니다.

## 2. 분류 규칙

파일·폴더 **이름에 키워드가 들어 있으면** 그 폴더로 보냅니다. **위에서부터 먼저 맞는 규칙 하나만** 적용합니다. `{날짜}`는 그날 날짜(`MMDD`)로 바뀝니다.

| 순서 | 키워드 | 보내는 곳 |
|---|---|---|
| 1 | 버틴집, 버팀지수, 생존배수, 폐업, 자동판정, 인허가, 상가정보, 조원, 동네가먹여살린가게, 팀플, 팀프로젝트, 4P-, 식품_, 상권, 소상공인, 3단계 | `팀프로젝트\09_기록\{날짜}` |
| 2 | 개인, 이재훈, 여행객, 한끼, 추천지도, 로컬맛집, 대구10미, 안지랑, 페르소나, 먹거리골목, 찐 맛집 | `개인프로젝트\{날짜}` |
| 3 | 졸업시험, 해설, 게시용 | `졸업시험` |
| 4 | 발표, 성과공유회, `.pptx` | `발표` |
| 5 | 강의, 매뉴얼, 개방데이터, 한국관광공사, 정의서 | `강의자료` |
| 6 | 대구로페이, 대구사랑상품권, 행복페이, 지역사랑상품권, 정보공개, 결정통지서, 연구 2026, 과제 | `실습\{날짜}과제` |
| 7 | 고객여정, 밸류체인, 경제정책관, 온누리, redteam, 실습, `.py`, `.ipynb` | `실습\{날짜}실습` |
| 8 | Day0, Day1 (수업 PDF) | `강의자료` |

### 규칙을 이렇게 정한 이유

- **팀 프로젝트(버틴집)와 개인 프로젝트(대구 로컬 음식점 추천 서비스)를 구분**하려고, 한쪽에서만 쓰는 단어만 넣었습니다.
- 두 프로젝트가 같이 쓰는 단어(**대구, 음식점, 맛집, 업력, 프랜차이즈, 기획서**)는 일부러 넣지 않았습니다.
- 팀 규칙이 맨 위라서 `폐업_개인메모.txt`처럼 둘 다 걸리면 팀프로젝트로 갑니다.
- `Day`만 쓰면 today·birthday 같은 영어 이름에도 걸려서 `Day0`, `Day1`로 좁혔고, 다른 규칙보다 뒤에 둡니다.
- `.csv`, `.xlsx`, `.pdf`, `.md`는 어디에나 있어서 확장자 규칙을 두지 않았습니다.

## 3. 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 지금 바로 정리 | `바탕화면\기록\지금 정리하기.cmd` 더블클릭 |
| 규칙 추가·수정 | `정리도구\분류규칙.txt`에 `키워드 = 폴더` 한 줄씩 |
| 옮기지 않을 폴더 추가 | `정리도구\제외목록.txt`에 이름 한 줄씩 (바탕화면에 정리용 폴더를 새로 만들면 꼭 추가) |
| 무엇이 언제 옮겨졌는지 | `정리도구\정리기록.log` |
| 실행 시간 바꾸기·끄기 | 작업 스케줄러 → "바탕화면 날짜별 정리" |
| 옮기지 않고 미리보기 | `정리.ps1 -DryRun` |

## 4. 깃허브 `이재훈` 브랜치 규칙

- 최상위는 **날짜 폴더(`MMDD/`)**
- 같은 날 한 작업은 그 날짜 폴더 안에 **종류별 하위 폴더**로 (`실습/`, `자료정리/`, `내용정리/`, `팀프로젝트/`, `과제/`, `파일정리/` 등)
- 날짜와 상관없는 것은 `개인프로젝트/`, `발표/`
- 폴더를 옮기면 문서 안 링크도 함께 고치고, README 목차를 갱신
