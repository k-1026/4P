## 1. 정리 원칙

| 원칙 | 내용 |
|---|---|
| 폴더 이름 | 번호(`01_`) 없이 짧은 이름으로 통일 |
| 날짜 이름 | 실습·과제 폴더는 작업을 시작한 날짜 `MMDD` + 이름 (예: `1111실습`, `1030과제`) |
| 지우지 않기 | 파일은 옮기기만 하고 지우지 않음. 지운 것은 휴지통으로 |
| 경로 함께 고치기 | 폴더를 옮기면 바로가기·즐겨찾기·문서 안 링크도 새 경로로 고침 |

## 2. 바탕화면 최종 구조

```
바탕화면
├─ 깃허브        깃허브와 연결된 git 프로젝트 (4P, K-뉴딜, qwer, 이재훈, my-project)
├─ 팀프로젝트    버틴집(폐업 판정) 작업 폴더, 받은 자료는 09_기록\MMDD
├─ 개인프로젝트  개인 기획(대구 로컬 음식점 추천 서비스) 자료, MMDD별
├─ 실습          수업 실습·과제 (1027과제 ~ 1112실습2)
├─ 강의자료      수업 PDF(Day02~Day14), 참고 매뉴얼
├─ 발표          발표 자료(pptx, 발표용 html·pdf)
├─ 졸업시험      졸업시험 문제·정답
└─ 기록          그날 새로 생긴 파일이 모이는 곳 (MMDD), 규칙에 안 맞는 파일이 남음
```

- 최상위에 섞여 있던 날짜 폴더를 **날짜 폴더가 맨 위**인 구조로 정리
- 같은 날 한 작업은 한 날짜 폴더 안에 종류별로 (`1109/실습`, `1109/자료정리` 등)
- 날짜와 상관없는 것은 `개인프로젝트/`, `발표/`
- 문서 안 경로·링크를 모두 새 위치로 고침 (링크 89개 확인, 깨진 링크 0개)
