# 리스크 점검 — team-demo (수업 예시 · 가상 데이터)

대상: opportunity_matrix.csv 에서 임팩트 · 실현성 평균이 모두 3.5 이상인 기회 (O1 · O2 · O3).
판정: 해당 없음 / 조건부 통과(조건 한 줄) / 막힘.

| 기회 | 개인정보 | 저작권 | 편향 | 책임 소재 |
|---|---|---|---|---|
| O1 매대 정보 카드 | 조건부 통과 — 상인 사진에 손님 얼굴 · 계좌번호가 찍히면 게시 전에 가림 | 해당 없음 — 상인이 직접 찍은 사진 | 조건부 통과 — 입력을 자주 하는 매대만 눈에 띄지 않게 정렬 기준을 공개 | **미정** — AI가 정리한 정보가 틀렸을 때(예: "카드 가능"이라고 떴는데 현금만) 누가 확인하고 고치는지 정하지 못함 |
| O2 운영 정보 대조 | 해당 없음 | 조건부 통과 — 블로그 글은 본문을 저장하지 않고 운영일 · 시간만 뽑아 씀. 지도 앱 약관은 **확인 전** | 해당 없음 | 조건부 통과 — 수정 요청문은 상인회 사무국이 확인한 뒤 발송 |
| O3 대기 · 품절 예측 | 조건부 통과 — 방문객 위치 정보는 쓰지 않음 | 해당 없음 | 조건부 통과 — 예측이 빗나가면 한산한 매대가 손해. 예측값에 "추정" 표시 | 조건부 통과 — 품절 표시는 상인이 직접 누른 값만 확정으로 표시 |

사용 데이터 경로: research/data/sources.md (D1~D5)

## 메모
- O1 의 책임 소재는 "상인 본인이 확인" 과 "상인회 사무국이 확인" 두 안이 있었으나 결론을 내지 못하고 Top 3 에 올림.
