# AX 아이디어 Top 3 — team-demo (수업 예시 · 가상 데이터)

트랙: AX 데이터 · 서비스. 숫자와 기관은 모두 수업용 가상 설정.

## 1위 · 야시장 오늘의 매대판 ← 캔버스 대상

| 항목           | 내용                                                                                                                                   |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 잡 스토리      | J1 — 여러 매대 음식을 사려고 줄을 설 때, 그 매대에서 되는 결제 수단을 줄 서기 전에 알고 싶다, 그래서 줄을 다시 서지 않도록 (+ J2 · J3) |
| 단계 × 역량    | 안내 × 자동화 + 생성 (O1)                                                                                                              |
| AI가 하는 일   | 상인이 올린 매대 사진 1장 · 한마디(음성 또는 글)에서 결제 수단 · 오늘 영업 여부 · 품절 메뉴를 뽑아 매대 정보 카드로 정리               |
| 사람이 하는 일 | 상인이 장사 시작 전에 사진 · 한마디를 올림. 게시 전에 누가 확인하는지는 미정                                                           |
| 필요 데이터    | 매대 정보 입력(D5 · 서비스 운영 후 생김) · 상인회 운영 공지(D2)                                                                        |
| 점수 · 리스크  | 임팩트 4.5 · 실현성 4.0 · 책임 소재 미정(risk_check.md)                                                                                |
| 성공 신호      | 방문객이 줄 서기 전에 매대판을 열어 봄. 리뷰의 결제 실패 언급이 줄어듦                                                                 |
| AI 생성 표시   | 카드마다 "AI 정리 · 상인 입력 hh:mm 기준"                                                                                              |
| 돈             | 야시장 상인회가 매대 1곳당 월 1만 원을 낼 것. 매대 80곳이면 월 80만 원                                                                 |

## 2위 · 운영 정보 대조 알림

| 항목           | 내용                                                                                                                |
| -------------- | ------------------------------------------------------------------------------------------------------------------- |
| 잡 스토리      | J3 — 방문 날짜를 정할 때, 오늘 야시장과 가려는 매대가 여는지 한 번에 확인하고 싶다, 그래서 헛걸음하지 않도록 (+ J4) |
| 단계 × 역량    | 안내 × 에이전트 (O2)                                                                                                |
| AI가 하는 일   | 지도 앱 · 블로그 · SNS 의 운영일 · 시간을 모아 상인회 공지와 대조하고, 다른 곳의 수정 요청문 초안 작성              |
| 사람이 하는 일 | 상인회 사무국이 수정 요청문을 확인하고 발송(승인 지점)                                                              |
| 필요 데이터    | 상인회 운영 공지(D2) · 외부 운영 정보 수집(D3)                                                                      |
| 점수 · 리스크  | 임팩트 4.3 · 실현성 3.5 · 저작권 조건부(지도 앱 약관 확인 전)                                                       |
| 성공 신호      | 외부 채널의 틀린 운영 정보 건수가 줄어듦                                                                            |
| AI 생성 표시   | 수정 요청문에 "AI 초안 · 사무국 확인"                                                                               |

## 3위 · 대기 · 품절 미리 보기

| 항목           | 내용                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 잡 스토리      | J5 — 인기 매대 앞에 줄이 길 때, 얼마나 기다릴지 미리 알고 싶다, 그래서 기다릴지 다른 매대로 갈지 줄 서기 전에 정하도록 (+ J6) |
| 단계 × 역량    | 방문 · 둘러보기 × 예측 (O3)                                                                                                   |
| AI가 하는 일   | 매대 입력 기록과 요일 · 방문객 수로 대기 시간 · 품절 예상 시각을 추정                                                         |
| 사람이 하는 일 | 상인이 "품절" 버튼을 직접 누름(확정값). 예측값은 "추정"으로만 표시                                                            |
| 필요 데이터    | 매대 정보 입력(D5) · 야시장 방문객 수(D4)                                                                                     |
| 점수 · 리스크  | 임팩트 4.0 · 실현성 3.5 · 편향 조건부                                                                                         |
| 성공 신호      | 품절 허탕 리뷰가 줄어듦                                                                                                       |
| AI 생성 표시   | "AI 추정 · 실제와 다를 수 있음"                                                                                               |

## 순위 이유

- 1위는 임팩트 · 실현성 합이 가장 높고(8.5), P1(점수 60)을 직접 줄이며, 11/16 MVP 로 화면 하나(매대 카드 목록)를 보여 줄 수 있음.
- 2위는 외부 데이터 수집 권리 확인이 남아 있어 한 단계 내림.
- 3위는 1위의 입력 기록(D5)이 쌓여야 가능하므로 1위 다음 순서.
