야시장 오늘의 매대판 — BM 캔버스 (v1, 결정 항목 포함)
확인값 · 가정값 · 결정 표기 기준 (수업용 가상 데이터)

8핵심 파트너

  • 야시장 상인회
  • 입력 안내 · 게시 확인 · 신고 접수 창구
  • 상인회 사무국 (게시 전 확인 담당, 결정)
근거: 사용자 메모, 설문조사

7핵심 활동

  • ① 상인 정보 입력 안내 ○ AI 보조
  • ② AI가 결제 수단 · 영업 · 품절을 카드로 정리 ◎ AI
  • ③ 게시 전 확인 ○ AI 보조
  • ④ 신고 접수 후 수정 ○ AI 보조

6핵심 자원

  • 매대 정보 카드 자동 정리 AI
  • 상인 입력 데이터 (D5, 운영 후 생김)
  • 상인회 운영 공지 (D2)
  • 사무국 수정 기록 결정

2가치 제안

  • 결제 수단 표시 → P1 직접 해결
  • 오늘 영업 여부 표시 → P2 직접 해결
  • 품절 메뉴 표시 → P3 부분 해결 (대기 시간 제외, 결정)
  • 방문 전 매대 카드 화면에서 확인
근거: painpoint/painpoint_def.md, 교차 확인 결과

4고객 관계

  • 틀린 정보를 신고하면 접수 후 수정하는 신고형 관계

3채널

  • 야시장 입구 안내판
  • 매대별 QR 코드

1고객 세그먼트

  • 방문객 — 현금 없이 방문한 구매자 (직장인 · 주말 가족 · 관광객)
  • 지불자 — 야시장 상인회
근거: painpoint_def.md, 사용자 설문조사

9비용 구조

  • 상인 입력 안내 인건비: 월 40시간 → 48만 원 가정값
  • 게시 전 확인 인건비: 월 20시간 → 24만 원 가정값
  • AI 처리 비용 — 미정
  • 인건비 합계: 월 72만 원 가정값 (시급 12,000원 가정)

5수익원

  • 상인회 정액 구독: 매대 1곳당 월 5천~1만 원 가정값
    사용자 설문 보고, 원자료 미확인
  • 기준값 월 7,500원 × 매대 80곳 = 월 60만 원 가정값
  • 손익(80곳): -12만 원 가정값
  • 손익분기: 96곳 (7,500원) · 72곳 (1만 원) 가정값
제외: 상단 노출 광고 (편향 리스크) · 매대 등록비 · 보류: 방문객 유료 알림 · 상권 데이터 판매
