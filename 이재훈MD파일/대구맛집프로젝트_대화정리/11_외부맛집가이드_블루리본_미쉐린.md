> 대화 날짜: 2026-10-30 (오전 10시 40분~11시경, 대화 2개)
> 표기: **[사용자]** = 사용자가 직접 말한 의견·조건, **[AI 제안]** = AI(Aside)가 제안한 내용

## 배경과 목적

- 팀 사이트 '동네가 먹여살린 가게'의 출처 문서에는 '빠진 기준'으로 블루리본("공개 데이터 없음, 자동 수집 차단")과 미쉐린 가이드("한국은 서울·부산만 발간")가 적혀 있어요.
- [사용자] 팀 표(서비스 / 공개 데이터 여부 또는 대구 수록 여부 / 도메인 / URL)의 두 항목을 검증해 달라고 했어요.

```
| 블루리본 | 공개 데이터 없음 | bluer.co.kr | https://www.bluer.co.kr |
| 미쉐린 가이드 (한국은 서울·부산만) | 대구 없음 | guide.michelin.com | https://guide.michelin.com/kr/ko |
```

**사용자가 정한 조사 조건 [사용자]**
- 공개 API·다운로드 데이터가 없는 것과 웹에서 열람할 수 없는 것을 **구분**
- 확인하지 못한 내용은 추측하지 말고 **'확인 필요'**로 표시
- 공개 페이지부터 조사하고, 로그인이 꼭 필요하면 이유와 확인 항목을 설명한 뒤 "이 항목을 확인하려면 ○○ 계정 로그인이 필요합니다. 사용 가능한 계정이 있으신가요? 있으시면 사이트에서 직접 로그인해 주세요."라고 묻기
- **아이디·비밀번호를 채팅에 입력하도록 요구하지 않기.** 사용자가 직접 로그인
- 근거 링크와 함께 요약하고 표 수정 문구 제안
- (미쉐린) 확인 기준일과 가이드 발행 연도 명시, 공식 선정과 기사·여행 콘텐츠 속 등장을 구분

## 핵심 논의

### 1. 블루리본

**"공개 데이터 없음" 검증:** API·다운로드가 없다는 뜻으로는 맞지만 표현이 부족해요. 웹 열람은 돼요.
| 구분 | 결과 |
|---|---|
| 공개 API·다운로드 | 없음 (사이트맵, 약관, FAQ, 웹 검색 어디에도 없음) |
| 웹 열람 | 가능. 비로그인은 범위가 좁음 |
| 기술적 제한 | robots.txt가 ClaudeBot, GPTBot 등 AI 봇과 python-requests, scrapy, curl, wget 차단. 짧은 시간에 15페이지 정도 열자 429(Too Many Requests) |

**로그인 관련:** 브라우저가 이미 블루리본 **무료 회원 계정으로 로그인**돼 있어서 따로 요청하지 않고 읽기만 했어요. 비로그인 화면은 쿠키 없이 불러와 비교했어요.

**이용 단계별 차이**
| 항목 | 비로그인 | 무료 로그인 (직접 확인) | 프리미엄 (유료) |
|---|---|---|---|
| 블루리본 맛집 목록 (`/search?ribbon=true`) | 로그인 페이지로 이동 | 볼 수 있음 | 볼 수 있음 |
| 식당 상세 (`/restaurants/번호`) | 로그인 페이지로 이동 | 볼 수 있음 | 볼 수 있음 |
| 통합검색 | 추천 맛집 랜덤 일부만 | 검색·페이지 이동 가능 | 볼 수 있음 |
| 멀티 필터, 지도 보기 | 불가 | 지도 누르면 프리미엄 안내 | 가능 (사이트 안내 기준) |
| 리뷰 | 불가 | 일부만 (예: 10건 중 4건) | 모든 콘텐츠 열람 (사이트 안내 기준) |
- 프리미엄 요금: 1개월 3,300원, 6개월 6,600원, 1년 11,000원 (부가세 포함)

**볼 수 있는 정보 (무료 로그인)**
- 음식점명(상세에 영문명도), 주소(도로명, 법정동, 층), 리본 개수(아이콘), 선정 연도("서울 2027 선정", "전국 2026 선정" 배지, 상세에 "<블루리본 서베이: 서울의 맛집> 2027년판에 수록"), 음식 종류, 레드리본 여부, 메뉴·가격, 전화, 영업시간, 주차, 홈페이지, 개업일, 소개문
- 지역 칸은 따로 없고 주소와 "서울편/전국편" 배지로 구분. 검색에 지역선택 필터 있음
- 리본별 건수: 전체 5,326 / 리본3 46 / 리본2 473 / 리본1 2,216 / 리본0 2,563 / 주목할 만한 새 맛집 28 / 평가를 기다리는 곳 23,774 (같은 화면에 "총 5,329개" 문구도 있어 조금 다름)

**대구 지역 구분 (사용자 추가 질문)**
- [사용자] "내가 확인했을 때는 대구에 지역별로 나누어져 있던데 그 데이터는 못 받아?"
- [지역 모두 보기](https://www.bluer.co.kr/search/zone) 화면 기준: **대구 전체 1,149곳**
  - 군위군 5, 남구 79, 달서구 173, 달성군 53, 동구 116, 북구 112, 서구 27, 수성구 264, 중구 139
  - 중구 세부: 동성로 97, 동인동 40, 종로 44
  - 목록 링크 예: 중구(동성로) https://www.bluer.co.kr/search?query=&zone=5003 , 수성구 https://www.bluer.co.kr/search?query=&zone=5005
- 이건 검색 필터 화면일 뿐 다운로드 데이터가 아니에요. 화면 내용을 표로 옮기는 것도 약관상 사전 서면 허가가 필요해서 AI가 대신 수집하지 않았어요.

**이용약관 (2026.8.10 시행)**
- **제18.1조:** 사전 서면 허가 없이 데이터를 뽑기 위해 봇·크롤러·매크로 같은 자동화 수단이나 **수동 프로세스**로 콘텐츠를 모니터링·복제·수집·정리·사용 금지. 회원가입·기업회원 가입·유료 이용권은 허가로 보지 않음
- 제18.4조: AI 학습은 공익·비영리 목적을 밝히고 사전 서면 허가 필요(거절 가능)
- 제18.5~18.6조, 제9.4조: 위반 시 형사고소, 크롤링 금지 청구, 손해배상, 계정 영구 차단
- 제15.3조, 제11.1.12조: 영리 목적 복제·배포 금지, 매장 정보·사진·리뷰를 동의 없이 쓰는 것도 금지
- 기업회원 약관 제20조에도 같은 크롤링 금지 조항
- 크롤링 금지 공지: "데이터 활용이 필요한 경우 반드시 공식적인 절차를 통해 승인을 받으라"
- 제휴 공급 사례: 캐치테이블(2026 공식 파트너, 앱 블루리본 탭), 레드리본 리스트를 네이버 지도·카카오맵 저장 목록으로 배포

### 2. 미쉐린 가이드

**확인 기준일:** 2026년 10월 30일 / **기준 에디션:** 미쉐린 가이드 서울 & 부산 2026 (2026년 3월 5일 발표)

**'한국은 서울·부산만', '대구 없음' 검증: 지금도 맞아요.** 다만 호텔은 예외라서 "한국 **레스토랑** 셀렉션은 서울·부산만"이 정확해요.
- 2026 에디션: 총 233곳 (서울 178, 부산 55). 2016년 '서울 2017' 첫 발간, 2024년부터 부산 포함. 대구 확장 공식 발표는 없음
- 현재 사이트 한국 목록 237곳: 3스타 1, 2스타 10, 1스타 35, 빕 구르망 71, 선정 레스토랑 120 (발표 후 늘어난 4곳은 모두 '선정 레스토랑')
- 사이트에서 '대구', 'Daegu' 검색 → "검색한 지역에는 선정된 레스토랑이 없습니다"
- 2026 미쉐린 키 호텔은 서울, 인천, 부산, 제주, 충주. 호텔 검색에서 Daegu도 선정 없음

**공식 선정과 '미쉐린' 홍보 구분**
- 대구 소재 음식점은 스타·빕 구르망·선정 레스토랑 모두 **0곳**
- 헷갈리는 사례(공식 선정 아님): 부산 선정점의 대구 지점(융캉찌에 대구직영점, 해목 신세계 대구점. 공식 목록에는 부산 매장만. 선정은 매장 주소 단위), "미쉐린 출신 셰프", "대구 미슐랭 레스토랑으로 부르는" 같은 홍보 문구

**확인할 수 있는 정보 (웹 열람)**
| 항목 | 열람 | 비고 |
|---|---|---|

- 공개 API 없음 (미쉐린 개발자 포털에는 타이어·물류 API만. 로그인 후에만 보이는 가이드 API가 있는지는 **확인 필요**). 다운로드 데이터 공식 경로 없음

**약관 (한국어 이용약관 V.2, 2022년 2월)**
- 자료는 개인·비영리 용도로만 조회·출력·이용
- 로봇·스파이더·자동 장치나 수동 공정으로 콘텐츠 모니터링·복사 금지

- 데이터만 따로 신청하는 공식 창구는 없어요. 문의 양식으로 데이터 이용 허가(라이선스)를 요청하는 것뿐이고, 허가 여부·조건·비용은 **확인 필요**
- 문의 양식: https://guide.michelin.com/kr/ko/contact-us ("I am..." → 기타(후원자, 기자, 지원자...), 제목 → 기타(리셀러, 파트너, 관리, 기자 등), territory → South Korea)

- 공식 2026 보도자료에는 등급별 개수와 일부 소개만 있고 전체 목록은 없음
- **대구는 0곳이라 허가를 받아도 대구 분석에는 도움이 안 돼요.** 서울·부산 비교나 '미쉐린' 홍보 매장 걸러내기에만 의미가 있어요.

- 미쉐린은 "대구는 미수록"이라고 표기만 할 거라면 신청 불필요. 공식 발표 수치(서울 178, 부산 55) 인용과 링크로 충분
- 미쉐린은 데이터 소스가 아니라 맥락 설명이나 블로그·기사 속 '미쉐린' 표기를 걸러내는 기준으로만 사용

## 보류·제외한 방안과 이유

- **블루리본 대구 데이터 수집(자동이든 수동이든)** → 약관 제18.1조, 사전 서면 허가 필요. AI가 대신 수집하지 않음
- **블루리본 프리미엄 정보 확인** → 이용권 구매가 필요해서 진행 안 함. 이용권 있는 계정으로 사용자가 직접 로그인하면 이어서 확인 가능
- **미쉐린 데이터 라이선스 신청** → 대구 0곳이라 대구 분석에 실익 없음 (서울·부산 비교 등에만 의미)
