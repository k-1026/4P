## 핵심 논의

AI가 링크 26개를 전부 열어보고, 원본 파일 10개를 받아서 사이트 숫자와 맞춰봤어요. 큰 문제는 없었지만 발표 전에 고치거나 말을 맞춰둘 부분이 나왔어요.

### 1. 발표 전에 고치면 좋은 것 (AI 점검 결과)
1. **전체 음식점 수 불일치:** 문서 39,867곳, 사이트 화면과 기준 데이터 표는 **39,862곳**
2. **착한가격업소 숫자가 두 개:** 버튼은 499곳, 기준 데이터 표는 "명단 500곳 중 500곳 연결". 원본 파일은 615건(미용실·세탁소 포함)이고 음식 업종이 정확히 500건. 중복으로 합쳐져 499가 된 것으로 추정
3. **위생등급 15곳 차이:** 2,459곳 중 2,400곳 연결, 편의점 42곳 빼면 2,358곳이어야 하는데 사이트는 2,343곳
4. **달서맛나 파일에는 모범음식점이 0곳:** 설명은 모범·안심·나트륨 세 종류지만 실제 223곳은 안심음식점 214곳 + 나트륨줄이기 음식점 9곳. "달서구 모범음식점 223곳"이라고 하면 틀리고 "구청 지정"이 정확
5. **중구 맛집 현황은 오래되고 섞인 자료:** 기준일 **2020-01-14**. 147곳 중 36곳은 분류가 '모범음식점'뿐(묵은맛명가·맛락·골목투어 아님). 이 파일에 중구 모범음식점 55곳이 있어서 "중구는 모범음식점 공개 명단 없음"은 사실과 다름
6. **"나머지 구·군은 공개 명단 없음"은 질문받을 수 있음:** 대구푸드 '구군별인증업소' 페이지에 9개 구·군 905곳 공개 (서구 54, 북구 95, 달성군 89, 군위군 0). "공공데이터포털에 파일이 없음"으로 좁혀 말하는 게 안전

### 2. 작은 수정
- **지도 경계:** southkorea-maps는 2013년 통계청 경계라 군위군(2023년 대구 편입)이 경북 소속이에요. "군위군은 편입 반영해 따로 붙임" 같은 메모 권장
- **대구 10미 링크:** 홈 대신 10미 소개 페이지가 정확해요 → https://www.daegufood.go.kr/kor/food/10mi_info.asp?snm=157 (10가지 목록은 공식과 동일)
- **달서구 15084548:** 이름은 '식품접객업소 현황'이고 일반·휴게음식점·제과점이 다 있어요. "(휴게음식점)"은 그중 휴게음식점만 썼다는 뜻으로 읽히게
- **수성구 모범음식점:** D-데이터허브 기준일 2025-12-18. 45곳은 파일을 못 받아 **확인 필요**
- **분류 표시:** 동인동 찜갈비집이 '돼지고기 구이/찜'으로 떠요(동인동 찜갈비는 소갈비). 상가정보 분류를 그대로 가져와서 생긴 문제
- **합계가 조금 작은 이유:** 모범·구청 지정 57+46+45+223=371인데 사이트는 368, 구청 추천 147+52+32+44=275인데 272. 같은 가게가 겹친 것으로 보임 (달서맛나 안 동명 2개, 남구 먹거리골목끼리 1곳 겹침)
- 남구 모범 파일은 파일명이 20250919인데 데이터 기준일은 2026-09-19였어요.

### 3. 확인 결과 맞는 것
- data.go.kr 링크 17개 모두 열리고 제목·날짜가 맞아요 (상가정보 20260630, 착한가격 20261001, 백년가게 20260820 등)
- 원본 건수 일치: 남구 모범 57, 동구 모범 46, 중구 맛집 147, 안지랑 52, 앞산카페거리 32, 앞산맛둘레길 44
- 백년가게: 대구 주소 83곳 = 음식점 60 + 비음식점 23
- 20년 이상 영업: 남구 파일에 인허가일자 칸이 있어요. 일반·휴게·제과 중 2006-10-29 이전 인허가를 대충 세면 579곳 (사이트 566곳과 비슷)
- 식품안심업소: 대구푸드 목록 실제 2,459곳
- LOCALDATA: 자동 접속 시 403 (문서 그대로)
- 미쉐린: 2026 에디션은 서울 178곳, 부산 55곳만 선정
