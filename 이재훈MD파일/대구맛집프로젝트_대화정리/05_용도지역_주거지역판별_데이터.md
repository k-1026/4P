# 용도지역 데이터로 점포의 주거지역 입지 판별

> 대화 날짜: 2026-10-29 (오후 4시 40분경)
> 표기: **[사용자]** = 사용자가 직접 말한 의견·조건, **[AI 제안]** = AI(Aside)가 제안한 내용

## 배경과 목적

- 대구 맛집 지도(버틴집) **2단계 분석**에서 점포 좌표가 **주거지역 안에 있는지** 판단하려고 해요.
- 팀 출처 표 4번 행: 용도지역지구 정보 / 제공처 후보: 국토교통부·국가공간정보 관련 공식 서비스 / 데이터셋명과 URL: 확인 필요 / 필요 항목: 용도지역 구분, 구역 경계
- [사용자] 정확한 데이터셋명, 제공기관, URL, 형식, 좌표계, 이용 방법을 알려 달라고 했어요. 특히 점포 위경도와 대조할 수 있는 **폴리곤 경계 데이터**가 있는지, 주거지역 세부 구분과 판별 방법, 주소 조회만으로 판단할 때의 한계도 물었어요.

## 핵심 논의

### 1. 후보 데이터
경계 폴리곤 데이터가 있어요. 다만 대구 파일은 브이월드 로그인이 필요해서 **실제로 받아서 열어보지는 못했어요.** 아래는 공개 명세와 메타데이터 기준이에요.

| | ① 브이월드 SHP (추천) | ② 브이월드 WFS/WMS API | ③ 토지이음 SHP |
|---|---|---|---|
| 정확한 이름 | (연속주제)\_국토계획/도시지역, 파일명 `LSMD_CONT_UQ111_대구.zip` | 국토교통부\_용도지역지구정보(WMS/WFS), 레이어 `lt_c_uq111` | (도시계획)용도지역정보 |
| 제공 | 국토교통부, 브이월드 | 국토교통부 국가공간정보센터 (data.go.kr 15123895, 실제 호출은 브이월드) | 국토교통부, 토지이음 |
| URL | vworld.kr/dtmk/dtmk_ntads_s002.do?dsId=30300&svcCde=MK | api.vworld.kr/req/wfs | eum.go.kr 정보마당 > 데이터개방 |
| 형식 | 시도별 SHP 폴리곤. 갱신일 2026-10-15, 대구 4,538KB | GML, JSON | 전국 SHP·CSV, 매월 갱신, 최신 2026-09-29, 약 975MB |
| 좌표계 | GRS80 TM중부(EPSG:5186), Bessel TM중부(EPSG:2097). 목록에 '\_5174'가 붙은 시도 파일도 따로 있음 | 4326, 5186, 5179, 3857 등 선택 | Bessel 중부(EPSG:5174) |
| 받는 조건 | 브이월드 회원 로그인 (무료) | 브이월드 인증키 | 공개 |
| 라이선스 | CC BY-NC-ND (영리 이용·변경 불가) | data.go.kr 표기는 '이용허락범위 제한 없음' | 공공누리 출처표시 (자유 이용) |

- **분석용:** ① 추천. 대구 파일만 4.5MB로 가볍고, 우리 데이터에 원본 좌표(EPSG:5174)가 있어서 잘 맞아요.
- **서비스에 지도를 올릴 때:** 영리 목적이면 ①의 CC BY-NC-ND가 걸릴 수 있어요. 그때는 ③이 안전해요.
- **②:** 한 번에 최대 1,000개 피처까지라, 점포 수만 곳을 하나씩 조회하기보다 파일이 나아요.

**속성 필드** (브이월드 WFS 컬럼정보 엑셀로 확인)
- `ucode` (용도코드), `uname` (용도지역명)
- `sido_name`, `sigg_name`, `dyear`/`dnum` (고시년도·번호), `mnum` (관리번호)
- `ag_geom` (폴리곤)
- SHP 파일 컬럼명도 같을 가능성이 높지만 **확인 필요**예요.

### 2. 주거지역 세부 구분과 코드
국토계획법 시행령 제30조의 구분이고, 코드는 행정표준코드 기준이에요.

| 코드 | 구분 | 성격 |
|---|---|---|
| UQA111 / UQA112 | 제1종 / 제2종 전용주거 | 단독주택 / 공동주택 중심의 양호한 주거환경 |
| UQA121 / 122 / 123 | 제1·2·3종 일반주거 | 저층 / 중층 / 중고층 주택 |
| UQA130 | 준주거 | 주거 위주에 상업·업무 기능 일부 허용 |
| UQA100 / 110 / 120 | 주거 / 전용 / 일반 (세분 안 된 값) | 따로 표시해 둘 것 |
| UQA2xx / 3xx / 4xx | 상업 / 공업 / 녹지 | 주거지역 아님 |

- **판별 규칙 [AI 제안]:** `ucode`가 `UQA1`로 시작하면 주거지역. 준주거(UQA130)는 따로 떼서 보기. 법적으로는 주거지역이지만 실제로는 상가가 늘어선 곳이 많아서예요.

### 3. 판별 방법 [AI 제안]
1. 브이월드 로그인 후 `LSMD_CONT_UQ111_대구.zip` 다운로드. '\_5174'가 붙은 대구판이 있으면 그걸 받기 (대구판이 실제로 있는지는 **확인 필요**)
   - 10/28에 만든 대구 음식점 CSV에 원본 좌표(`X_5174`, `Y_5174`)가 있어요. 같은 좌표계 파일과 바로 맞추면 변환 오차 15~20m를 피할 수 있어요.
   - 받은 뒤 `.prj` 파일로 실제 좌표계를 꼭 확인
2. 점포 좌표가 어느 폴리곤 안에 있는지 판정: QGIS '위치로 속성 결합' 또는 Python GeoPandas `sjoin(predicate="within")`
3. **경계선에서 10m 안쪽 점포는 '경계'로 따로 표시.** 대로변에 상업지역이 띠 모양으로 지정된 곳이 많아서 좌표가 몇 m만 틀려도 결과가 바뀌어요.
4. 어느 도시지역 폴리곤에도 안 들어가면 관리·농림지역일 수 있어요. 관리지역(`lt_c_uq112`), 농림지역(`lt_c_uq113`) 레이어로 따로 확인

### 4. 주소 조회만으로 판단할 때의 한계
토지이음 열람이나 필지(PNU)별 토지이용계획 조회 방식의 문제예요.
- **한 필지에 용도지역이 두 개:** "일반상업지역, 제2종일반주거지역"처럼 둘 다 나와서 점포가 어느 쪽인지 모름
- **도로명주소와 지번이 1:1이 아님:** 여러 필지에 걸친 건물이나 집합건물은 대표 지번 하나로만 조회
- **글자 정보만 나옴:** 경계까지 거리, 상업지역 바로 옆인지 같은 위치 관계를 볼 수 없음
- **조회량:** 2만 9천여 곳을 하나씩 조회해야 해서 호출 제한에 걸리기 쉬움

좌표 방식의 한계도 있어요.
- 인허가 좌표 정확도에 따라 결과가 달라져요.
- 좌표 없는 점포(중구 표본 기준 약 6%)는 판정할 수 없어요.
- 지구단위계획이 걸린 곳은 같은 용도지역이어도 실제 허용 용도가 다를 수 있어요.

## 확정한 사항

- 공식 폴리곤 경계 데이터가 있어요 (브이월드 SHP, WFS, 토지이음 SHP).
- 주거지역 코드는 `UQA1xx` 계열이에요.
- 데이터 선택과 판별 규칙은 **사용자가 아직 확정하지 않았어요.**

## 보류·제외한 방안과 이유

- **주소(필지) 조회 방식** → 한 필지 두 용도지역, 지번 1:1 불일치, 위치 관계 불명, 호출량 문제
- **WFS API로 점포별 조회** → 한 번에 1,000개 피처 제한, 수만 곳 조회에 비효율
- **브이월드 SHP를 영리 서비스 지도에 사용** → CC BY-NC-ND 라이선스 문제 가능
