# 프랜차이즈 식별 (공정위 가맹정보, 대구 로컬 체인)

> 대화 날짜: 2026-10-29 (오후 2시 50분경 대구 로컬 체인 확인, 오후 4시 30분경 공정위 API 명세 확인)
> 표기: **[사용자]** = 사용자가 직접 말한 의견·조건, **[AI 제안]** = AI(Aside)가 제안한 내용

## 배경과 목적

- 대구 맛집 지도(버틴집)는 "오래 영업한 동네 가게"를 찾는 지도예요. 업력 상위권에 체인점이 섞이면 취지와 맞지 않아요.
- [사용자] 1단계 분석 대상에서 **프랜차이즈 점포를 제외**하고 싶다고 했어요.
- [사용자] "대구 프렌차이즈도 있을 수 있잖아. **대구만 있는 막창 프렌차이즈**나"라고 지적했어요.
- 팀 출처 표의 3번 행: 가맹정보 정보공개서 조회 / 공정거래위원회 / https://data.go.kr/data/15125570/openapi.do / 필요 항목 브랜드명

## 핵심 논의

### 1. 대구 로컬 체인 실태 (10/29 오후 2시 50분경)
대구 영업 중 일반음식점 29,277곳(10/28 수집 데이터)에서 같은 상호가 5곳 이상인 경우를 뽑아, 공정위 가맹사업거래 사이트(franchise.ftc.go.kr)에서 정보공개서 등록 여부를 하나씩 검색했어요.

| 대구 반복 상호 | 대구 영업 중 | 공정위 등록 |
|---|---|---|
| 태영생막창 | 21곳 (7개 구) | **없음** |
| 오빠막창 | 7곳 | **없음** |
| 황금막창, 고향숯불막창 | 각 5곳 | **없음** |
| 정하용선산곱창 | 6곳 | **없음** |
| 청도추어탕 | 21곳 | **없음** |
| 막창도둑 | 10곳 | 있음 (2015 등록) |
| 대구반야월막창 | 7곳 | 있음 (2010 등록) |
| 봉자막창 | 6곳 | 있음 (2019 등록) |
| 신참떡볶이, 신불떡볶이 | 9곳, 5곳 | 있음 |
| 호식이·종국이두마리치킨 | 29곳, 11곳 | 있음 |

- **미등록 체인이 있어요.** 태영생막창은 대구에서 가장 많이 반복되는 막창 상호인데 등록 기록이 없어요. 등록 의무가 없는 소규모 본부인지, 가족·지인이 같은 상호를 나눠 쓰는지는 **확인 필요**예요.
- **이름이 비슷해서 잘못 걸려요.** "동궁찜닭" 검색 → "설동궁찜닭", "일품돼지국밥" 검색 → "나날이일품돼지국밥". 부분 일치로 거르면 오탐이 생겨요.
- **반복 상호가 다 체인은 아니에요.** 대구식당(18곳), 우리식당(14곳), 의성식당(15곳) 같은 흔한 이름도 잡혀요.
- 대충 만든 상호 정규화 기준으로 반복 상호는 255개(2,006곳)였어요. 대략적인 규모로만 봐야 해요.

### 2. 3분류 처리 제안 [AI 제안, 사용자 미확정]
일괄 제외 대신 세 가지로 나누자는 제안이에요. 대구 로컬 체인의 **본점(원조 1호점)은 오히려 이 지도의 핵심 후보**일 수 있어서예요.

| 분류 | 판별 방법 | 처리 |
|---|---|---|
| ① 전국 프랜차이즈 | 공정위 등록 + 본부가 대구 밖 | 제외 |
| ② 대구 로컬 체인 | 공정위 등록 + 본부가 대구, **또는** 미등록이지만 대구 안에서 같은 고유 상호가 3곳 이상, 2개 구 이상 | 본점만 후보로 남기고 분점은 제외. "대구 출신 브랜드" 배지 |
| ③ 동명 상호 | "OO식당"처럼 지명+일반명사 형태 | 체인 아님, 개별 가게로 평가 |

**판별 방법**
1. 공정위 정보공개서 목록: 상호, 브랜드명, 등록일. 오탐을 막으려면 **브랜드명 완전 일치**로만 판정. 가맹본부 통계를 지역별로 필터하면 본부가 대구인 브랜드만 뽑을 수 있어요.
2. 인허가 데이터의 반복 상호: "OO점", "본점", 괄호를 떼고 묶은 다음, 3곳 이상이면서 2개 구 이상에 퍼진 상호를 후보로. "식당", "국밥", "할매" 같은 일반명사만으로 된 이름은 제외
3. 본점 판별: 상호에 "본점"이 있거나 같은 브랜드에서 인허가일이 가장 오래된 곳. 다만 지위승계로 개업일이 부풀려질 수 있어요(땅땅치킨이 1988년으로 나오는 것도 그런 경우로 보임). 그래서 **상위 30~50개 브랜드는 사람이 직접 확인**해야 해요.

### 3. 공정위 API 명세 확인 (10/29 오후 4시 30분경)
**출처 표의 15125570은 브랜드명 필드가 없어요.**
- 15125570은 정보공개서 한 건의 **목차**를 돌려주는 API예요. 공정위 가맹사업거래 사이트 API로 연결만 해 둔 방식이라, 인증키도 franchise.ftc.go.kr 마이페이지에서 따로 받아야 해요.
- 요청: `franchise.ftc.go.kr/api/search.do?type=title&jngIfrmpSn=정보공개서일련번호&serviceKey=키`
- 응답: XML, `<tocObj attrbMnno level hasChild><title>…</title></tocObj>` 반복. 브랜드명은 "Ⅱ. 가맹본부의 흥부찜닭 가맹사업 현황" 같은 목차 제목 안에만 있어요.
- 같은 사이트의 목록 API(`type=list`)는 샘플키로 호출해 봤어요. `brandNm`은 있지만 **업종 필드가 없어서** 외식 브랜드만 골라낼 수 없어요.
```
<root><totalCount>1</totalCount><items><item>
 <jngIfrmpSn>149646</jngIfrmpSn><corpNm>(주)바디퍼스트</corpNm><brandNm>바디퍼스트</brandNm>
 <brno>6308801910</brno><jngIfrmpRgsno>20221253</jngIfrmpRgsno><viwerUrl>…</viwerUrl>
</item></items></root>
```

**추천: data.go.kr 15125467 (공정위 가맹정보 브랜드 목록 정보 제공 서비스)** [공개 명세로 확인, 실제 호출은 안 함]
- 주소: `apis.data.go.kr/1130000/FftcBrandRlsInfo2_Service/getBrandinfo`
- 요청 변수(모두 필수): `serviceKey`, `pageNo`, `numOfRows`, `resultType`(xml/json), `jngBizCrtraYr`(기준년도)
- 응답 공통: `resultCode`, `resultMsg`, `numOfRows`, `pageNo`, `totalCount`, `items.item`
- 개발계정 자동승인, 하루 10,000건, JSON·XML 모두 가능

| 필드 | 뜻 |
|---|---|
| `brandNm` | 브랜드명 |
| `corpNm` | 법인명 (2024-12-13 추가) |
| `indutyLclasNm` / `indutyMlsfcNm` | 업종 대분류 / 중분류 |
| `majrGdsNm` | 주요상품명 |
| `brno` / `crno` | 사업자등록번호 / 법인등록번호 |
| `brandMnno` / `jnghdqrtrsMnno` | 브랜드관리번호 / 가맹본부관리번호 |
| `jnghdqrtrsRprsvNm` | 가맹본부 대표자명 |
| `jngBizStrtDate` / `jngBizCrtraYr` | 가맹사업개시일자 / 기준년도 |

**정정:** 앞서(10/29 오후 2시 40분경) 15110241(브랜드별 가맹점 현황)에 점포 상호가 있다고 했는데 **틀렸어요.** 브랜드 단위 통계(가맹점수, 신규, 해지, 평균매출)만 있고 개별 점포 목록은 없어요.

**신청 전과 신청 후에 확인할 수 있는 것**
| 신청 전 (확인함) | 신청 후에만 확인 가능 |
|---|---|
| 15125467 주소, 요청 변수, 응답 필드명 (공개 명세) | 실제 JSON 구조 (`response.body` 같은 감싸는 층이 있는지) |

| 잘못된 키로 부르면 `INVALID_KEY` 에러 | 기준년도별 전체 건수, 연도 간 중복 |

### 4. 상호와 브랜드명 대조 시 문제 (대구 영업 중 29,277곳으로 시험)
**놓치는 경우 (표기 차이)**
- 지점명·띄어쓰기: "교촌치킨중앙점", "교촌치킨 남산점", "교촌치킨(율하점)"
- 한글·영문: "BBQ중구점", "비비큐(BBQ)율하점", "비비큐치킨앤비어 동북로점" (100곳) → 별칭 사전 필요
- 줄임·덧붙임: "신전"(신전떡볶이), "한솥"(한솥도시락), "60계"(60계치킨), "불닭발땡초동대문엽기떡볶이", 결합 브랜드 "본죽&비빔밥"
- 목록에 없는 체인: 정보공개서 미등록 체인은 아예 안 잡힘 (예: 태영생막창 21곳)

**잘못 걸리는 경우 (같은 이름의 개인 가게)**
- "본가": 더본코리아 등록 브랜드인데 대구 "본가숯불돼지갈비", "본가양대창"은 다른 가게
- "할매": 들어간 등록 브랜드 33개, 대구 상호 152곳 → 부분 일치면 대량 오분류
- "김밥천국": 등록 본부 3곳(그중 (주)김밥천국은 2025년 등록). 대구 "엄마손김밥천국", "고을김밥천국" 등 55곳은 대부분 개인 가게로 보임
- "새마을식당": 더본코리아 브랜드. 대구 동구 "새마을식당"(2010년 인허가)은 가맹점인지 상호만으로는 판단 불가

**추천 대조 순서 [AI 제안]**
1. 상호 정리: 공백, 괄호, '○○점' 제거
2. 외식 업종 브랜드와 정확히 같은지 확인
3. 브랜드명이 4자 이상일 때만 '브랜드명으로 시작하는지'까지 확인
4. 영문·한글 별칭 사전으로 한 번 더 매칭
5. 2자 이하 이름이나 '할매', '본가' 같은 일반 단어 브랜드는 사람이 직접 확인
6. 미등록 체인은 대구에서 정리한 이름이 5곳 이상 반복되면 체인으로 보는 방식으로 보완

## 내 의견과 요구사항

- [사용자] 프랜차이즈 점포를 1단계 분석 대상에서 제외하고 싶다.
- [사용자] 대구에만 있는 로컬 프랜차이즈(막창 등)도 고려해야 한다.
- [사용자] API가 브랜드명을 주는지, 정확한 응답 필드명과 형식, 활용신청 전후로 확인 가능한 범위를 구분해 달라고 했어요.
- [사용자] 상호 표기 차이·동명 상호로 생기는 누락과 오분류도 설명해 달라고 했어요.

## 확정한 사항

데이터와 명세로 확인된 사실이에요.
- 출처 표의 **15125570은 목차 API라 브랜드명 필드가 없어요.** 브랜드명이 필요하면 **15125467**을 써야 해요.
- 15110241에는 개별 점포 목록이 없어요.
- 대구 반복 상호 중 태영생막창, 오빠막창, 황금막창, 고향숯불막창, 정하용선산곱창, 청도추어탕은 공정위 미등록이에요.
- 프랜차이즈 처리 방식(제외 범위, 로컬 체인 본점 처리)은 **사용자·팀이 아직 결정하지 않았어요.**

## 검토 중인 사항

- [AI 제안] 3분류 (전국 제외 / 대구 로컬 체인은 본점만 + 배지 / 동명 상호는 개별 평가)
- [AI 제안] 출처 표 수정안
  - URL: data.go.kr/data/15125467/openapi.do
  - 필드: `brandNm`, `indutyLclasNm`, `indutyMlsfcNm`
  - 비고: 상호 정리 후 대조. 일반명사 브랜드는 직접 확인. 미등록 체인은 반복 상호로 보완
- [AI 제안] 미등록 체인 판별 기준: 3곳 이상 + 2개 구 이상 (2번 논의) 또는 5곳 이상 반복 (4번 논의). 두 기준이 대화 중에 다르게 나왔으니 하나로 정해야 해요.

## 보류·제외한 방안과 이유

- **15125570(목차 API)** → 브랜드명 필드 없음
