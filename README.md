# 혼밥 — 대구에서 혼자 먹을 식당 찾기

> 4P 팀 프로젝트. **대구 안에서 혼자 갈 식당을 찾아 주고, 그 집이 1인분·혼밥이 되는지 알려 주는 웹 AI 챗봇**을 만든다.

## 한눈에 보기

| 질문 | 답 |
|---|---|
| 누구를 위한 것인가 | 대구 달서구에 사는 **32세 직장인 1인가구**. 점심때 혼자 먹을 식당을 찾는다 |
| 무엇이 불편한가 | ① 1인분이 되는지 앱에서 미리 거를 수 없다 · ② 1인분·가격·맛·거리를 한 앱에서 함께 걸 수 없다 · ③ 가 보기 전에는 1인분·혼밥이 되는지 알 수 없다 · ④ 혼자 앉으면 눈치가 보여 망설인다 |
| 어디서 가장 막히나 | 먹는 순간이 아니라 **그 전**, "근처에서 혼자 먹을 식당 찾기" 단계 |
| 무엇을 만들었나 | 1인분 + 취향(지역·음식·가격)으로 한 번에 거르는 **혼밥 챗봇** (대구 식당 5,498곳) → 동성로 혼밥 DB 391곳과 **멀티 에이전트 추천 앱** (11-26 중간본) |
| 근거 | 공식 통계(KREI 2025, 생활시간조사 2024 등), 직접 확인한 식당 메뉴판, 고객 글 331건 |

## 근거 원칙

- 근거 등급: A 공식 통계 · B 보고서·민간 조사 · S 직접 확인 · C 언론 · D 커뮤니티·리뷰(사례로만)
- 숫자는 A·B에서만 쓴다. 원자료를 직접 계산한 값은 "Claude 계산"으로 표시하고, 공표된 표를 먼저 재현해 검증했다.
- 시점: 통계·보고서는 2021년 이후, 리뷰·글·메뉴판 사진은 3년 이내.

## 이 저장소에 없는 것

공개 저장소라서 **고객 글 원문(리뷰·커뮤니티 글), 통계 원자료, 보고서 PDF, 수집 결과 CSV**는 올리지 않았다.
문서 안의 고객 글은 요약으로 바꿔 두었다. 원본은 팀 공유 드라이브에 있다.
팀원 작업에도 리뷰 원문, 지도 링크, API 키는 넣지 않았다. VOC 분류 표의 고객 글 조각 칸은 비워 두었다.
