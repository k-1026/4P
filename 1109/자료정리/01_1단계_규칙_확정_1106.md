## 1. 계산 명세 수정안 반영

팀원이 공유한 계산 명세 수정안을 반영했습니다.

| 항목 | 내용 |
|---|---|
| 시작일 | 인허가일 (지위승계해도 그대로) |
| 기준 평균 | 같은 구·업태에서 최근 10년(2016-10-28 ~ 2026-10-28) 안에 폐업한 가게의 평균 영업 기간. 30곳 미만이면 대구 전체 같은 업태 |
| 생존배수 | 영업 기간 ÷ 기준 평균 |
| 1단계 | 구별 생존배수 90백분위수 이상(동점 통과) **그리고** 영업 5년 이상 |
| 동년배 현재 영업 비율 | 같은 구·업태·개업 5년 구간의 영업 중 수 ÷ 전체 수 × 100. 30곳 미만이면 대구 전체. 2000년 이후 개업만 표시, 진행 중인 구간은 `집계 중` |
| 최근 12개월 폐업 비중 | 12개월 폐업 수 ÷ (영업 중 수 + 12개월 폐업 수) × 100 |
| 30년 표시 | 기준일이 인허가일의 30주년 이상 |

스크립트: `step7_spec_compare.py`, 결과: `수정안_계산결과_대구전체.csv`

## 2. 단기 신고 제외: C안

**[사용자]** 두 기준을 모두 계산해 보고 정하기로 했고, C안을 시험한 뒤 확정했습니다.

| 안 | 제외 대상 |
|---|---|
| A | 30일 이내 폐업 중 주소에 행사 키워드가 있는 기록 |
| B | 30일 이내 폐업 전부 + 행사 키워드가 있는 폐업 |
| **C (확정)** | 30일 이내 폐업 중 ① 주소에 행사 키워드가 있거나 ② 같은 주소에서 30일 이내 폐업이 5건 이상인 기록 |

- 행사 키워드: `일원`, `축제`, `행사`, `페스타`, `페스티벌`, `박람회`, `장터`
- 결과: 30일 이내 폐업 2,732건 중 **1,946건 제외**, 786건은 실제 단기 폐업으로 보고 남김
- 같은 주소 기준을 3건, 5건, 10건으로 바꿔도 결과가 크게 달라지지 않았습니다.

## 3. 프랜차이즈 처리

### 기준값에는 포함

**[사용자]** 팀에서 "프랜차이즈를 포함해 전체를 계산한 뒤 가게별로 판정하자"는 의견이 나와, 객관적으로 따져 보고 포함하기로 했습니다.

- **근거:** 기준값에서 프랜차이즈를 빼도 통과 명단이 97.4% 같았습니다(중구 246곳 중 237곳).
- **적용 범위:** 기준 평균, 동년배 현재 영업 비율, 최근 12개월 폐업 비중은 프랜차이즈를 포함해 계산합니다.
- **빼는 곳:** 전국 프랜차이즈는 순위, 합격선, 1단계에서만 뺍니다.

### 전국 프랜차이즈 판별

**[사용자]** "되도록 프랜차이즈는 잡으면 좋겠다", "강함은 제외"로 정했습니다. 본부 위치는 **현재 본사 소재지**로 봅니다.

| 구분 | 조건 | 처리 |
|---|---|---|
| 강함 | 공정위 브랜드명과 일치하고 본부가 대구 밖이며, 아래 중 하나 | `전국 프랜차이즈`, 1단계 제외 |
| | · 브랜드명 4자 이상이고 대구에 3곳 이상이거나 상호에 지점명 | |
| | · 브랜드명 3자 이하이고 대구에 5곳 이상이며 지점명 | |
| 별칭 사전 | `비비큐(BBQ)`, `메가MGC커피`처럼 공정위 이름과 표기가 다른 체인 26개 | 공정위에서 대구 밖 본부를 확인하면 제외 |
| 약함 | 이름만 일치 | 순위에 남기고 `프랜차이즈 확인 필요` 표시 |
| 대구 브랜드 | 본부가 대구 | 지점까지 모두 판정 |

- 공정위 가맹점 목록 API는 대부분 비어 있어 주소 대조에 쓰지 못했습니다.
- 공정위에 등록되지 않은 체인은 잡지 못합니다. 사람 확인용으로 `프랜차이즈_검토목록.csv`를 만들었습니다.
- 스크립트: `step8_franchise_brands.py`, `step8b_hq_region.py`, `step8c_store_match_test.py`, `step8d_franchise_sensitivity.py`, `step8e_missed_chains.py`, `step9_final_table.py`

## 4. 상호 변경: 최근 10년만 보류

**[사용자]** "변경 확인 시 통과 보류", "최근 10년 변경만"으로 정했습니다.

- **기준:** 기준일 전 10년(2016-10-28 이후) 안에 상호가 바뀐 가게는 1단계 통과 대신 `업력 확인 필요`로 둡니다.
- **표기만 바뀐 경우:** 띄어쓰기나 영문 병기처럼 표기만 바뀐 경우는 세지 않습니다.
- **영업 기간과 생존배수:** 상호가 바뀌어도 인허가일을 그대로 씁니다. 업력을 끊지 않고 판정만 보류하는 방식입니다.
- **조회 대상:** 통과 후보 2,164곳의 변경 이력을 식약처 API로 조회하고 있습니다(02번 문서).
