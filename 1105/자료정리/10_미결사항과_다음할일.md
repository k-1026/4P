# 미결 사항과 다음 할 일

> 정해진 기준은 `12_지표_결정사항.md`에 있습니다.

## 정해야 할 것

| 항목 | 현재 상태 |
|---|---|
| 서비스 새 이름 | 미정. `동네상권`은 피하는 것이 좋음 |
| 대표자 변경을 업력 끊기에 포함할지 | 미정. 대물림 가게 문제 |
| 2단계 동네 수요 상권 정의 | 미정 |
| 시민 반응 데이터 | 팀 확정 전 |
| 이전 사이트와의 관계 | "동네가 먹여살린 가게"와의 관계 **확인 필요** |
| 최종본 문구 수정 | 팀 확인 필요 |

## 제안하는 순서

1. 상위 30곳 변경 이력을 마저 받고, 변경 유형 추정이 맞는지 표본을 확인합니다.
2. 대표자·상호 변경 처리 기준을 정하고 대구 상위권부터 적용합니다.
3. 공정위 API(15125467)를 신청해 전국 프랜차이즈를 제외합니다.
4. 보정된 값으로 공식 선정 명단과 비교해 다시 시험합니다.
5. 휴게음식점·제과점을 추가합니다.
6. 최신 인허가로 갱신합니다.
7. 콕스로 지수가 면적이나 개업 시기에 치우치지 않았는지 검증합니다.

이전 방향의 3-3단계(1인·최소 주문)와 대봉1동 작업은 보류 상태입니다.

## 키 관리

- 공공데이터포털과 카카오 키는 PC 사용자 환경변수 `DATA_GO_KR_KEY`, `KAKAO_REST_KEY`에만 저장합니다.
- 코드, CSV, 문서, 채팅에 키를 적지 않습니다.
- 저장 명령은 `set`이 아니라 `setx`입니다. 명령 하나에 줄바꿈이 들어가지 않게 입력합니다.
