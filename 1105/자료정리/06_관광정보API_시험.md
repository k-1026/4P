# 한국관광공사 관광정보 API 시험

> 카카오 계정을 쓰지 않고 영업시간을 채울 수 있는지 시험했습니다.

## API

- 이름: 한국관광공사_국문 관광정보 서비스_GW (데이터 ID 15101578)
- 주소: `apis.data.go.kr/B551011/KorService2`
- 무료, 개발 계정 자동 승인, 기능별 하루 1,000건
- 음식점: `contentTypeId=39`
- 쓴 기능: `locationBasedList2` (위치 기반 목록), `detailIntro2` (소개 정보)
- 음식점 소개 필드: `opentimefood`, `restdatefood`, `firstmenu`, `treatmenu`, `seat`, `packing`, `parkingfood`

## 결과

- 스크립트: `step3_tour_check.py`
- 대봉1동 중심 반경 1km 음식점: 6곳
- 기본표 174곳과 연결: **1곳 (방천가족족발)**

| 관광정보 상호 | 연결 안 된 이유 |
|---|---|
| 진흥반점, 현짬뽕 | 주소가 남구 |
| 김진수로스터리카페 | 카페라 기본표에서 제외된 업종 |
| 대봉정 | 대표 메뉴가 아메리카노인 카페로 보이고, 기본표에 비슷한 상호 없음 |
| 왕거미식당 | 반경 끝 지점이고, 기본표에 비슷한 상호 없음 |
