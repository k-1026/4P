## 요청 원문

### 1. 주제 후보 검토 (15:14)

```
[CJ_AX] 프로젝트1 주제 선정

1. 편의점 물류 판매순위 및 지역(구역) 별 판매율 파악 이후 물류와 바로 연결하여 발주
2. 지역 카페, 식당 영업 유무 파악(보안업체, 포스기, 배달어플 접속 여부로 파악)
3. 전통시장 온누리 상품권으로 파악하는 대구 찐 맛집

로컬 비즈니스 유형- 1. 장소형: 특정 공간 자체가 상품. 방문 경험.
```

→ 결과: 세 주제를 장소형 적합도·데이터 확보·CJ 연결성으로 비교. 3번 추천.
- 1번: 판매 데이터가 본사 비공개, 장소형과 맞지 않아 탈락 권장
- 2번: 보안·포스 데이터 확보 불가 → 인허가 개·폐업 데이터로 대체하면 가능
- 3번: 장소형에 적합. 단 점포별 사용액 비공개라 '찐 맛집' 판별 기준 재설계 필요

### 2. 선정 기준 변경 (15:19)

```
굳이 로컬 비즈니스 유형에 초점을 맞추지 않아도 괜찮습니다. 설득력 높고 방대한 양의 데이터를 기반으로 결과물을 클로드코드를 활용하여 소비자가 선호할만한 서비스로 산출하기 쉬운 주제를 정하려고 합니다
```

→ 결과: 2번과 3번을 결합한 **'오래 살아남은 가게 = 검증된 맛집' 지도** 제안.
- 핵심 논리: "리뷰는 조작될 수 있지만, 20년 영업은 조작할 수 없다"
- 근거 데이터: 지방행정 인허가 데이터(개업일·폐업일·좌표, 수백만 건 단위)
- 구현: 인허가 내려받기 → 좌표 변환 → 업종·지역별 평균 생존 기간 → 온누리 결합 → 웹 지도

### 3. 인스타그램 실시간 연동 가능성 (15:24)

```
오늘 영업 여부 확인을 인스타그램으로 알 수 있을 경우에, 실시간 데이터 연동하는 서비스/바이브코딩이 가능할까?
```

→ 결과: 가능하지만 범위가 좁음.
- 공식 Business Discovery API로 비즈니스 계정의 최근 게시물만 조회 가능
- 개인 계정·스토리는 불가, 크롤링은 이용약관 위반
- 인허가 폐업 여부 + 게시물 휴무 문구 + 정기 휴무 패턴을 합친 **'오늘 열었을 확률'** 기능으로 제안

### 4. 대구로페이 근거 추가 검토 (15:31)

```
그렇다면 '온누리 가맹점 목록은 받을 수 있지만 점포별 사용액은 없습니다. '찐 맛집'을 증명할 근거가 약합니다.' 에 대한 추가적인 근거로 대구로페이 많이 사용한 점포 를 추가하는 건 어떨까?
```

→ 결과: 대구로페이도 점포별 사용액은 비공개.
- 사용액은 할인 혜택에 끌려 움직이고, 연매출 30억 원 초과 인기점은 가맹 대상에서 빠짐
- 정보공개청구 시 행정동·업종별 집계 요청 권장
- 역할 전환: '맛집 증명'이 아니라 **'주민 소비가 몰리는 상권' 지표**로 사용

### 5. 거지맵 참고 가치 (15:40)

```
거지맵 같은 커뮤니티형 사이트 알아? 우리 주제에 참고할만한 가치가 있는 데이터일까?
```

→ 결과: 데이터 출처보다 참고 서비스·검증 도구로 가치.
- 수요 증명 근거, 커뮤니티형의 홍보 오염 문제가 우리 서비스의 차별점
- 거지맵은 가격 축, 우리는 시간(업력) 축 → 겹치면 "싸고 오래 버틴 집"
- 크롤링 대신 행정안전부 착한가격업소 데이터로 가격 신호 확보, 거지맵은 표본 대조용

### 6. 단어 구조화 (16:40)

```
그러면 주민들이 자주가고 오래버틴 집이니까, 주제에 있어서 설득력을 높이려면 어떤 식으로 단어를 구조화하면 좋을까?
```

→ 결과: 데이터가 증명하는 만큼만 말하는 단어로 정리.
- 구조: 주장(버틴집) → 근거(오래 버틴 / 동네 소비가 몰리는 / 값이 착한 / 시장 안의) → 숫자
- 피할 단어: '맛집'(맛 미측정), '주민이 자주 가는'(방문 데이터 없음), '주민이 검증한'(주민 평가 없음)
- 대체: **'시간이 검증한'**
- 카피 후보: "리뷰는 조작할 수 있어도, 20년은 조작할 수 없다" / "광고가 아니라 시간이 고른 가게" / **"동네가 먹여 살린 가게"**

### 7. 방문 빈도 데이터와 서비스 방향 확정 (16:44)

```
방문 빈도 데이터를 추가 근거로 사용하고 싶은데 사용할만한 데이터가 있을까? 동네가 먹여 살린 가게를 캐치프레이즈로 모든 데이터를 교집합화한 가게 또는 상권을 가장 신뢰가는 곳으로 설정하는 서비스로 하고자 해
```

→ 결과: 점포별 방문 빈도는 공개 데이터 없음. 지역 단위로 대체하고 단계형 판정으로 확정.
- 대체 데이터: 한국관광공사 지역별 방문자수·관광 수요 강도 (외지인 비중이 낮을수록 동네 수요 중심)
- 점포 단위 검증: 영수증 리뷰 수 수작업 표본
- 가게 판정: 1단계 오래 버틴 집 → 2단계 동네가 고른 집 → 3단계 **동네가 먹여 살린 집**
- 상권 판정: 생존배수 평균·대구로페이 가맹 밀도·외지인 비중 낮음이 겹치는 곳
