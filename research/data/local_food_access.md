# 지역 특산물 판매처 및 지역 먹거리 데이터 소스 후보

- 조사 기준일: 2026-10-27
- 조사 방법: 대구 D-데이터허브(data.daegu.go.kr)와 공공데이터포털(data.go.kr) 상세 페이지 확인 (파일은 내려받지 않음)

## 1. 조사 목적

시민과 관광객이 대구 지역 먹거리(특산물, 로컬푸드)를 **어디서 살 수 있는지** 안내하는 데 필요한 데이터를 찾는다. 판매처 위치 데이터와 단순 생산 통계를 구분하고, 대구 특산물 판매처 전용 데이터가 없으면 대체할 공식 데이터를 제시한다.

**확인하지 못한 데이터**
- **대구 명품 D마크 인증 품목·업체**: 보도로만 확인했고 데이터셋은 찾지 못했다(확인 필요).
- **대구·경북 특산물 판매처 통합 목록**: 찾지 못했다. 위 로컬푸드 직매장과 온누리 가맹점 데이터로 대체한다.

> **중복 활용**: 온누리상품권 가맹점 데이터는 `traditional_markets.md`에서도 쓴다. 이 파일은 "취급품목으로 판매처 찾기", `traditional_markets.md`는 "시장별 가맹 현황"이 목적이다.

## 3. 데이터 활용 예시

- 대구 로컬푸드 직매장·직거래장터 지도 (주소 지오코딩 후)
- 특산물 카드: "대구 사과 재배면적·생산량"(재배현황) + "가까운 로컬푸드 직매장"(직매장 현황)
- 전통시장 안 과일·농산물 판매 점포 찾기 (온누리 취급품목, 정확도 한계 표시)

## 4. 데이터 품질 및 한계

| 항목 | 내용 |
|---|---|
| 갱신 주기 | 대구 로컬푸드 연간(차기 등록 예정 2026-05-08로 표시되어 있으나 2025년 파일이 최신), 농식품부 연간, 경북 수시(1회성), 재배현황 연간, 온누리 연간 |
| 최신 기준일 | 대구 로컬푸드 2025-05-08 (최종 수정 2025-05-14), 농식품부 2021-12-31, 경북 2021-09-28, 재배현황 2025-12-31, 온누리 2026-07-31 |
| 대구 포함 | 대구 로컬푸드·재배현황·달성군 시장은 대구 데이터, 농식품부·온누리는 전국, 경북은 대구 아님 |
| 누락 가능 항목 | 대구 로컬푸드 파일의 컬럼(주소·운영시간·좌표 포함 여부) 미확인. 재배현황은 구·군별 값 없음. 온누리 취급품목은 자유 텍스트라 품목 검색이 부정확함 |
| 결합 기준 | 판매처는 **주소**로 지오코딩해 좌표 생성. 특산물 품목명(사과, 연근, 미나리 등)으로 재배현황과 판매처를 연결 |

## 5. 출처 신뢰도

| 데이터셋 | 등급 | 근거 |
|---|---|---|
| 대구 로컬푸드직매장 및 직거래장터 현황 | B | 대구시 공식 데이터지만 상세 페이지에 컬럼 정의가 없어 항목을 확인하지 못했다. |
| 농식품부 로컬푸드 직매장 현황 | B | 공식 데이터지만 기준일이 2021년이고 대구 행 포함 여부를 확인하지 못했다. |
| 경북 로컬푸드 직매장 현황 | B | 공식 데이터지만 1회성(2021년)이고 전체 컬럼이 페이지에 없다. |
| 달성군 현풍백년도깨비시장 판매상품 | B | 공식 데이터 목록에서 제목만 확인했다. |
| 온누리상품권 가맹점 | A | 공공기관 공식 데이터이고 상세 페이지에서 컬럼까지 확인했다. |
| 대구 농축산물 재배현황 | A | 대구시 공식 데이터이고 상세 페이지에서 29개 컬럼을 모두 확인했다. |

## 6. 추가 확인 사항

- [ ] 대구 로컬푸드직매장 CSV를 내려받아 컬럼(주소, 운영요일, 판매품목 등) 확인
- [ ] 직매장과 직거래장터가 한 파일에 섞여 있는지, 구분 컬럼이 있는지 확인
- [ ] 달성군 현풍백년도깨비시장 판매상품 파일 컬럼 확인
- [ ] 대구 명품 D마크 인증 목록 공개 여부 (대구시 농산유통과 문의)
- [ ] 농식품부 직매장 데이터에 대구 행이 있는지 확인
