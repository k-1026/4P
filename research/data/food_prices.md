# 농수산물 및 식품 가격 데이터 소스 후보

- 조사 기준일: 2026-10-27
- 조사 방법: 공공데이터포털, KAMIS, 한국소비자원 참가격 페이지 직접 확인

## 1. 조사 목적

대구에서 장보기·외식에 드는 가격을 데이터로 보여 줄 수 있는지 확인한다. **농수산물 도매·소매 가격**(시장에서 파는 식재료)과 **음식점 메뉴 가격**(외식비)은 서로 다른 데이터이므로 나누어 조사했다. 가격은 처음 기획대로 추가 기능 후보이며, 이 문서는 그 확보 가능성을 판단하는 근거다.

|---|---|---|---|---|---|---|
| 참가격 서비스가격정보 > 외식비 | 한국소비자원 (원자료 행정안전부, 출처 국가데이터처) | 웹페이지 + "엑셀저장" 버튼 (CSV/API 아님, API 여부 확인 필요) | https://www.price.go.kr/tprice/portal/servicepriceinfo/dineoutprice/dineOutPriceList.do | 지역, 냉면, 비빔밥, 김치찌개(백반), 삼겹살(환산전/후), 자장면, 삼계탕, 칼국수, 김밥 | **대구 포함** (시도 단위). 지역 선택 조회 가능 | 대구 외식비 평균 카드 |

**참가격 외식비 대구 값 (2026년 9월, 페이지에서 직접 확인)**: 냉면 11,750원, 비빔밥 10,467원, 김치찌개백반 8,583원, 삼겹살(환산후 200g) 18,470원, 자장면 7,167원, 삼계탕 17,167원, 칼국수 7,583원, 김밥 3,250원.

**확인하지 못한 데이터**
- 대구북부농수산물도매시장 경락가격: 대구농수산물유통관리공사 데이터는 수산물 원산지 현황 등만 검색되고 가격 데이터는 찾지 못했다(확인 필요).

## 3. 데이터 활용 예시

- 대구 외식비 카드: 8개 품목의 대구 평균 가격과 전월 대비 변화
- 품목별 가격 추이: 대구 사과 소매가격 월평균 그래프 (KAMIS 가격추이 API, 대구 지역코드 확인 후)
- 착한가격업소 지도: 대표메뉴와 가격 표시 (북구만)

## 4. 데이터 품질 및 한계

| 항목 | 내용 |
|---|---|
| 갱신 주기 | aT 지역별 가격 API 실시간, 참가격 외식비 월별(연·월 선택 조회), 착한가격업소 반기, 경락가격 1회성 |
| 최신 기준일 | aT API 수정일 2026-09-21, 참가격 외식비 2026년 9월, 착한가격업소 2026-06-24, 경락가격 2022-12-31 |
| 대구 포함 | 참가격 외식비는 대구 포함 확인. aT·KAMIS는 확인 필요. 착한가격업소는 북구만 |
| 누락 가능 항목 | 참가격은 시도 평균이라 구·상권 단위 없음, "잠정치"이며 "시도 간 비교가 적절하지 않을 수 있음"으로 안내됨. 김밥 단위가 2017년 1월부터 1인분→1줄로 바뀜 |
| 결합 기준 | 농산물 가격은 **품목코드**(KAMIS 코드표)와 **지역코드**, 외식비는 **시도명**, 착한가격업소는 **좌표·주소** |

- 농산물 소매가격은 품목마다 단위(예: 사과 10개)가 달라 단위를 맞춰 보여 줘야 한다.

## 5. 출처 신뢰도

| 데이터셋 | 등급 | 근거 |
|---|---|---|
| aT 지역별 품목별 도·소매 가격정보 API | B | 공공기관 공식 API지만 대구 지역코드 포함 여부를 명세에서 확인하지 못했다. |
| KAMIS Open-API | B | 공식 서비스 목록은 확인했지만 응답 포맷과 지역코드는 서비스별 명세에서 확인해야 한다. |
| 일별 품목 경락가격 | B | 공식 데이터지만 시장 구분이 없고 1회성 데이터라 대구 활용성이 낮다. |
| 참가격 외식비 | A | 공공기관 공식 페이지에서 대구 값과 품목 단위를 직접 확인했다. |
| 북구 착한가격업소 | A | 구청 공식 데이터이고 상세 페이지에서 컬럼까지 확인했다. |
