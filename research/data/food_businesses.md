# 음식점 및 식품 관련 점포 데이터 소스 후보

- 조사 기준일: 2026-10-27
- 조사 방법: 각 데이터셋 공식 상세 페이지 확인 (파일은 내려받지 않음. 항목은 상세 페이지 표기 기준)

## 1. 조사 목적

대구 음식점·카페·식품 점포가 어디에, 어떤 업종으로, 몇 개 있는지 파악하는 기반 데이터다. 서비스의 지도 표시, 지역별 점포 수 비교, 업종 구성 분석이 모두 이 데이터에서 출발한다. 영업 중인 점포만 골라낼 수 있는지와 좌표 제공 여부가 핵심 확인 사항이다.

## 3. 데이터 활용 예시

- 지도에서 대구 음식점·카페 위치를 업종별 색으로 표시 (상가정보의 위도·경도 사용)
- 구·행정동별 영업 중 음식점 수 비교 (일반음식점 인허가의 영업상태로 필터)
- 최근 1년 인허가 건수로 "새로 생기는 가게가 많은 지역" 표시

## 4. 데이터 품질 및 한계

| 항목 | 일반음식점 인허가 | 상가(상권)정보 CSV | 상가(상권)정보 API | 남구 식품위생업소 |
|---|---|---|---|---|
| 갱신 주기 | 수시 ("매일 갱신, 2일 전 기준"으로 안내) | 분기 | 실시간 | 연간 |
| 최신 기준일 | 수정일 2025-11-27 (안내와 맞지 않음, 확인 필요) | 2026-06-30 | 수정일 2026-08-14 | 2026-06-20 |
| 대구 포함 | 포함 (전국) | 포함 (전국) | 포함 (전국) | 남구만 |
| 누락 가능 항목 | 폐업 업소 포함, 좌표 컬럼명 확인 필요 | 실제 영업 여부와 차이 가능, 전체 행 수 표기 오류(1행) | 오퍼레이션별 응답 항목 확인 필요 | 좌표·영업상태 없음 |

- **결합 기준**: 상호명 + 도로명주소. 좌표는 인허가 데이터(EPSG:5174)를 WGS84로 변환한 뒤 상가정보(경도·위도)와 맞춘다.
- 일반음식점 인허가에는 카페(휴게음식점)가 포함되지 않을 수 있다. 휴게음식점 인허가 데이터는 따로 확인해야 한다(확인 필요).

## 5. 출처 신뢰도

| 데이터셋 | 등급 | 근거 |
|---|---|---|
| 전국일반음식점표준데이터 | B | 공공기관 공식 데이터지만 전체 컬럼과 실제 최신 기준일을 페이지에서 확인하지 못했다. |
| 상가(상권)정보 CSV | B | 공공기관 공식 데이터지만 전체 컬럼 목록과 시도별 분할 여부가 페이지에 없다. |
| 상가(상권)정보 API | B | 공식 API지만 오퍼레이션별 요청 변수는 활용가이드에서 따로 확인해야 한다. |
| 남구 식품위생업소현황 | A | 구청 공식 데이터이고 상세 페이지에서 형식·컬럼·갱신 주기를 모두 확인했다. |

## 6. 추가 확인 사항

- [ ] 일반음식점 CSV를 내려받아 좌표·영업상태·업태 컬럼명과 대구 행 수 확인
- [ ] 휴게음식점(카페) 인허가 데이터가 따로 있는지 확인
- [ ] 상가정보 CSV가 시도별로 나뉘어 있는지, 대구 파일의 행 수 확인
- [ ] 상가정보 API 활용가이드에서 시도·반경 조회 오퍼레이션과 요청 변수 확인
- [ ] 두 데이터의 대구 음식점 수 차이를 비교하고 "공식 점포 수" 기준 결정
