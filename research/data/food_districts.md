# 대구 먹거리 상권 및 상권 분석 데이터 소스 후보

- 조사 기준일: 2026-10-27
- 조사 방법: 공공데이터포털(data.go.kr) 상세 페이지 확인 (파일은 내려받지 않음)

## 1. 조사 목적

대구의 먹거리 상권을 지역별로 비교하려면 상권 단위 점포 수, 업종 분포, 상권 구역, 유동인구가 필요하다. 이 문서는 그중 **실제로 공공데이터로 제공되는 것**과 직접 계산해야 하는 것을 구분한다. 먹거리 골목처럼 이름이 붙은 상권의 데이터도 함께 정리한다.

- **유동인구**: 대구 유동인구 공공데이터셋은 이번 조사에서 확인하지 못했다(확인 필요).
- **대구 전체 먹거리 골목 목록**: 남구 3곳 외에 수성구 들안길 등 다른 구·군 골목 데이터는 찾지 못했다(확인 필요).

> **중복 활용**: 상가(상권)정보 CSV·API는 `food_businesses.md`에서도 쓴다. 이 파일은 "상권 단위 집계·비교"가 목적이고, `food_businesses.md`는 "개별 점포 목록·위치"가 목적이다.

## 3. 데이터 활용 예시

- 행정동별 음식 업종 점포 수 단계구분도 (상가정보를 행정동으로 집계)
- 상권 비교 차트: 안지랑곱창골목 vs 앞산카페거리 vs 앞산맛둘레길의 업소 수, 업태 구성
- 지도에서 지점을 고르면 반경 500m 안의 업종 분포 표시 (상가정보 API, 오퍼레이션 확인 후)

## 4. 데이터 품질 및 한계

| 항목 | 내용 |
|---|---|
| 갱신 주기 | 상가정보 CSV 분기, API 실시간, 남구 먹거리골목 3종 연간 |
| 최신 기준일 | 상가정보 2026-06-30 (차기 등록 예정 2026-10-31), 안지랑 2026-10-02, 앞산카페거리 2026-09-01, 앞산맛둘레길 2026-10-02 |

| 누락 가능 항목 | 상권 경계·유동인구 없음. 먹거리골목 데이터에 좌표 없음. 상가정보 전체 컬럼(행정동 코드 등) 확인 필요 |
| 결합 기준 | 먹거리골목 업소는 **도로명주소를 지오코딩**해 좌표를 만든 뒤 상가정보와 업소명·주소로 연결. 상권 구역은 업소 좌표로 직접 계산해야 함 |
