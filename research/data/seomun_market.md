# 서문시장 — 데이터 소스 후보

> 트랙: AX 데이터·서비스 (푸드 & 리테일) · 조사일: 2026-10-27
> 출처 등급: **A** 공식통계·계획 / **B** 공공기관·연구원 / **C** 언론 / **D** 블로그·민간·비정형 (팀 CLAUDE.md 기준)

## 키워드 개요
대구 중구에 있는 대구 최대 전통시장. 섬유·의류·건어물·먹거리 상가와 야시장으로 유명하다.

## 숫자로 적히는 항목
- 시장 내 점포 수, 상시 영업 점포 수, 노점 수
- 점포 업종(취급 품목) 구성
- 온누리상품권 가맹점 수
- 야시장 운영 시간·매대 수
- 주변 유동인구 (지하철 2·3호선 서문시장역 승하차 인원)
- 주변 상권 추정 매출

## 비정형이지만 수집 가능한 데이터
- 네이버·카카오 지도 리뷰 수, 별점 (점포별 인기도) — 자동 수집은 이용약관 확인 필요 **D**
- SNS 해시태그 언급량 (#서문시장, #서문야시장) **D**
- 네이버 데이터랩 검색량 추이 **C**

## 대시보드 활용 아이디어
- 업종별 점포 구성 비율 + 연도별 변화
- 서문시장역 시간대별 승하차 → 혼잡 시간대 안내
- 야시장 운영일 vs 비운영일 유동인구 비교

## 확인 필요
- 대구 중구청 전통시장 현황 파일이 공공데이터포털에 있는지
- 서문시장 상인연합회 자체 통계(점포 수, 방문객) 공개 여부
