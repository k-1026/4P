# 대구 전통시장 데이터 소스 후보

- 조사 기준일: 2026-10-27
- 조사 방법: 공공데이터포털(data.go.kr)과 대구 D-데이터허브(data.daegu.go.kr) 상세 페이지 확인 (파일은 내려받지 않음)

## 1. 조사 목적

대구 전통시장의 위치, 규모, 취급 품목, 방문 편의(주차·화장실) 정보를 모아 시장 탐색 화면의 기본 데이터로 쓴다. 대구 전체를 덮는 데이터와 특정 구·군만 있는 데이터를 구분해, 어느 수준까지 비교할 수 있는지 판단한다.

- **운영시간**: 표준데이터에는 운영시간 컬럼이 없고 "시장개설주기"(상설·5일장 등으로 추정)만 있다. 시장별 운영시간 데이터는 찾지 못했다(확인 필요).
- 중구(서문시장 등), 수성구, 달성군, 군위군의 구·군 단위 전통시장 현황 데이터는 이번 조사에서 확인하지 못했다.

> **중복 활용**: 온누리상품권 가맹점 데이터는 `local_food_access.md`에서도 쓴다. 이 파일에서는 "시장별 점포 수·가맹 현황", `local_food_access.md`에서는 "특산물 판매처 찾기"가 목적이다.

## 3. 데이터 활용 예시

- 지도에서 대구 전통시장 위치 표시, 주차장·화장실·온누리 사용 가능 여부 필터
- 시장 비교표: 점포 수, 개설연도, 온누리 가맹 점포 수
- 시장 상세 화면: 취급품목, 달서구 시장은 점포 목록까지 표시

## 4. 데이터 품질 및 한계

| 항목 | 내용 |
|---|---|
| 갱신 주기 | 표준데이터 연간(매월 초 병합), 서구·동구 연간, 북구 수시, 온누리 연간 |
| 최신 기준일 | 표준데이터 수정일 2025-11-26, 서구 수정일 2026-06-10, 동구 2026-03-31, 북구 파일명 2022-12-12(수정일 2026-10-15), 온누리 2026-07-31 |
| 대구 포함 | 표준데이터·온누리는 대구 전체, 나머지는 해당 구만 |
| 누락 가능 항목 | 운영시간 없음. 표준데이터는 기관별 등록 시점이 달라 행마다 기준일자가 다를 수 있음. 동구 "규모" 단위 미확인. 서구·동구·북구는 좌표 없음 |
| 결합 기준 | **시장명**(표기 차이 정리 필요) + 도로명주소. 온누리 가맹점은 "소속 시장명"으로 연결 |

## 5. 출처 신뢰도

| 데이터셋 | 등급 | 근거 |
|---|---|---|
| 전국전통시장표준데이터 | A | 공공기관 공식 표준데이터이고 상세 페이지에서 항목·형식·갱신 주기를 확인했다. |
| 서구·동구 전통시장 | A | 구청 공식 데이터이고 상세 페이지에서 컬럼까지 확인했다. |
| 북구 전통시장 현황정보 | B | 구청 공식 데이터지만 컬럼 정의를 확인하지 못했다. |
| 달서구 시장별 상점정보 | B | 공식 데이터 목록에서 제목만 확인했고 상세 항목은 확인하지 못했다. |
| 온누리상품권 가맹점 | A | 공공기관 공식 데이터이고 상세 페이지에서 컬럼까지 확인했다. |

## 6. 추가 확인 사항

- [ ] 표준데이터를 내려받아 대구 시장 수와 각 행의 데이터기준일자 확인
- [ ] 북구 전통시장 현황정보, 달서구 시장별 상점정보 파일의 컬럼 확인
- [ ] 중구·수성구·달성군·군위군 전통시장 데이터 존재 여부 (D-데이터허브 목록 2페이지 이후 포함)
- [ ] 시장별 운영시간·휴무일 공식 출처
- [ ] 온누리 "소속 시장명"과 표준데이터 "시장명"의 표기 일치 여부
