# 대구 음식점업 생존율 — 데이터 소스 후보

- 키워드: 대구 음식점업 생존율
- 대시보드 용도: 생존배수의 **비교 기준선**(업종·지역 평균 생존)
- 조사일: 2026-10-27

## 숫자로 적히는 항목

신생기업 수, 소멸기업 수, 1년·5년 생존율, 활동기업 수(산업별·시도별), 업종별 평균 영업 기간(인허가 데이터로 직접 계산)

## 왜 두 가지를 같이 쓰나

- KOSIS 생존율: 공식 통계라 설득력이 높지만 **시도·대분류 단위**까지만 나올 가능성이 큼.
- 인허가 직접 계산: 구·업태 단위로 잘게 나눌 수 있지만 **우리가 계산한 값**이라 검증이 필요.
- 둘을 비교해 우리 계산값이 공식 통계와 비슷한 수준인지 교차검증한다.

## 확인 필요 항목

- [ ] KOSIS에 **대구 × 숙박·음식점업** 생존율 표가 있는지, 표 ID
- [ ] KOSIS API 인증키 발급 절차
- [ ] 인허가 데이터 폐업 기록이 몇 년 전까지 남아 있는지(기준선 계산 기간 결정)
