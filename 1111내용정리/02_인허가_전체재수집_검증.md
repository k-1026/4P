# 인허가 전체 재수집 · 검증

## 왜 다시 받나

- 지금 쓰는 일반음식점 원본(97,575행)은 **10/28에 포털에서 받은 것**입니다. 11/10에 바뀐 부분만 다시 받았지만, 전체를 공식 API와 한 줄씩 맞춰 본 적은 중구 말고는 없었습니다.
- 그래서 대구 9개 구·군 전체를 행정안전부 API(`15154916`)로 **처음부터 다시 받아**, 기존 자료와 비교해 빠진 것·달라진 것을 파일로 남깁니다.
- 원칙: **빠뜨리지 않고 확인하고, 확인할 수 있는 파일로 남긴다.** (표본만 보는 방법 대신 전체 재수집을 선택)

## 방법

1. 구·군별로 100건씩 끝까지 받기. 받는 대로 저장해서 중간에 끊겨도 이어서 받음.
2. 서버가 한 쪽에서 응답하지 않으면 8번(약 5분) 다시 시도 → 안 되면 그 구·군은 미루고 다음 구·군으로 → 한 바퀴 돈 뒤 10분 쉬고 남은 것 다시 시도 (최대 30바퀴).
3. **빠짐 점검** (수집이 끝나면)
   - 같은 가게가 두 번 받히면 최신 기록 하나만 남김
   - 수집 시작(11/11) 이후 갱신된 기록을 한 번 더 받아 채움
   - 구·군마다 "받은 가게 수 = API 전체 건수"인지 확인 → `빠짐 없음` / `다시 받아야 함`
4. **칸별 대조:** 기존 자료와 상호 · 인허가일자 · 영업상태 · 폐업일자 · 업태 · 도로명주소를 비교해 `일치` / `불일치` / `새로 생김` / `API에 없음`으로 나눔
