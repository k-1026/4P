## 2. 데이터 기본 정보 (API 페이지 기준)

| 항목 | 내용 |
|---|---|
| 설명 | 한식·중식·일식 등 음식류를 조리·판매하며 식사와 함께 음주가 허용되는 업소의 인허가 정보. 전국 자치단체 자료를 같은 서식으로 모은 것 |
| 갱신 | 매일 갱신, **2일 전 기준** |
| 좌표계 | **보정계수 안 들어간 Bessel 중부원점TM (EPSG:5174)**. 지도에 쓰려면 위도·경도(WGS84)로 바꿔야 함 |
| 법령 소관 · 문의 | 식품의약품안전처 식품안전정책과 |
| API 주소 | `https://apis.data.go.kr/1741000/general_restaurants/info` (JSON/XML, 한 번에 최대 100건) |

## 7. 쓸 때 주의할 점

- **인허가일자 = 주인이 시작한 날이 아님.** 지위승계(양도·상속)를 해도 인허가일자는 그대로라, 영업연수는 "같은 자리에서 음식점이 이어진 기간"입니다. 주인 기준은 식약처 인허가 변경 정보(15145167, D10)로 따로 봐야 합니다.
- **영업/정상이어도 실제로 문 닫았을 수 있음.** 폐업 신고를 안 한 가게는 계속 '영업'으로 남습니다. 그래서 폐업 판정 작업을 하는 것입니다.
- **좌표가 없는 가게가 있음** (대구 97,575곳 중 3,990곳, 4.1%).
- **자치단체코드가 바뀔 수 있음.** 2026-07-01 행정체제 개편 때 전남·광주·인천 일부 코드가 바뀌었습니다 (대구는 변동 없음).
